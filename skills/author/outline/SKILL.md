# 大纲技能

帮助作者为书籍创作详细、可执行的大纲。

## 可用框架

### 框架一
15个节拍：开场画面、主题陈述、建置、催化剂、争论、进入第二幕、B故事线、欢乐与游戏、中间点、反派逼近、一切尽失、灵魂暗夜、进入第三幕、高潮结局、终结画面

### 框架二
第一幕（25%）：建置、激励事件、第一转折点
第二幕A（25%）：上升动作、欢乐与游戏、中间点
第二幕B（25%）：矛盾升级、一切尽失、至暗时刻
第三幕（25%）：高潮、解决、尾声


### 场景-续集法（Dwight Swain）
场景：目标 → 冲突 → 灾难
续集：反应 → 困境 → 决策

### 自定义 / 混合
根据作者偏好的方式构建

## 大纲深度层级

- **高层级**：主要情节点与幕式结构
- **章节级**：每章发生的事件与目标
- **场景级**：逐幕拆解，含视角、情感、目的

## 每个场景/章节需包含

- **视角人物**：谁的视角
- **目标**：视角人物想要什么
- **冲突**：阻碍他们的是什么
- **结果**：如何结束（高潮前通常以失败告终）
- **情感弧**：读者应有的感受
- **情节线索**：推进了哪些故事线
- **目标字数**：预估长度
