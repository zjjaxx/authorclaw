# 章节大纲 (1-15)

# 《异能吞噬者》第一卷：饥饿之影 · 章节大纲（第1-15章）

**本部分对应全书结构：第1-24章（铺垫与世界观建立） 的前半部分**
**核心目标：** 建立林默作为“清道夫”的日常与生存状态，引入关键配角（阿吉），并引爆“被迫吞噬先知”的核心事件，使其从苟活的工具变为背负秘密的猎物。

## **第1章：诊所的账单**
*   **视角人物：** 林默
*   **主要场景地点：** 乌鸦诊所
*   **关键情节节拍：**
    1.  **开场钩子：** 林默在“乌鸦”医生的手术台上醒来，忍受着缝合伤口（非致命）的剧痛与体内规则碎片轻微冲突带来的恶心感。账单被“乌鸦”冷漠地拍在台边——金额远超预期，因为用上了稳定规则的特效药。
    2.  **生存压力：** 林默清点身上所剩的现金和未出手的“规则结晶”（上次任务的战利品），发现仅够支付账单，距离下个月“药费”（抑制剂）的缴纳截止日只剩10天。他必须尽快接到新委托。
    3.  **记忆回流闪现：** 在等待麻药退去时，他因疲惫无意识触及了体内某个记忆碎片——一个孩童在火场中哭喊的画面（来自某次吞噬）。他猛地惊醒，冷汗涔涔，用指甲掐掌心以锚定自我。
    4.  **情报碎片：** 离开前，“乌鸦”医生头也不抬地低声说了一句：“最近‘上面’风声紧，好几个嘴巴不牢的‘货’不见了。接活小心点。”
*   **张力等级：** 5/10
*   **章节结尾钩子：** 林默走出诊所，融入老城区的阴影。他摸了摸口袋里的通信器，上面有一条未读信息，来自中间人阿吉：“默哥，有大活，肥。老地方，尽快。”
*   **主人公状态：** **专家境（中期）**，状态：轻伤，规则稳定度尚可，但经济与药费压力巨大。

## **第2章：锈火与情报**
*   **视角人物：** 林默
*   **主要场景地点：** 锈火酒吧
*   **关键情节节拍：**
    1.  **场景建立：** 林默进入“锈火酒吧”，熟练地避开几个明显是新人、眼神不安分的异能者，走向吧台角落。嘈杂、混乱但有序的信息流氛围。
    2.  **会见阿吉：** 阿吉戴着顶新帽子，笑嘻嘻地凑过来，先是一通插科打诨的抱怨（最近风声紧，好货难收），然后切入正题：一个紧急清理委托，目标在市中心制造了多起“意外死亡”，疑似失控，酬金极高且预付三成。
    3.  **细节与疑虑：** 阿吉提供了模糊的目标特征（总是下雨时出现，死者体内有“枯萎”迹象）和活动区域。林默注意到阿吉在描述委托人时眼神闪烁，且预付金是罕见的“纯净规则结晶”（硬通货），而非现金。
    4.  **中二角色的初次提及：** 阿吉压低声音提醒：“对了，听说‘审判官’那疯子最近也在附近活动，好像对这几起‘意外’也有兴趣。你撞上了最好绕道，那家伙……不讲道理只讲他那本破‘律法’。”
*   **张力等级：** 4/10 （日常中的不安）
*   **章节结尾钩子：** 林默接下委托，拿起装着预付结晶的小袋。阿吉最后补了一句，语气难得认真：“默哥，这次……感觉有点不一样。目标可能不止是‘失控’那么简单。”
*   **主人公状态：** **专家境（中期）**，状态：决定接下高风险高回报委托以解燃眉之急。

## **第3章：雨夜狩猎**
*   **视角人物：** 林默
*   **主要场景地点：** 城市中心区，雨夜街道
*   **关键情节节拍：**
    1.  **追踪与侦查：** 林默根据情报在目标区域蹲守，利用【掠食者感知】模糊捕捉异常的、带有“衰败”气息的规则波动。雨声掩盖了许多声音。
    2.  **遭遇目标：** 他发现目标——一个穿着连帽衫、身形佝偻的身影，正将手按在一个晚归的上班族肩上。上班族瞬间眼神空洞，皮肤以肉眼可见的速度失去光泽、出现皱纹。林默果断出手，用附着了吞噬之力的匕首投掷打断。
    3.  **战斗与能力展示：** 目标转身，露出兜帽下干枯如树皮的脸和毫无理性的浑浊眼睛。它操控雨水化为带有枯萎特性的水箭攻击。林默展现清道夫的经验，以速度和精准的近身缠斗为主，避免被规则直接侵蚀，并用吞噬之力尝试接触、分析对方能力本质（【生命汲取/枯萎】变种）。
    4.  **目标的异常：** 战斗中发现，目标虽失控，但动作间偶尔有极其短暂的、类似“挣扎”的停顿，且口中含糊念叨着“光……必须……告诉……”等碎片词语。
*   **张力等级：** 7/10
*   **章节结尾钩子：** 林默即将制服目标时，【掠食者感知】突然传来更强烈、更隐匿的复数波动——有人正在快速靠近战场，来者不善。他瞥见远处楼顶似乎有反光（狙击镜？）。
*   **主人公状态：** **专家境（中期）**，战斗消耗中等，对目标的状态产生怀疑。

## **第4章：第三方与抉择**
*   **视角人物：** 林默
*   **主要场景地点：** 雨夜街道，战场
*   **关键情节节拍：**
    1.  **遭遇夹击：** 三名身着统一黑色作战服、戴着覆面头盔的武装人员无声出现，配合默契，直接使用特制武器（发射束缚能量网、规则干扰弹）攻击林默和目标，意图明显是“全部清除”。
    2.  **身份识别：** 林默认出这是“理事会”直属的清洁部队风格，心沉了下去。这意味着目标涉及理事会必须掩盖的秘密，而自己这个接委托的清道夫也被视为了需要处理的“目击者”。
    3.  **被迫合作与目标的临终时刻：** 在清洁部队火力下，林默与失控目标暂时陷入被动。目标在又一次被击中时，眼中的浑浊突然短暂清明，它看向林默，用尽最后力气嘶哑地说：“……先知……看见了……农场是……他们来了……跑……” 随即，它体内规则彻底暴走，枯萎领域失控性扩张。
    4.  **绝境与吞噬的呼唤：** 清洁部队加强攻击，目标濒死，林默自己也受伤。体内因战斗和危机，【吞噬】本能传来强烈的“饥饿感”——眼前这个蕴含复杂规则和诡异信息的目标，是“补品”，也可能是“毒药”。
*   **张力等级：** 9/10
*   **章节结尾钩子：** 在清洁部队的集火和目标的规则自爆中，林默被冲击波撞入街边店铺。废墟里，目标奄奄一息的身体就在他触手可及之处，那颗蕴含着规则碎片的核心微弱发光。吞噬，立刻获得力量可能破局；不吞噬，可能死在下一秒的清剿中。
*   **主人公状态：** **专家境（中期）**，受伤（多处擦伤、规则轻微侵蚀），面临生死与道德抉择。

## **第5章：被迫的饕餮**
*   **视角人物：** 林默
*   **主要场景地点：** 街边店铺废墟
*   **关键情节节拍：**
    1.  **生死一瞬的抉择：** 林默听到清洁部队逼近的脚步声和武器充能声。求生的本能、对力量的渴望（打破困局）、以及目标临终话语带来的巨大疑惑，压倒了对吞噬副作用的恐惧。他扑向目标，右手（手背疤痕发亮）按在对方心口，发动【吞噬】。
    2.  **吞噬过程描写：** 详细描写吞噬的感官体验——规则碎片如冰冷的洪流涌入体内带来的胀痛与力量感；紧接着，远比以往任何一次都庞大、清晰、系统的**记忆碎片**轰然炸开。
    3.  **继承“先知”的碎片：** 林默“看见”了：一个温和而坚定的男人（“先知”）在秘密记录，内容是关于“农场”的真相、异能起源的假说、理事会“圈养”计划的残酷逻辑；他看到“先知”被发现、被追捕；最后一段记忆，是“先知”在自知必死前，用某种方法将核心信息与执念固结在自己的规则本源中，希望能被“后来者”继承。
    4.  **力量提升与副作用：** 吞噬完成，目标化为飞灰。林默感觉自身异能强度明显提升，但对新力量的掌控生涩。更严重的是，“先知”那份“必须揭露真相”的沉重执念，如同一个响亮的声音在他脑海中不断回响，与其他记忆碎片混杂，带来剧烈的头痛和认知干扰。
*   **张力等级：** 8/10
*   **章节结尾钩子：** 林默勉强压下不适，从废墟中暴起，利用新获得的力量和混乱击退/摆脱了清洁部队的先头人员。他踉跄逃入雨夜更深的小巷，知道自己的人生从此改变——他不仅成了理事会的清除目标，更背负了一个足以颠覆一切的秘密，以及一份沉重的遗志。
*   **主人公状态：** **专家境（后期）**。**境界提升触发**：吞噬了蕴含庞大信息和执念的“先知”遗骸。**代价**：获得新力量但掌控不稳；脑中永久性增加了一个强烈且正义的“外来声音”（先知执念）；人格污染风险显著增加；成为理事会最高优先级清除目标之一。

## **第6章：余烬与追捕令**
*   **视角人物：** 林默
*   **主要场景地点：** 城市下水道临时藏身处
*   **关键情节节拍：**
    1.  **消化与混乱：** 林默在恶臭的下水道中检查伤势，尝试平息体内新融入规则的躁动和脑海中“先知”记忆的低语。他发现自己能模糊理解更多关于规则本质的信息，但代价是注意力难以集中。
    2.  **检查战利品：** 从清洁部队一名队员身上摸到的加密通讯器残留信息显示，对他的追捕令已下达，代号“污染源清除”，优先级最高。同时，他也看到了关于“审判官·夜煌”协助追查“先知”相关线索的调令。
    3.  **联系阿吉（危险）：** 林默用备用加密线路短暂联系阿吉，只问了两句：“委托人的信息，到底是谁？” 和 “我被标记了，有没有安全屋和‘非官方药’渠道？”
    4.  **阿吉的回应：** 阿吉声音紧张：“默哥！我就知道！委托人信息是假的，源头可能就在理事会内部！这是钓‘先知’的饵，你中计了！安全屋坐标发你，药……我尽量，但‘乌鸦’那边肯定被盯上了！”
*   **张力等级：** 7/10
*   **章节结尾钩子：** 林默刚记下坐标，通讯器传来刺耳的干扰音，随后被强行切断。他立刻意识到线路可能已被反向追踪，必须立刻离开这个藏身处。就在他起身时，下水道另一端传来了缓慢、清晰的脚步声，以及一个平静却充满压迫感的男声：“依据《暗面清剿律》第三条，非法吞噬、携带高危信息者，当处以‘净灭’。”
*   **主人公状态：** **专家境（后期）**，状态：受伤，规则不稳，精神受记忆回流干扰，被全面追捕。

## **第7章：审判官的律法**
*   **视角人物：** 林默
*   **主要场景地点：** 城市下水道
*   **关键情节节拍：**
    1.  **夜煌登场：** 来者正是夜煌。银发，复古长风衣，在下水道的昏光中轮廓分明。他并未立刻攻击，而是如同宣读文书般，列举林默的“罪状”：非法吞噬（未在理事会报备的目标）、破坏清理行动、以及最重要的——“承载并可能扩散‘禁忌知识’（先知信息）”。
    2.  **初次规则交锋：** 夜煌发动能力，定义此区域为“临时法庭”，林默立刻感到周围空间变得滞涩，自己的规则运作受到无形压制。林默尝试反击，但新获得的力量运用生疏，被夜煌轻松化解。
    3.  **对话与探查：** 夜煌注意到林默眼中偶尔闪过的、不属于他的悲悯与坚定神色（先知记忆影响），产生了兴趣。他一边攻击，一边质问：“你吞噬了‘先知’？有趣。他的‘遗言’在你脑中低语吗？告诉我，他‘看见’了什么？”
    4.  **不敌与逃脱契机：** 林默不敌，受创加重。危急时刻，他利用对下水道地形的熟悉和夜煌对“活捉审讯”的些许迟疑，引爆了身上最后一枚从清洁部队缴获的规则干扰弹，制造混乱，借机遁入更复杂的管道深处。
*   **张力等级：** 8/10
*   **章节结尾钩子：** 夜煌并未深追，站在原地，看着林默消失的方向，淡金色的瞳孔中若有所思。“并非纯粹的疯狂吞噬者……身上有‘先知’的烙印，却又保留了清晰的自我意识……变量。” 他转身离开，“判决暂缓，观察继续。”
*   **主人公状态：** **专家境（后期）**，状态：新增外伤，规则冲突因战斗加剧，精神疲惫，但初步见识到“执笔者境”的规则运用方式（领域雏形压制）。

## **第8章：安全屋的喘息**
*   **视角人物：** 林默
*   **主要场景地点：** 阿吉提供的临时安全屋（老旧公寓）
*   **关键情节节拍：**
    1.  **抵达与处理伤势：** 林默艰难抵达安全屋，一个简陋但功能齐全的一居室。他处理伤口，服用随身携带的常规止痛药和基础抑制剂，勉强压下体内规则的躁动。
    2.  **与“先知”记忆的初次主动沟通：** 在极度安静和疲惫中，林默尝试主动去“倾听”脑中那个最响亮的声音（先知执念）。他“看到”更多碎片：一份加密数据的位置（可能在某个公共网络节点），几张模糊的“农场”外部照片，以及一种深切的、对“被圈养而不自知”的同胞的悲悯。
    3.  **生存评估：** 林默清点资源：现金不多，食物和水够几天，抑制剂只剩一周的量。他必须在一周内搞到新的抑制剂（“药费”），否则规则反噬和人格污染会同时爆发。
    4.  **阿吉的留言：** 在安全屋隐藏的夹层里，林默找到阿吉留下的便条、一小袋现金、一个未注册的加密数据棒，以及一句警告：“默哥，只能帮到这了。‘药’的渠道在查，但价格会翻几倍。另外，小心‘审判官’，他找你不全是为了理事会任务，那疯子有自己的‘法典’。”
*   **张力等级：** 5/10 （短暂的缓冲期，但压力巨大）
*   **章节结尾钩子：** 林默插入数据棒，里面是阿吉能搜集到的、关于近期失踪的异能者（疑似被送入“农场”）的名单和最后出现地点。其中一个名字和照片，让他瞳孔骤缩——那曾是他刚成为清道夫时，有过一面之缘、还对他露出过善意微笑的年轻女孩。
*   **主人公状态：** **专家境（后期）**，状态：伤势稳定，但药费危机倒计时启动，精神因主动接触先知记忆而更显沉重。

## **第9章：数据幽灵**
*   **视角人物：** 林默
*   **主要场景地点：** 安全屋；城市图书馆的公共网络终端区
*   **关键情节节拍：**
    1.  **制定计划：** 林默决定双线进行：一是尝试获取先知加密的数据，看看是否有破局关键；二是通过阿吉或黑市寻找抑制剂。前者优先，因为信息可能带来筹码。
    2.  **潜入与检索：** 乔装后，林默前往大型公共图书馆，利用公共终端和从先知记忆中获得的关键词、算法，尝试定位并解密那份隐藏数据。过程紧张，需躲避摄像头和可能的网络监控。
    3.  **获取碎片：** 成功下载到一段加密数据包，但无法在公共终端完全解密，只提取出部分内容：一份关于“青禾生命”（苏夫人的公司）某个附属研究站的内部结构简图（标注有“样本流转区”），以及几行意义不明的实验日志编号。
    4.  **遭遇盘查：** 离开时，林默察觉有图书馆安保人员（气质不像普通保安）在注意他。他保持镇定离开，但确认自己已被某种程度的监控。
*   **张力等级：** 6/10
*   **章节结尾钩子：** 回到安全屋，林默用更安全的设备解密剩余数据。最后一部分是一段极短的、扭曲的音频，似乎是“先知”在极度恐惧或痛苦中录下的，背景有规律的机械嗡鸣和模糊的、非人的哀嚎。先知最后的声音颤抖着：“……他们不是屠宰场……是培养皿……我们都在被‘修剪’……”
