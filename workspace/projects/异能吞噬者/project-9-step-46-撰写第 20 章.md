# 撰写第 20 章

# 第20章：妹妹的发现

咖啡馆的玻璃门推开时，风铃响得刺耳。

林深站在门口，喘气。他是一路跑进来的，外套的拉链只拉了一半，头发被雨打湿了几缕贴在额角。店里暖气开得足，空气里有咖啡豆的焦香和甜腻的蛋糕味。晚上九点，人不多，角落坐着一对学生情侣，吧台后店员在擦杯子。

然后他看到了林浅。

她坐在最里面的卡座，背对着墙，面前放着一杯几乎没动的热可可。双手拢在杯子上，指节捏得发白。她抬头看见林深，眼睛瞬间红了。

林深走过去，拉开对面的椅子坐下。动作尽量慢，尽量正常。他能感觉到后颈的汗在往下流，不是热的，是刚才跑出来的，也是急的。

“哥。”林浅开口，声音有点哑。

“嗯。”林深应了一声，目光快速扫过周围。落地窗外是湿漉漉的街道，路灯在积水里拉出细长的光晕。没有异常人影，没有可疑的能量波动——至少他现在的感知没捕捉到。但他脑子里那些碎片正安静地蜷缩着，像动物察觉到潜在威胁前的蛰伏。

“你怎么了？”他问，声音压得很低。

林浅咬了咬嘴唇。她今天穿了件米色的毛衣，头发扎成马尾，但几缕碎发没扎好，垂在耳边，显得有点凌乱。她没回答，而是把手伸进放在座位旁边的帆布包里，摸索了几下，掏出一个旧手机。

不是她现在用的那个智能机，是个老款的按键机，边缘都磨白了。

“这是……”林深皱眉。

“我以前用的。”林浅低着头，手指在按键上按了几下，调出一张照片，把屏幕转向林深，“上周整理旧东西翻出来的，本来想导照片出来……然后看到了这个。”

林深接过手机。

屏幕很小，分辨率不高，照片有些模糊，像是在傍晚拍的，光线暗。画面里是一条旧城区的巷子，青石板路，两边是斑驳的老墙。照片焦点没对准，但能认出巷子深处有两个人的背影。

左边那个，身材高瘦，穿着深色外套，走路姿势有点僵硬。

右边那个……

林深的心脏停跳了一拍。

是他自己。三天前，在旧城区追踪“匿影”时经过那条巷子的背影。照片里他侧着脸，眉头皱着，明显在警惕什么。

而左边那个穿深色外套的人，虽然只拍到小半个侧脸和背影，但林深认得——是气象站事件前，在旧城区跟踪过他的那个“破碎之神”信使。

“这张照片，”林浅的声音在发抖，“是我摄影社一个学姐拍的。她上个月去旧城区采风，随手拍的街景，后来整理照片觉得构图不好，就删了大部分，只留了几张。我把旧手机借给她导过照片，这张……应该是那时候残存的缓存文件。”

她吸了吸鼻子。

“我今天下午在图书馆，突然想起来这件事，就把手机翻出来……然后看到了你。”她抬起眼，眼眶通红，“哥，这个人是在跟踪你，对不对？”

林深没说话。

他盯着那张模糊的照片，脑子里飞快地转。旧城区、跟踪者、被无意拍下的瞬间——这些都是事实。但他不能承认。

“你看错了。”他把手机推回去，声音尽量平稳，“那天我去那边见一个客户，谈项目的事。这个人……可能只是顺路。”

“顺路？”林浅的声音突然拔高了一点，又猛地压下去，像怕惊动什么，“哥，你看他的姿势！他在你后面五米，身体前倾，脚步很轻，而且他一直在看你的方向！这不是顺路，这是跟踪！”

林深呼吸。

他意识到林浅观察得太仔细了。她学美术的，对人体的动态、姿态、视线方向敏感得可怕。

“就算是跟踪，”他压低声音，“也可能是商业竞争对手雇的人。我做金融的，有时候会接触到敏感项目——”

“那这个呢？”林浅打断他，手指在旧手机上又按了几下，调出另一张照片。

这张更模糊，像从视频里截的图。画面是夜间，光线很暗，只能隐约看到一个废弃工厂的轮廓。但画面一角，有一个极其黯淡的、几乎和阴影融为一体的瘦削人影，正做出一个要融入墙角的动作。

人影的轮廓，和林深在工厂追踪“匿影”时看到的那个跳跃前的姿态，有八九分相似。

“这也是那位学姐拍的？”林深问，声音有点干。

“不是。”林浅摇头，“这是我在学校论坛的‘都市传说’板块翻到的。发帖人自称是城市探险爱好者，半夜去北郊废弃工厂拍灵异照片，结果拍到了‘鬼影’。帖子没什么人关注，但我……我认出来了。”

她顿了顿，声音更轻了。

“我认出来，那个工厂的位置，和你上个月说‘加班通宵’那晚，手机定位最后出现的地方……只隔了两条街。”

咖啡馆里很安静。

角落那对学生情侣在低声说笑，吧台的咖啡机发出蒸汽喷涌的嘶鸣。林深感觉自己的手心在冒汗。他看着林浅，看着她通红的眼睛，看着她紧紧攥着手机、指节发白的手。

她不是偶然看到。

她在查。她在拼凑。

“小浅。”林深开口，声音比想象中更沙哑，“听我说。”

“我不想听你说‘没事’。”林浅的眼泪终于掉下来，一颗一颗砸在桌面上，“哥，你这几个月变了。你瘦了好多，黑眼圈重得吓人，你回家就关在房间里，手机永远静音，有时候半夜我起来喝水，看见你站在阳台发呆……你身上有种……我说不清，就是有种特别累、特别重的东西。”

她抽了张纸巾，胡乱擦脸。

“然后我看到了这些照片，我去查了那些‘都市传说’——什么‘影子人’、‘记忆窃贼’、‘认知污染’……哥，你是不是……遇到了‘那种事’？”

最后几个字，她说得几乎无声。

但林深听清了。

认知污染。这个她从哪听来的词？

他身体前倾，手越过桌子，一把抓住林浅的手腕。动作有点急，林浅吓得一缩，但她没挣开。林深的手很凉，掌心有薄茧——是最近训练留下的。

“看着我。”林深说，声音压到最低，低得像耳语，“小浅，看着我。”

林浅抬起泪眼。

“我现在说的话，每一个字你都要记住。”林深盯着她的眼睛，“我确实在做一些……很特殊的工作。涉及国家安全级别，保密等级很高。我不能告诉你细节，但确实有危险。你看到的这个人，可能是威胁之一。”

他停顿，确保她在听。

“你发现的这些照片、这些信息，很危险。不是对你哥我危险，是对你自己。”他握紧她的手腕，“如果有人知道你在查这些，知道你和我的关系，他们会盯上你。用你来威胁我，或者……更糟。”

林浅的嘴唇在抖。

“所以你要做几件事。”林深一字一句地说，“第一，立刻删除这张照片，清空旧手机的所有数据，然后把手机彻底处理掉——砸碎，扔进不同的垃圾桶。第二，忘掉你在论坛看到的那个帖子，忘掉‘都市传说’这些词，不要再查任何相关的东西。第三，从今天起，你的手机、电脑，我会让人做安全加固，但你自己也要警惕——不要点陌生链接，不要接未知号码，出门尽量和同学一起。”

他松开手，从口袋里掏出自己的手机，快速操作了几下。

“我会给你一个紧急联系人号码。如果遇到任何你觉得不对劲的事——有人跟踪、收到奇怪信息、看到无法解释的现象——不要犹豫，立刻打这个电话。对方会帮你，也会通知我。”

林浅看着他操作，眼泪还在流，但眼神里的慌乱慢慢被一种更沉的东西取代。不是害怕，是……明白了。

“哥，”她小声说，“你是不是……在保护什么很重要的东西？”

林深呼吸。

“我在保护你。”他说，“你是我唯一的亲人，你的安全是我的底线。如果你出事，我所做的一切都毫无意义。”

这句话他说得很重。

林浅的眼泪又涌出来，但她点了点头。“我知道了。”她擦掉眼泪，拿起那个旧手机，手指在删除键上悬停了几秒，然后按下去。屏幕闪烁，照片消失了。她又调出格式化选项，确认，清空。

动作很稳。

“我会听话。”她说，声音还有点鼻音，但清晰了很多，“我不查了。但你答应我一件事。”

“什么？”

“你也得保护你自己。”林浅看着他，“你不能……你不能出事。不然我怎么办？”

林深感觉喉咙发紧。他点了点头，说不出话。

吧台的店员朝这边看了一眼，大概觉得气氛太沉重。林深站起身，从钱包里抽出几张钞票放在桌上。“走吧，我送你回宿舍。”

他们走出咖啡馆。

雨已经停了，街道湿漉漉的，空气里有泥土和铁锈的味道。林深走在外侧，把林浅护在里侧。路灯下他们的影子拉得很长，偶尔交错。

一路无话。

到宿舍楼下时，林浅停下脚步。她转过身，看着林深，突然踮起脚尖，伸手抱了他一下。很轻，很快。

“哥，”她在耳边说，“你也要好好的。”

然后她松开手，转身跑进了宿舍楼。

林深站在原地，看着她的背影消失在门厅里。夜风很冷，吹在脸上像刀刮。他站了几分钟，直到确认她宿舍的灯亮起，才转身离开。

回到车上时，陈实已经坐在副驾驶了。

“她安全上楼了。”陈实看着平板上的监控画面，“情绪看起来稳定了。你跟她说了什么？”

“该说的。”林深发动车子，“那张照片处理干净了吗？”

“已经远程抹除了原始文件和所有云端备份。拍摄者的设备也做了清理，不会有残留。”陈实推了推眼镜，“但问题不在这里。”

林深看向他。

“我们追踪了那张照片的流转路径。”陈实把平板转向林深，屏幕上是一张复杂的关系图，“拍摄者是临江大学摄影社的一名普通学生，无异常背景。照片原本存在她的手机里，后来她清理相册时删掉了——按理说，这张照片应该彻底消失。”

他点了点屏幕上的一个节点。

“但一周前，有人通过一个隐蔽的校园局域网漏洞，从她已删除的缓存区里恢复了这张照片，并把它推送到了林浅小姐正在同步整理的旧手机相册里。推送时间，精确在她开始整理旧东西的前一天。”

林深的手握紧了方向盘。

“有人故意的。”他说，不是疑问句。

“对。”陈实说，“手法很专业，覆盖了所有常规追踪痕迹。我们只能确定，对方对林浅小姐的日常习惯、设备使用情况非常了解，而且能精准把握‘时机’——在她开始怀疑、开始主动查找相关信息的时候，递上最关键的一块拼图。”

林深感觉后背发凉。

不是“破碎之神”的风格。他们更直接，更狂热，不会玩这种细腻的心理游戏。

那会是谁？

车子驶入夜色。街道两旁的霓虹灯在车窗上拖出流动的光带。林深看着前方，脑子里那些碎片的声音又浮起来，这次带着一种低沉的、不安的共鸣。

右肩胛骨的酸痛持续传来。

他想起了“引路人”在气象站说的话：**工具当知自身用途。**

也许，他从来都不是唯一的棋手。

也许，连他保护妹妹的这份心思，也早就在某个人的算计里了。
