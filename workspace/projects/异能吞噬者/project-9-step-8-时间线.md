# 时间线

# **《异能吞噬者》详细时间线**

## **一、故事开始前（背景基石）**

*   **【日期模糊，约15年前】“彼岸花计划”启动与冻结**
    *   **事件**：由跨国联合秘密科研组织发起，旨在通过基因编辑与信息拓扑技术，人工制造能够“归零”异能污染的生物武器。实验体编号CN-Alpha系列。在首次“全域抑制脉冲”测试中发生灾难性事故，导致所有实验体死亡或重度脑损伤，计划被无限期冻结封存。唯一的“半成功”产物——**CN-Alpha-01（林深，时年约13岁）**——在事故中记忆被擦除，被伪造成“实验室勤杂工遗孤”身份流落社会。
    *   **影响**：埋下主角真实身份的伏笔；解释了林深能力的非自然起源；留下了未解的技术遗产和潜在威胁（如“初始协议”）。
*   **【5年前】“寂静画室”事件**
    *   **事件**：画家**苏雅（“引路人”姐姐）** 的异能“美之固化”失控，形成高危诡域雏形。收容所特遣队介入，评估后判定不可逆，启动“物理封印”程序，将整个画室及内部的苏雅永久隔离。其弟**苏铭（未来的“引路人”）** 目睹全程，世界观彻底崩塌。
    *   **角色**：苏雅、苏铭（引路人）、收容所外勤部队。
    *   **影响**：直接催生了“引路人”的极端理念与“破碎之神”组织的思想萌芽。这是反派动机的情感与事实核心。
*   **【3年前】“破碎之神”组织形成**
    *   **事件**：**苏铭**利用其黑客能力与“漏洞预视”异能，联络上其他对收容所或自身命运绝望的异能者及边缘学者，初步构建以“世界程序论”和“神圣重启”为核心的教义，“破碎之神”成形。
*   **【1年前】“数据坟场”泄露与陈实加入**
    *   **事件**：一次“源海”信息剧烈渗漏导致临江市局部地区出现大规模集体认知错乱（短暂遗忘语言、符号意义），被收容所掩盖为“工业事故”。实习研究员**陈实**因在处理后续数据时表现出出色的信息梳理能力，被正式招募入收容所Site-07站点。
*   **【故事开始前1个月】林深母亲旧事触发隐忧**
    *   **事件**：林深在整理旧物时，偶然发现母亲生前未寄出的信件，提及“总感觉能听见别人的情绪，很吵”，结合母亲抑郁自杀的往事，林深潜意识中对“异常”的恐惧被再次激活。他开始失眠加剧，为后续“脆弱”状态埋下伏笔。

## **二、开局：坠入深渊（第1章 - 第30章）**

*   **【第1-3章】诡域初现与意外吞噬**
    *   **事件**：林深所在的深蓝资本大楼夜间发生离奇事件（实习生因阅读特定文件触发“认知扭曲”模因污染，开始异化）。加班的林深被卷入，在混乱中被异化者攻击。生命威胁下，其体内“吞噬协议”**被动触发**，首次吞噬了该实习生刚成型的异能核心。
    *   **角色**：林深、异化的实习生（未命名）。
    *   **主角状态**：**Lv.1 觉醒境（污染度跃升至~12%）**。出现强烈副作用：剧烈头痛、幻听（实习生最后的恐惧尖叫）、对办公室特定物品产生莫名恐惧。
*   **【第4-10章】收容所介入与被迫合作**
    *   **事件**：收容所迅速清理现场并锁定林深。Site-07主管通过联络员**陈实**与林深接触，以“监控、研究并提供控制方法，同时保护其妹林浅”为条件，迫使林深签订合作协议。林深被授予“特殊顾问”虚衔，实质为受监控的资产。
    *   **角色**：林深、陈实（首次正式登场）、Site-07主管（幕后）。
    *   **主角成长**：开始接受基础训练，学习使用“灵摆共鸣仪”，了解异能世界常识。精神持续受碎片侵扰。
*   **【第11-20章】首次任务与主动吞噬**
    *   **事件**：追捕一名能操控阴影进行偷窃与伤人的异能者“匿影”（Lv.2）。任务中，为解救被阴影困住的平民，林深在陈实远程指导下，**首次尝试主动控制吞噬**，成功制服目标。
    *   **角色**：林深、陈实、“匿影”。
    *   **主角境界提升**：**晋升Lv.2 掌控境（污染度~22%）**。触发事件：首次成功主动吞噬。**代价**：“匿影”的孤僻性格碎片导致林深接下来一周对人群密集场所有轻微不适；获得能力【阴影亲和】。
*   **【第21-30章】“渡鸦酒馆”与“织梦者”事件**
    *   **事件**：调查一系列离奇自杀案，线索指向灰色地带情报点“渡鸦酒馆”。林深结识老板**苏晚晴**。案件真凶为异能者“织梦者”，能编织美好幻梦诱使目标沉溺至死。对决中，林深为阻止其自杀式扩散梦境，被迫吞噬。
    *   **角色**：林深、陈实、苏晚晴（首次登场）、“织梦者”。
    *   **主角状态**：消化“织梦者”核心（过程约三周），记忆碎片情感强烈（对逝去家人的眷恋），导致林深数次梦回童年。获得能力【记忆丝线】。污染度升至~28%。

## **三、上升：暗流涌动（第31章 - 第80章）**

*   **【第31-45章】连环袭击与“破碎之神”浮出**
    *   **事件**：临江市发生多起针对低危异能者的袭击，受害者能力被粗暴剥离（未吞噬，似被吸取）。收容所调查指向信奉“净化”的极端团体。林深首次遭遇“破碎之神”外围成员，听到“重启”、“天灾”等词汇。
    *   **角色**：林深、陈实、收容所外勤队、“破碎之神”外围成员。
    *   **影响**：林深开始怀疑自身能力是否唯一。“引路人”首次通过加密信息向林深传递晦涩“问候”。
*   **【第46-60章】“火狐”追捕与城市危机**
    *   **事件**：一名代号“火狐”的Lv.3异能者（能力：高热喷射）因污染加深开始失控，在市区制造连环纵火与爆炸。林深参与围捕，经历激烈战斗，最终在楼顶对决中吞噬“火狐”。
    *   **角色**：林深、陈实、苏晚晴（提供情报）、“火狐”。
    *   **主角境界提升**：**晋升Lv.3 驾驭境（污染度~45%）**。触发事件：吞噬高污染度Lv.3异能者，并成功在战斗中初步融合【阴影亲和】与【高热喷射】创造新战术（如阴影中的火焰突袭）。**代价**：继承“火狐”暴怒倾向，战后情绪控制难度增加，需主动克制；获得能力【高热喷射】。
*   **【第61-80章】林浅的察觉与“引路人”的直接接触**
    *   **事件**：林深因连续任务和消化负担，身体状况下滑，被**林浅**敏锐察觉。林浅开始暗中调查。同时，“引路人”策划了一次精妙的袭击，将林深诱入一个规则复杂的废弃商场诡域，两人首次“面对面”（通过投影）进行哲学对话。“引路人”暗示林深“并非偶然”。
    *   **角色**：林深、林浅（主动性增强）、陈实、“引路人”（正式登场）。
    *   **影响**：林深对自身起源产生深度怀疑；“引路人”的“世界程序论”在他心中种下种子；林浅正式步入危险边缘。

## **四、中点转折：身份颠覆（第81章 - 第120章）**

*   **【第81-100章】“记忆编织者”的陷阱与真相碎片**
    *   **事件**：追捕一名能篡改他人记忆的高危异能者（Lv.3巅峰）。任务实为“引路人”设计的陷阱。林深在吞噬该目标时，看到了不属于对方的记忆闪回：**编号休眠舱、白色实验室、以及“CN-Alpha-01激活”的指令画面**。他陷入巨大混乱。
    *   **角色**：林深、陈实、“记忆编织者”（工具人）、“引路人”（幕后）。
    *   **主角状态**：精神遭受重创，新吞噬的核心消化极慢。污染度因情绪冲击飙升至**~58%**，濒临Lv.4门槛但极不稳定。
*   **【第101-120章】档案解密与信任破裂**
    *   **事件**：林深凭借记忆碎片中的线索，胁迫陈实协助，突破权限查找到了部分“彼岸花计划”的加密档案。**Site-07主管**在压力下部分解密，证实林深是人工制造的“产品”，其觉醒是计划预设的“协议激活”。林深与收容所的“合作”关系本质暴露。
    *   **角色**：林深、陈实、Site-07主管。
    *   **中点核心转折**：林深身份从“偶然觉醒的倒霉蛋”彻底颠覆为 **“被设计好的工具”** 。他的核心驱动力从“生存与控制”转向 **“愤怒与追寻真相”** 。与收容所进入相互利用、高度戒备的新阶段。

---

## **五、危机加深：代价显现（第121章 - 第180章）**

*   **【第121-140章】“锚点”的动摇与林浅的觉醒**
    *   **事件**：林深因身份真相而情绪失控，能力出现短暂暴走，差点伤及前来寻找他的林浅。巨大的后怕和妹妹的泪水，促使林浅**主动要求接触异能真相**。在苏晚晴的有限指导下，林浅出于“守护哥哥”的强烈意愿，**自然觉醒辅助能力【情绪稳定锚域】**。
    *   **角色**：林深、林浅（觉醒）、苏晚晴。
    *   **影响**：林深最大的“软肋”主动踏入战场，他的保护策略被迫改变。林浅成为团队正式成员，其能力对林深的精神稳定至关重要。
*   **【第141-160章】“破碎之神”总攻与多重吞噬**
    *   **事件**：“引路人”发动代号“熵增”的大规模行动，同时袭击多个收容所站点和城市节点，释放大量被囚禁或诱导的高危异能者，制造全面混乱。意图逼迫林深进行超负荷“清理”。林深、陈实、苏晚晴、林浅协同作战。
    *   **角色**：全体主要角色。
    *   **主角危机**：在保护妹妹和城市的最终防线战斗中，林深短时间内被迫**连续吞噬超过五名Lv.3以上异能者核心**。
*   **【第161-180章】人格解离与第三条路的萌芽**
    *   **事件**：超负荷吞噬导致灾难性后果。林深陷入严重的 **“人格解离”** ，体内多个核心碎片同时活跃，自我认知模糊，出现持续幻听、记忆错乱和无意识模仿他人言行的症状。**污染度一度突破70%**，踏入Lv.4领域但处于崩溃边缘。依靠**林浅全力维持的“锚域”** 和**陈实从古籍中找到的临时稳定方案**，才勉强维持主体意识不散。
    *   **主角状态**：**Lv.4 重构境（状态极不稳定，污染度~68%-72%波动）**。触发事件：超负荷多重吞噬。**代价**：濒临人格毁灭，亲身感受所有被吞噬者的痛苦与存在，由此诞生了极致的共情与悲悯。他开始思考：除了吞噬毁灭和硬抗，是否有可能**容纳、转化**这些异质规则？

## **六、最终高潮：规则真相与终极对决（第181章 - 第220章）**

*   **【第181-200章】追寻“源海”与最终真相**
    *   **事件**：为寻找解决自身崩溃和世界危机的方法，林深在苏晚晴的线索和陈实的资料支持下，主动探寻“源海”相关遗迹。结合“引路人”故意泄露的部分核心教义，以及收容所最深机密，他终于拼凑出完整真相：**异能是“源海”渗漏、世界存在“慢性漏洞”、“重启”意味着彻底终结**。
    *   **角色**：林深、陈实、苏晚晴、“引路人”（信息博弈）。
    *   **核心揭示**：林深“吞噬”能力的终极潜能，并非删除，而是 **“高维缓存与转译”** ——他可能成为连接两个维度、管理“错误”的桥梁。
*   **【第201-220章】“彼岸花”遗址决战与新协议推演**
    *   **事件**：“引路人”启动最终计划，企图在“彼岸花计划”主遗址（最大渗漏点）强制林深执行“重启协议”。林深携队友前往决战。
    *   **最终对决**：林深拒绝被任何一方利用。他做出疯狂抉择：**同时连接/吞噬“引路人”的【漏洞预视】、收容所试图加载的“全域抑制协议”、以及遗址爆发的所有高危异能能量**，在自己的意识空间内，以自身为实验场，进行一次终极的 **“沙盒推演”** ，试图证明“容纳与可控转化”的第三条路可行。
    *   **角色**：林深、引路人、陈实、苏晚晴、林浅（关键锚点）、收容所力量。
    *   **主角终极成长**：在自我几乎被信息洪流冲散的边缘，凭借**林浅的锚定**、**对妹妹及所有被他吞噬者的守护誓言**，以及**自身顽强的“定义自我”的意志**，他完成了推演，并反向输出了一段稳定的“新协议”信息脉冲，暂时修复并加固了遗址的渗漏点。
    *   **结局状态**：**境界回落并稳固在 Lv.4 重构境（污染度永久性压制在60%以下）**。通过这次终极仪式，他彻底消化了体内大部分不稳定核心，对力量的控制与理解达到全新高度。身体留下不可逆的损伤（部分感官过载、偶尔信息幻视），但自我意识前所未有的清晰和坚定。“引路人”在目睹推演成功后，逻辑链条崩坏，被收容所收押。

## **七、结局与余波（第221章 - 第226章）**

*   **【第221-226章】新的起点**
    *   **事件**：世界并未立刻改变，但裂隙中透入微光。收容所内部对林深的态度分裂，但他已拥有不可忽视的话语权和实力。他并未加入任何一方，而是在苏晚晴的“渡鸦酒馆”基础上，建立了一个极小规模的、非正式的 **“缓冲区”** 或 **“异常共存研究小组”** ，成员包括陈实（双重身份）、苏晚晴、林浅，以及少数被他们救下的、愿意尝试的异能者。
    *   **最终画面**：林深站在能俯瞰城市的屋顶，眼中不再有迷茫与疲惫，只有一种沉淀后的平静与坚定。他依然能听见脑中细微的、来自无数被吞噬者的“回响”，但他不再视其为噪音，而是视为一份需要背负和理解的“记录”。他望向妹妹所在的大学方向，又看了看手中陈实发来的、关于下一个“轻微异常点”的数据报告。路还很长，但方向已然明晰——**不是消灭黑暗，而是学习在黑暗中携带火光，并为后来者留下路标**。
    *   **角色**：所有存活的主要角色。
    *   **主题收束**：天赋是诅咒，力量是负担，但在承受并理解这一切之后，个体依然可以选择用这被诅咒的力量，去开辟一片让更多“错误”得以喘息、甚至共存的狭窄之地。这就是属于林深的、充满代价的救赎之路。

**【时间线总览完毕】**
*   **故事时长**：从开局事件到结局，跨度约**10-12个月**。
*   **危机升级**：个人生存危机 -> 城市隐秘事件 -> 组织间对抗 -> 全球性规则危机。
*   **境界追踪**：林深严格遵循 **Lv.1 (Ch.1-30) -> Lv.2 (Ch.30) -> Lv.3 (Ch.60) -> Lv.4 (Ch.160-220，经历不稳到稳固)** 的阶梯成长，每次晋升均有明确触发事件与沉重代价，无跳跃式升级。
*   **角色出场与成长**：所有关键配角均按设定在时间线中登场，并完成其人物弧光（陈实从机械到共情，苏晚晴从旁观到投入，林浅从被保护到守护者）。
