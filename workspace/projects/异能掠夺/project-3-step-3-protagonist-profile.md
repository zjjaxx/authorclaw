# Protagonist profile

# 主角档案：林深

## 基础信息
- **全名**：林深
- **年龄**：28岁
- **职业/角色**：前顶尖网络安全工程师 / 现深网“异能碎片”匿名贩子 / “断网人”全球掠夺网络的无意识活体密钥
- **代号/化名**：深网交易中使用“Null”（空值），黑市中间人圈内称其“幽灵码农”

## 外貌描述
- **身高/体型**：178cm，偏瘦但精干。七年的程序生涯与近年的逃亡生活，在他身上留下矛盾的印记——既有久坐导致的轻微驼背，又有高度警惕性赋予的、猎食动物般的肌肉张力。
- **面部特征**：面容清俊但被疲惫蚀刻。眼窝略深，眼下有长期睡眠不足导致的顽固青黑。眼睛是偏浅的褐色，在正常光线下显得疏离淡漠，但在专注观察“碎片”或处于紧张状态时，瞳孔会不自觉地轻微收缩，给人一种非人的精密感。
- **发型/穿着**：黑色短发，随意且常被自己抓乱。穿着永恒是深色系、无标识的棉质衣物——灰色连帽衫、黑色T恤、磨损的牛仔裤。唯一值钱且从不离身的是一块改装过的智能手表，表盘常暗，实为连接深网定制终端和监控自身生命体征的设备。
- **显著特征**：左手腕内侧有一道长约五厘米、略显扭曲的陈旧疤痕，看起来像烧伤或某种能量灼伤。他声称是童年意外，但实际是参与“心智防火墙”项目时留下的生物接口痕迹。思考或焦虑时，他会无意识用右手拇指摩挲这道疤痕。

## 技能与能力
### 专业技能
- **顶尖的程序与黑客能力**：擅长逆向工程、漏洞挖掘、数据隐匿。能编写极其高效的自动化脚本处理黑市交易琐务，构建多层跳转的匿名网络。
- **危机构建与生存本能**：对危险有野兽般的直觉，擅长利用环境、规则漏洞甚至人性弱点制造逃生窗口。计划总有A/B/C方案。

### 异能：“碎片视觉”
- **能力表现**：能“看见”他人使用异能后，在现实空间中残留的、常人不可见的“碎片”。碎片形态各异：
  - **刚剥离的**：如碎裂的发光玻璃，边缘锐利，色彩饱和度高，携带强烈的情感或记忆“回响”。
  - **时间较久的**：色彩黯淡，形态模糊如灰烬，回响微弱。
  - **高纯度/核心碎片**：结构复杂，类似分形几何或微缩星图，内部有规律脉动，回响可能包含原宿主的部分人格片段或强烈执念。
- **使用代价**：每次主动聚焦使用能力超过30秒，或接触高纯度碎片，都会引发剧烈的、一侧的偏头痛（通常为右侧），伴随短暂的视觉扭曲和**记忆闪回**——闪回内容是他自身被封锁的过去片段，模糊且痛苦，加剧他的逃避倾向。长期或频繁使用，头痛会演变为持续数小时的神经痛，并伴有耳鸣和短暂的方向感丧失。
- **能力限制**：无法直接看见他人“正在施展”的异能，只能看见残留物；无法直接鉴定碎片的具体异能效果（需结合黑市情报或实验）；对高度洁净、被特殊技术处理过的环境（如“清道夫”设施）残留物感知力下降。

## 致命缺陷
**“在高压下，倾向于将人际关系与道德选择工具化，以此作为情感隔离的盔甲。”**

他并非天生冷血，而是妹妹的悲剧后，他将“负责就会导致伤害”的恐惧，扭曲成了一套行为逻辑：将一切互动简化为“交易”，将人简化为“变量”或“资源”。这让他能在黑市中存活，却也切断了建立真实同盟、获得预警或情感支持的可能。他总在孤军奋战，因为他不相信任何联结是牢固的。这个缺陷会在他最需要帮助时（如遭遇“夜莺”背叛时）被无限放大，带来致命危机。

## 情感创伤与背景故事

### 核心创伤：“幸存者的选择权愧疚”
**事件概要**（基于精炼前提）：
七年前，为缓解妹妹林浅“情绪色彩视觉”能力带来的痛苦，林深冒险从黑市抢夺一枚号称能“屏蔽感知”的碎片。碎片导致林浅情感淡漠，后在随之而来的报复与混乱中，林浅因反应迟钝遭遇车祸身亡。林深将妹妹的“麻木”与死亡，完全归咎于自己滥用能力的贪婪选择。

### 背景时间线
1.  **天赋觉醒期（12-18岁）**：自幼展现出过人的逻辑与抽象思维。16岁时首次无意识“看见”碎片——在父亲与同事激烈争吵后，他瞥见对方办公椅上残留的几点愤怒的“红色碎屑”。一度以为是心理问题，开始自我记录观察。
2.  **技术攀登与家庭变故期（18-22岁）**：考入顶尖大学计算机专业，同时私下研究自身“视觉”。21岁，妹妹林浅能力显现并陷入痛苦。父母在一次离奇事故（后被证实为低级异能冲突波及）中双双去世，林深被迫辍学，携妹艰难生活。
3.  **“心智防火墙”项目与改造期（22-23岁）**：因一份出色的漏洞报告被招募进入保密项目。负责人（维序者）赏识其独特的大脑结构。在“为国家安全做贡献”和“获得稳定收入医治妹妹”的双重驱动下，同意作为高级测试体。项目成功，其部分脑区被永久改造为“活体图谱绘制器”，代价是相关记忆被选择性抑制，并获得一笔丰厚但带有监控的“补偿金”。
4.  **悲剧与堕落期（23-24岁）**：用项目所得尽力照顾林浅，但妹妹病情未见好转。铤而走险抢夺碎片，导致连锁灾难，林浅身亡。同时，项目“补偿金”因不明原因被冻结追回（实为维序者开始清除早期实验痕迹）。陷入绝望与债务。
5.  **深网流亡期（24岁至今）**：为偿还因妹妹治疗和后续风波欠下的高利贷（记忆抵押），利用被改造后强化了的碎片视觉，潜入深网黑市。凭借技术能力和谨慎（实为恐惧驱动），逐渐成为小有名气但行踪飘忽的碎片贩子“Null”，在45天倒计时中挣扎求生。

## 动机（欲望 vs. 需求）
- **表层欲望（Want）**：“在45天内凑齐无法追踪的巨款，还清记忆债务，然后彻底抹去‘林深’和‘Null’的一切数字与物理痕迹，移居到一个无人认识的地方，作为一个‘空白’的普通人活下去。”——本质是**逃离**，逃离过去、逃离能力、逃离代价。
- **深层需求（Need）**：“必须直面并整合自己被篡改的过去、自己作为‘武器’的本质，以及因恐惧而一直逃避的责任。理解真正的力量不是掠夺或控制，也不是彻底的抛弃，而是带着伤疤和记忆，在混沌中建立有温度的、负责任的联结。”——本质是**接纳与重建**。他需要原谅那个当年做出错误选择、但初衷是爱的年轻自己；需要承认自己已是系统的一部分，并通过自己的行动去修复系统，而非简单地一走了之。

## 角色弧线（从开端到结局）
- **开端（故事起点）**：一个高度工具化、情感隔离的逃亡者。视能力为诅咒，视交易为必要之恶，唯一的目标是个人清净。拒绝深入任何碎片背后的故事，对黑市的系统性不公漠然。
- **进展（卷入阴谋）**：在债务压力和高纯度碎片交易的推动下，被迫越陷越深。开始察觉“断网人”的存在，从纯粹的牟利者，变为好奇的窥探者。与阿飞、老周等配角的互动，开始不情愿地撬动他封闭的情感。
- **转折（背叛与孤立）**：“夜莺”的背叛是重击，粉碎了他仅存的、对“利用规则达到目的”的自信。被迫从棋手变回棋子，陷入绝对孤立。这是**旧人格的彻底破产**。
- **深化（直面创伤）**：在逃亡中，被迫逐步回忆起项目真相和妹妹悲剧的全貌。痛苦，但开始理解悲剧的根源是系统（维序者的项目）与个人选择的交织，而非他一人之罪。与维序者镜像般的创伤对照，让他从仇恨对手，开始**理解悲剧的普遍结构**。
- **高潮（关键抉择）**：在最终对决中，拥有机会摧毁网络或夺取控制权。他选择了**第三条道路**——不是消灭，也不是统治，而是“污染”。这个选择的根源，源于他对妹妹“麻木”的深刻恐惧（那是一种控制的结局），也源于他在与阿飞、老周甚至敌人互动中，重新拾起的、对“人性复杂联结”的微弱信念。
- **结局（新生状态）**：不再是逃亡者或单纯的贩子。他失去了“消失”的可能，但找到了**存在的意义**。他可能成为新生的“共鸣时代”一个麻烦的见证者、一个非官方的调解人，或是继续游走在灰色地带，但目的已变为修复与平衡，而非掠夺。他接纳了自己作为“密钥”和“桥梁”的宿命，并以此身份，开始小心翼翼地重新学习信任与负责。

## 说话方式
- **总体特点**：简洁、精确、多停顿。习惯将复杂情感或社会关系转化为技术或系统隐喻。
- **常用句式**：“从逻辑上讲…”、“这个变量不稳定”、“系统容错率太低”。
- **情绪流露时**：紧张或愤怒时，语速不会加快，反而会变慢，字词间隔拉大，显得更加冰冷。极少提高音量，真正的情绪往往体现在突然的沉默或极其尖刻的、一针见血的讽刺中。
- **面对阿飞/老周**：会流露出有限的、带疲惫感的调侃。对阿飞的中二言论，通常以一句干巴巴的“说人话”或“你的协议该更新了”打断。对老周的抱怨和贪小便宜，会叹口气，但最终往往默许或给出一个实用的、不那么合法的解决方案。

## 关键关系
1.  **林浅（已故妹妹）**：永恒的情感锚点与愧疚之源。她的照片是他数字世界中唯一未加密的私人文件。她的悲剧是他一切行为的原始驱动力，也是他最终理解“控制”与“共鸣”区别的钥匙。
2.  **阿飞（中二黑客）**：技术上的“外挂”，情感上的意外闯入者。阿飞那种毫无根据的乐观、中二病式的英雄主义和对林深能力的盲目崇拜，对林深而言既可笑又刺眼，却也在不知不觉中，成为他灰色世界里一抹无法忽略的、笨拙的色彩。林深对阿飞的保护，起初纯粹出于“有用工具”的考量，后期则演变为一种兄长式的、不耐烦的责任感。
3.  **老周（房东兼线人）**：与“正常”世界仅存的、滑稽而脆弱的连接。老周贪财、怕死、满嘴跑火车，是林深的搞笑担当和情报来源。他们的关系建立在互相利用和有限的温情之上。老周代表着林深试图逃离的那个“庸常但真实”的世界，而老周一次次因为林深卷入麻烦却又最终选择帮忙，也在缓慢挑战着林深“所有人最终都会因我受害”的悲观预期。
4.  **维序者（主要对手）**：扭曲的导师与镜像。维序者代表了林深恐惧的未来——一个被创伤吞噬、转而寻求绝对控制以消除一切痛苦的极端版本。他们的对抗，是两种应对“代价”哲学的斗争，也是父子辈（维序者与女儿，林深与林浅）创伤模式的相互映照。最终的理解（非原谅）至关重要。
5.  **“清道夫”组织（制度性敌手）**：代表旧秩序的冰冷面孔。与他们的周旋，让林深深刻体会到“真相分层”和“秩序不可真空”。他们中可能出现的个别动摇者（如后期可能出现的某个有良知的成员），将成为林深窥见系统内部矛盾、甚至寻求非常规合作的窗口。

---

**档案核心摘要**：林深是一个被过去错误、系统改造和巨大愧疚压垮的天才。他的弧光不是从弱变强，而是从一个**试图逃离自身人性的精密工具**，成长为一个**敢于拥抱自身复杂性、并用这份复杂去“污染”和丰富世界的、有温度的人**。他的力量最终不在于能看见或交易什么，而在于他选择如何定义自己与这个充满代价的世界的连接方式。
