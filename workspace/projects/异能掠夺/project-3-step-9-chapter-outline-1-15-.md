# Chapter outline (1-15)

# 《异能掠夺》第一部分：碎裂之痕（第1-15章）章纲

**卷标：** 第一篇：45日倒计时
**主题句：** 债务迫近，碎片低语，而他不知每一次交易都在为一张巨网标定坐标。

---

### **第1章：Null的交易**
*   **POV:** 林深
*   **主要地点:** “深网集市” / 林深的安全屋（回顾）
*   **关键节拍:**
    1.  **高压开场：** 倒计时第45天。林深（化名“Null”）在“深网集市”的阴影中，正与一个紧张过度的卖家进行最终交割。他通过“碎片视觉”确认货品（一枚“情绪色彩感知”碎片）为高纯度，但也瞥见了原宿主强烈的“焦虑与背叛”情感回响，引发右侧太阳穴初次刺痛。
    2.  **代价显现：** 交易完成，获得无法追踪的加密货币。头痛加剧，伴随短暂闪回——一个模糊的实验室场景和一双空洞的眼睛（妹妹林浅）。他迅速服下止痛药，动作熟练得令人心疼。
    3.  **生存算计：** 回到蜗居安全屋。他调出加密账本，冰冷的数字显示：距离偿还“记忆债务”还差一个天文数字。他列出几个潜在的高价值碎片线索，评估风险与收益，最终锁定其中一个——传闻出现在城中某富豪私宅的“瞬时记忆强化”碎片。
    4.  **线人登场：** 联系老周获取该富豪宅邸的安保情报。老周在视频通话中哭穷夸大风险，最终以“友情价”提供了一份漏洞百出的内部布线图，并神秘兮兮地提醒：“最近‘穿黑袍的’（指陌生势力）也在打听类似东西，小心点。”
*   **紧张程度:** 7/10
*   **章节结尾钩子:** 林深关掉和老周的通话，目光落在妹妹林浅那张磨损的照片上。止痛药效过去，新的头痛伴随着更清晰的闪回碎片袭来——这次，他“看”到了一张由发光线条构成的、极其复杂的局部网络图一角，转瞬即逝。他揉了揉眉心，将其归咎于过度疲劳。

### **第2章：不请自来的信徒**
*   **POV:** 林深
*   **主要地点:** 林深的安全屋 / 网络空间
*   **关键节拍:**
    1.  **入侵警报：** 林深正在为入侵富豪宅邸编写定制脚本，他布设的层层数字陷阱中，有一道外围警报被触发。追踪显示，入侵者技术花哨但路径诡异，不像“清道夫”的风格。
    2.  **中二接触：** 入侵者没有窃取数据，反而在隔离区留下一个加密信息包和一句留言：“向阴影中的传奇致敬！‘窃神者’请求觐见，共商大计！” 附赠一个动画表情：一个戴头盔的小人向星空鞠躬。林深皱眉，觉得对方要么是疯子，要么是陷阱。
    3.  **反向追踪与评估：** 林深用更隐蔽的手法反向追踪，发现对方IP跳跃极快，但核心落脚点指向本地一所大学的服务器，技术痕迹显示其主人是个天赋极高但缺乏纪律的年轻黑客。他决定暂时观察。
    4.  **宅邸潜入准备：** 他完成脚本，利用老周提供的图纸（结合卫星图和公开数据修正）规划出潜入路径。需要一件能短暂干扰新型生物识别锁的小玩意，这又得找老周。
    5.  **代价的提醒：** 准备装备时，他无意间看到手腕上的疤痕，头痛隐隐复发。他强迫自己专注在技术细节上，用理性的计划覆盖对代价的恐惧。
*   **紧张程度:** 5/10（技术对抗紧张，但无直接人身危险）
*   **章节结尾钩子:** 林深打包好潜入装备，那个自称“窃神者”的黑客再次发来消息，这次直接点明：“前辈，您对‘集市’东南角第三个摊位今天新到的那批‘灰烬’不好奇吗？我有内部消息哦。” 消息附带了那个摊位监控的实时截图一角。林深瞳孔微缩——截图里，有个穿着得体、与周围格格不入的男人正在鉴定物品。

### **第3章：集市暗流**
*   **POV:** 林深
*   **主要地点:** 深网集市
*   **关键节拍:**
    1.  **再临险地：** 林深变换装扮进入集市。他警惕性极高，确认没有“尾巴”后，才快速移动。空气里的臭氧味和压抑的低语让他神经紧绷。
    2.  **观察目标：** 他远远观察“窃神者”提到的摊位。那个穿着得体的男人（“断网人”外围收购代理）正在用一台精密的便携式仪器检测几块色泽黯淡的碎片（“灰烬”），举止专业冷静。林深开启“碎片视觉”快速扫过，发现那些“灰烬”虽然能量微弱，但结构残留显示它们曾属于同一类型的异能，且剥离手法相似——像是系统性“采集”的痕迹。
    3.  **意外遭遇：** 正当他准备离开时，集市入口传来一阵不易察觉的骚动。几个穿着便装、但行动间带有某种协调韵律的人分散进入（“清道夫”侦察小队）。林深的心脏猛跳一下，迅速融入阴影，向备用出口移动。
    4.  **“窃神者”现身？：** 在接近出口的巷道，一个戴着兜帽、身影略显单薄的年轻人似乎“不小心”撞了他一下，快速塞给他一个微型U盘，低语：“见面礼！他们在抓‘雨燕’！” 然后迅速消失在岔路。
    5.  **脱身与疑惑：** 林深没有犹豫，利用对地形的熟悉和预设的干扰器（触发消防喷淋误报），在混乱中离开集市。回到安全屋，他读取U盘，里面是那个“得体男人”离开集市后，在不同街角被多个隐蔽摄像头拍到的行进路线片段，以及一个深网匿名账户的片段信息。
*   **紧张程度:** 8/10
*   **章节结尾钩子:** 路线片段最终指向城市一片高档滨湖区。而那个匿名账户的关联信息，经林深初步解密，跳出了一个他曾在某科技伦理研讨会公开报道中见过的名字——陈序（尚未与维序者关联）。林深感到一阵莫名的不安，这不像巧合。

### **第4章：老周的“安全屋”**
*   **POV:** 林深（兼老周视角插叙）
*   **主要地点:** “二手轮回”铺子
*   **关键节拍:**
    1.  **交货与警告：** 林深从老周那里取走干扰生物锁的装置。老周一边收钱一边压低声音说，不止一拨人在打听“记忆强化”类碎片，有个出价很高的神秘客户要求异常详细的原宿主信息，这不合黑市常规。
    2.  **市井情报网：** 老周展示他“情报网”的成果——几张模糊的手机照片，显示最近有“看起来就很贵”的黑色商务车在附近几个老旧社区出没，车上人似乎在观察或记录什么。老周觉得像“踩点的”。
    3.  **阿飞正式登场：** 突然，店铺前门铃响，阿飞（陈飞）穿着一件印着抽象电路图的T恤，背着鼓鼓囊囊的背包，径直走进来，眼睛放光地看着林深：“前辈！我终于找到您的实体安全屋了！请务必让我协助您下一次的伟大行动！” 老周目瞪口呆。
    4.  **冲突与评估：** 林深第一反应是掐断这个威胁。但阿飞迅速用极低的声音报出了林深几个用于洗钱的中间账户末四位，以示自己“有价值且无害”，并举起双手表示投降。林深眼神冰冷，在瞬间评估了当场处理掉阿飞的风险与收益。
    5.  **被迫的“合作”：** 老周打圆场，暗示这愣头青说不定真有用。林深最终没有采取极端措施，而是给阿飞一个近乎不可能的技术挑战：在24小时内，在不触发警报的情况下，弄到目标富豪宅邸最新升级的室内动态感应系统的核心算法特征。他想用这个测试阿飞的能力和威胁等级。
*   **紧张程度:** 6/10（人际紧张与暴露风险）
*   **章节结尾钩子:** 阿飞兴奋地接下了挑战，称其为“破晓行动的前奏”。他离开后，老周擦了把汗对林深说：“这小子……是个真疯子还是天才？” 林深看着阿飞留下的、已经接上店铺WiFi开始疯狂刷数据的笔记本电脑，没有回答。他的手机震动，加密信箱里收到了富豪即将离家参加为期三晚的慈善游艇派对的匿名情报——潜入窗口确定了。

### **第5章：无声潜入**
*   **POV:** 林深
*   **主要地点:** 滨湖高档别墅区，目标宅邸
*   **关键节拍:**
    1.  **技术渗透：** 利用阿飞在截止时间前发来的算法漏洞（附赠一个中二的“相位裂隙已打开”动画），林深编写的脚本成功骗过了动态感应系统。他如幽灵般潜入宅邸内部。
    2.  **碎片搜寻：** 根据情报，碎片被藏在书房一个伪装成艺术品的保险箱内。林深用非接触式扫描器确认了碎片散发的特殊能量场，与“瞬时记忆强化”描述吻合。但他同时也“看”到了碎片周围萦绕着不祥的、深紫色的“懊悔与自我怀疑”回响。
    3.  **意外发现：** 在打开保险箱的瞬间，他注意到箱内除了目标碎片，还有一份纸质文件边缘，上面有手写的“项目：心智防火墙 - 二期受试者跟踪评估”字样。他心头一震，迅速用微型相机拍下。
    4.  **危机逼近：** 就在他取出碎片，准备撤离时，宅邸外传来汽车引擎声——比预计时间提前了！富豪突然返回。林深立刻启动B计划，从预定备用路线（通风管道）撤离。
    5.  **代价支付：** 在狭窄管道中剧烈运动，加上近距离接触高纯度碎片，剧烈偏头痛毫无征兆地爆发。他咬牙忍住眩晕和耳边开始出现的模糊呜咽声（碎片回响），凭借意志力爬出管道，消失在别墅区外的绿化带中。
*   **紧张程度:** 9/10
*   **章节结尾钩子:** 林深在安全屋处理头痛，查看拍下的文件照片。内容残缺，但提到了“受试者编号7”、“神经适配性优异”、“后续观察终止于…事故”。而“事故”二字下面，被人用红笔重重划了一道线。编号7？他感到一阵冰冷的寒意顺着脊椎爬升。

### **第6章：解码与邀约**
*   **POV:** 林深 & 阿飞（穿插）
*   **主要地点:** 林深的安全屋（网络协作）
*   **关键节拍:**
    1.  **碎片处理：** 林深将新得到的碎片存入特制屏蔽容器，头痛稍有缓解。他开始在黑市低调放出风声，试探买家。
    2.  **文件分析：** 林深将文件片段交给阿飞，要求他查找“心智防火墙”项目的任何公开或非公开信息。阿飞如同拿到圣旨，立刻进入“超频模式”，在深网和学术数据库中进行地毯式搜索。
    3.  **阿飞的发现：** 阿飞回报：公开记录中，“心智防火墙”是数年前一个由政府资助的、关于网络安全的前沿研究项目，已于多年前结题，负责人是著名科技伦理学家陈序。但阿飞在一些极隐秘的论坛和失效的备份服务器中，找到了该项目与“非标准神经心理学实验”、“志愿者异常反应”等关键词的微弱关联。
    4.  **神秘邀约：** 林深在深网收到一份加密等级极高的匿名邀约，请他鉴定一枚“极度危险、难以归类”的碎片，报酬是天文数字的加密货币，且预付一半定金。邀约附带了一张碎片在特定光谱下的成像图——结构之复杂，能量脉动之规律，是林深从未见过的“完美”形态。
    5.  **两难抉择：** 鉴定这种碎片风险极高，可能触发巨大代价。但报酬足以一次性解决他的债务危机。同时，他对这份邀约的来源和碎片本身充满警惕与好奇。阿飞兴奋地表示这可能是“触及世界真实面纱的钥匙”。
*   **紧张程度:** 7/10（心理博弈与抉择压力）
*   **章节结尾钩子:** 林深看着账户里突然多出的巨额定金，又看了看屏幕上那张完美的碎片图像，以及阿飞找出的、陈序在某次访谈中谈论“技术应为人类建立理性秩序”的视频片段。他回复了匿名邀约，只有一个词：“地点？”

### **第7章：鉴定师**
*   **POV:** 林深
*   **主要地点:** 城中一处高档私人俱乐部（临时鉴定场所）
*   **关键节拍:**
    1.  **严密布置：** 约见地点是一个私密性极强的俱乐部包厢。林深提前抵达，进行了全面的反监控扫描，并设置了几个紧急撤离的物理和数字后门。对方似乎并不介意。
    2.  **雇主现身：** 雇主是一名气质干练的中年女性，自称是某跨国收藏基金的代理人（“断网人”中层执行者）。她话不多，直接展示了保存在多层屏蔽箱中的碎片实物。
    3.  **直面“完美”：** 林深在绝对安全的隔离环境下，启动“碎片视觉”。眼前的景象让他呼吸一滞：碎片如同一个微缩的、缓缓旋转的星云，内部结构遵循着某种分形几何，美得令人心悸。没有寻常碎片的情感回响，只有一种冰冷的、浩瀚的“秩序感”。但当他试图深入观察能量核心时，剧痛瞬间炸开！
    4.  **代价冲击与关键信息：** 这次头痛远超以往，伴随着强烈的视觉扭曲——他不再是看到闪回，而是仿佛被拉入了一个纯白的、无限延伸的走廊，走廊两侧是无数的门，其中一扇门上标着“7”。一个平静的、非人的声音在低语：“协议…同步…关键节点…” 他强行切断视觉，几乎呕吐。
    5.  **交易与警告：** 林深强忍不适，给出了鉴定结果：“非自然生成碎片，高度结构化，疑似人工干预或极端变异产物。危险等级：未知。不建议任何形式的激活尝试。” 对方似乎对他的痛苦反应和“非自然生成”的结论很满意，支付了尾款，并意味深长地说：“Null先生，你的‘眼睛’很特别。希望我们有机会再次合作。” 离开时，林深注意到俱乐部外有一辆眼熟的黑色商务车。
*   **紧张程度:** 8/10（直面未知与巨大代价）
*   **章节结尾钩子:** 林深回到安全屋，几乎虚脱。他在恍惚中打开电脑，将“7”、“协议同步”、“关键节点”这几个词输入搜索，毫无结果。但鬼使神差地，他调出了之前拍下的“心智防火墙”文件照片，将“受试者编号7”与“7”号门联系在一起。一个可怕的猜想开始成形。阿飞此时发来紧急消息：“前辈！追踪到付你定金的部分资金，源头和之前调查‘灰烬’的那个匿名账户有间接关联！他们是一伙的！”

### **第8章：追猎者苏芮**
*   **POV:** 苏芮
*   **主要地点:** “清道夫”第七区设施 / 城市街道
*   **关键节拍:**
    1.  **任务简报：** 苏芮接到上级指令，近期“集市”异常活跃，且检测到几次高能量碎片波动（对应林深的几次交易）。要求她带队进行一轮定点清扫和情报收集，重点目标是“雨燕”（一个在黑市贩卖情报的中间人，据说掌握某些组织渗透证据）。
    2.  **现场调查：** 苏芮带队突袭“集市”一个疑似“雨燕”使用的联络点，只找到被焚毁的终端残骸和匆忙撤离的痕迹。现场残留的微量能量痕迹让她皱眉——过于“干净”，不像普通黑市贩子。
    3.  **数据交叉：** 回到设施，她调阅近期所有异能相关事件报告。发现几起“野生能力者能力突然衰退或失控”的案件，地点分散，但时间相对集中。受害者都声称失去能力前接触过“陌生人”或“买了奇怪的东西”。她将这几起案件与“集市”高能量波动的时间点放在一起比对。
    4.  **发现疑点：** 数据没有直接关联，但一种模式浮现：高能量交易后，似乎总伴随着周边区域野生能力者的“事故”。她向上级提交了初步分析，建议深入调查是否有组织在系统性收购或影响碎片流向。报告被标记为“已阅，优先度调低”，理由是“缺乏直接证据，可能为巧合”。

*   **紧张程度:** 6/10（调查过程的紧张）
