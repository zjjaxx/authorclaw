# Write Chapter 3

# 第三章：集市暗流

臭氧的味道更浓了。

林深第三次调整口罩的位置，过滤棉已经饱和，那股金属烧焦的甜腥气还是渗进来，在舌根留下挥之不去的铁锈味。他贴着铅板墙壁移动，脚步落在混凝土上几乎无声，连帽衫的阴影遮住大半张脸，只露出一双浅褐色的眼睛，瞳孔在昏暗光线里保持收缩状态。

凌晨五点四十七分，“深网集市”的人流量进入波谷。少数几个彻夜交易的摊位还亮着惨白的应急灯，大部分阴影里空无一人，只有堆积如山的废弃服务器机柜在角落里沉默矗立，像机械的墓碑。

阿飞——不，“窃神者”——说的那个摊位在东南角第三个。

林深在二十米外的岔道停下，背靠一个锈蚀的配电箱。他没有直接看过去，而是让视线扫过整个区域，用余光勾勒轮廓。这是他在“集市”生存两年的本能：永远不要直视目标，视线本身就会引来注意。

第三个摊位比他想象的要正规。不是随便铺块防雨布那种，而是用三个改造过的服务器机柜围成半封闭空间，柜体表面覆盖着黑色吸光材料，顶部架着一排低功率紫外灯管，发出滋滋的轻微电流声。灯光下，几块颜色黯淡的碎片摆在天鹅绒衬垫上，形态模糊，像烧尽的香灰。

摊位前站着一个人。

深灰色羊毛大衣，剪裁合身。黑色皮鞋，鞋面一尘不染。即使隔着二十米，林深也能看出那身行头与“集市”的格格不入——这不是黑市贩子或绝望的能力者，这是另一种东西。

“绅士”。阿飞起的代号倒挺贴切。

林深屏住呼吸，让注意力稍微松弛。

现实图景开始褪色，另一层视野像水渍般渗透进来。

首先是摊位本身：那些覆盖机柜的黑色材料在“碎片视觉”里呈现出蜂巢状的细密结构，是某种能量屏蔽涂层，效率不高但足以干扰普通感知。紫外灯管周围缠绕着淡紫色的能量残留，说明这灯不只是照明，还用来激活或检测某些特定频段的碎片。

然后是天鹅绒衬垫上的“灰烬”。

林深的呼吸停了一拍。

在常人眼中模糊黯淡的碎屑，在他的视野里呈现出惊人的一致性。七块碎片，每一块的边缘都平滑得像是用激光切割过的——这不是自然崩解会有的形态。它们散发的能量场极其微弱，几乎快要消散，但残留的结构纹理高度相似:都呈现出细密的、类似年轮的同心圆纹路，圆心处有一个微小的能量坍缩点。

更关键的是，每块碎片周围的“情感回响”色彩，都是同一种死寂的灰白色。

没有恐惧，没有愤怒，没有悲伤。只有一种被彻底抽干的、空洞的麻木。

就像……记忆被格式化后的残留物。

林深强迫自己维持视野。太阳穴开始抽痛，右侧的神经像被细线勒紧，但他需要更多信息。他聚焦在那些同心圆纹路的细节上，尝试辨认——

纹路不是完全连续的。每隔大约十五层圆环，就有一道细微的断点，断点处的能量流向有微小的偏转。

这是系统性的剥离手法。有人用同一种技术，从七个不同的异能者身上剥离了这些碎片。不是随机收集，而是有针对性的“收割”。

头痛加剧了。视野边缘开始出现闪烁的噪点。

林深切断“碎片视觉”，现实图景重新占据主导。他靠在配电箱上，闭上眼睛，深呼吸三次，压制住翻涌上来的恶心感。右手拇指用力按压太阳穴，左手无意识地摩挲着手腕疤痕。

“绅士”还在摊位前。他从怀里掏出那个银色的便携分析仪，对准其中一块“灰烬”。仪器侧面的散热孔发出几乎听不见的高频嗡鸣，顶部的微型屏幕亮起蓝光，数据流快速滚动。

他在记录。不是在估价，是在采集数据。

林深的手指收紧。指甲陷进掌心的肉里，刺痛让他保持清醒。

他需要离开。现在。这个“绅士”和他背后的东西太危险，不是他能碰的。他的目标是四十五天后还清债务消失，不是卷入什么系统性收割的阴谋。

他缓缓后退，准备融入身后的阴影通道。

就在这时，集市入口方向传来一阵骚动。

不是争吵，不是交易纠纷。是另一种声音——急促但整齐的脚步声，皮革鞋底踩在混凝土上的特殊摩擦声，还有某种电子设备启动时特有的、几乎超越人耳感知范围的极低频嗡鸣。

林深全身肌肉瞬间绷紧。

他太熟悉这种声音了。三年前，妹妹出事那晚，“清道夫”的善后小队抵达现场时，空气里就弥漫着这种低频嗡鸣——那是他们携带的“认知干扰场”启动的声音，用来让围观者产生“合理”的错觉:煤气爆炸，食物中毒，集体幻觉。

“清道夫”来了。

不是平时的例行巡逻。低频嗡鸣的强度说明他们带了重型设备，至少是三级响应规格。目标明确，行动迅速。

林深不再犹豫。他转身，向与入口相反的备用出口移动，脚步依然控制着节奏，不快不慢——奔跑会暴露，但正常速度撤离不会。

巷道错综复杂，像地下蚁巢的隧道。他记得每一条岔路，记得哪个转角有监控盲区，记得哪段通风管道可以临时藏身。这些信息是用两年的时间和三次差点被抓换来的。

经过第二个转角时，他听到了压低的声音指令:

“A组封锁东南区出口。”

“B组检查所有屏蔽摊位。”

“C组跟我来，目标可能在第三或第四象限。”

声音冷静、专业，透过骨传导耳机传来细微的电流杂音。林深贴着墙壁，心跳控制在每分钟九十下。他需要绕过两个区块，抵达备用出口所在的第七象限。

头顶的通风管道传来震动。有人在上层移动。

他拐进一条更窄的巷道，这里堆满了报废的CRT显示器，玻璃屏幕碎裂成蛛网状，在昏暗光线里反射出扭曲的倒影。臭氧味在这里混入了另一种气味——淡淡的血腥味，还很新鲜。

林深停下。

巷道尽头躺着一个人。

男性，三十岁左右，穿着廉价的格子衬衫，脸朝下趴在地上。后脑有一个规整的圆孔，边缘焦黑，没有流血。电击弹，非致命，但足够让成年人昏迷六小时。这是“清道夫”的标准抓捕工具。

格子衬衫右手摊开，五指僵硬地蜷曲。手心躺着一枚硬币大小的金属片，表面有烧蚀痕迹。

林深认识这种金属片。这是高端屏蔽容器的内部锁扣，需要专用工具才能拆卸。老周说过，“雨燕”——那个在黑市贩卖情报的中间人——最近在追查一批失踪的碎片，那些碎片都保存在这种定制容器里。

他蹲下身，用戴着手套的手指快速检查。格子衬衫的颈动脉还在跳动，呼吸微弱但平稳。没有明显外伤，除了后脑那个精准的电击弹孔。

专业的。

林深起身，准备离开。这不是他的麻烦。在“集市”，好奇心是比贪婪更致命的病。

他刚迈出一步，身后传来急促的脚步声。

不是“清道夫”那种整齐的步伐，是更轻快、更混乱的脚步声，还夹杂着粗重的喘息。有人正在这条巷道里奔跑，而且快被追上了。

林深瞬间做出判断。他侧身挤进两堆显示器之间的缝隙，空间狭窄得胸骨几乎被挤压。缝隙深处堆着几个腐烂的纸箱，散发着霉味和老鼠屎的酸臭。他蜷缩身体，将自己完全埋入阴影。

三秒后，一个人影冲进巷道。

是个年轻人，最多二十岁，穿着印着像素风格游戏角色的连帽衫，兜帽跑掉了，露出一头乱糟糟的黑发。他脸上全是汗，眼镜歪在一边，镜片后的眼睛瞪得很大，里面是纯粹的、动物般的恐惧。

“雨燕”的线人？还是无关的路人？

年轻人看到了巷道尽头的格子衬衫，脚步踉跄了一下。他转头四顾，发现这是条死路，脸色瞬间惨白。

追兵的脚步声近了。

年轻人咬咬牙，做出了一个让林深皱眉的决定——他没有继续往前冲，而是突然转向，朝着林深藏身的显示器堆冲过来！

林深的手指已经摸到了腰间的电击器。

但年轻人没有攻击，也没有求救。他在距离显示器堆两米的地方突然刹车，从口袋里掏出一个东西，用尽全力朝缝隙方向扔过来！

那东西在空中划出一道弧线。

林深下意识接住。

是一个微型U盘，金属外壳还带着体温。

年轻人用嘴型说了两个字:“见面礼！”

然后他转身，朝着巷道入口方向举起双手，声音颤抖但清晰:“我投降！别开枪！我只是个跑腿的！”

两个穿着深灰色战术背心的人影出现在巷道口。身材高大，动作协调，脸上戴着全覆式战术面罩，只露出一双眼睛。其中一人举着非致命电击枪，枪口稳稳对准年轻人。

“趴下。”声音透过面罩的变声器传出，冰冷失真。

年轻人立刻趴下，脸贴在肮脏的地面上。

另一个“清道夫”成员开始检查格子衬衫的状况，用手持扫描仪扫过全身，然后对着耳机低声汇报:“目标B已控制，生命体征稳定。发现屏蔽容器残片。”

举枪那人没有放松警惕，枪口在年轻人和巷道深处来回移动。“还有其他人吗？”

“热成像显示只有两个生命信号。”检查格子衬衫的人回答，“但这条巷道有大量金属堆积，可能有屏蔽区。”

枪口缓缓转向显示器堆的方向。

林深屏住呼吸。他的藏身处理论上能屏蔽普通热成像，但“清道夫”的装备是定制型号，性能参数未知。心脏在胸腔里沉重地跳动，每一下都震得耳膜发疼。右手握着电击器，左手攥着那个温热的U盘，拇指无意识地摩挲着U盘外壳上粗糙的激光蚀刻纹路。

五秒。十秒。

“清洁组三分钟后到。”耳机里传来指令，“把两个目标带回七区。优先审讯目标B，他知道‘雨燕’的下落。”

“收到。”

两个“清道夫”成员动作利落地给年轻人和格子衬衫戴上黑色头套和束缚带，一前一后架起他们，快速撤离巷道。

脚步声远去。

低频嗡鸣也逐渐减弱，朝着集市其他区域移动。

林深又在缝隙里等了整整两分钟。直到确认周围没有任何动静，只有通风管道永恒的嗡鸣和远处隐约传来的、被镇压下去的骚动声，他才缓缓挪出藏身处。

双腿因为长时间蜷缩而发麻，他扶着墙壁站直，活动了一下僵硬的肩膀。头痛又回来了，这次是从后脑勺开始，沿着颈椎向上蔓延的闷痛。

他看着空荡荡的巷道尽头，格子衬衫躺过的地方只剩下一小片灰尘被搅乱的痕迹。那个年轻人被带走时留下的鞋印还清晰可见，鞋底花纹是某个运动品牌的限量款。

“见面礼”。

年轻人用嘴型说的那两个字，还有U盘抛过来时眼睛里那一闪而过的……狡黠？

林深低头看向手里的U盘。外壳是普通的铝合金，但边缘有一圈细微的蓝色荧光，只在特定角度下能看到。他认出来，这是深网某种匿名情报交易的标记，荧光颜色代表情报等级——蓝色是“已验证，高风险高价值”。

他用袖子擦掉U盘上可能留下的指纹，塞进内袋最深的夹层。

然后他转身，以最快的速度但依然保持隐蔽的节奏，穿过剩下的巷道，抵达备用出口。

出口伪装成老式配电房的检修门，门轴被特意调整过，开启时几乎无声。林深滑出门缝，反手将门带上，锁扣自动扣死。

外面是城市黎明前最黑暗的时刻。

空气冰冷，带着早春特有的湿润泥土味，与集市里那种人工的、病态的臭氧味形成鲜明对比。他站在一条背街小巷里，两旁是高耸的、墙皮剥落的居民楼，少数几扇窗户亮着昏黄的灯，有人在准备早餐。

安全了。

至少暂时。

林深拉紧兜帽，沿着小巷阴影快步行走。十分钟后，他绕了两个街区，从一个二十四小时自助洗衣店的后门进入，穿过满是烘干机热风和洗衣粉气味的店面，从正门出来，混入第一批早班通勤的人群。

又换了三次公交，两次步行，确认没有任何尾巴，他才回到筒子楼。

***

安全屋的门在身后锁上三道锁时，林深才允许自己松懈下来。

他背靠着门板滑坐到地上，摘下口罩，深深吸了一口气——空气里有咖啡、灰尘和电子元件的味道，不好闻，但熟悉。熟悉的意味着可控，意味着暂时安全。

头痛没有缓解，反而因为紧张感的消退而更加鲜明。他摸索着走到工作区，从抽屉里翻出药盒，干咽下两片止痛药。然后他烧水，泡了一杯速溶咖啡，滚烫的液体滑过喉咙，带来虚假的暖意。

做完这些，他才从内袋里取出那个U盘。

金属外壳在显示器冷光下泛着哑光。那圈蓝色荧光已经消失了，说明是一次性的加密标记，读取后会自动擦除。

林深没有立刻插入。他先启动了一台完全物理隔离的备用终端，断掉所有网络连接，甚至拔掉了电源线，改用电池供电。然后他插入U盘。

系统识别，弹出一个加密分区。

密码是动态的。林深尝试了年轻人扔出U盘时说的那两个字的拼音首字母组合，失败。他又尝试了“雨燕”的代号拼音，失败。

第三次，他输入了今天在集市看到的那些“灰烬”碎片的数量:7。

分区解锁。

里面只有一个文件，没有命名，格式是加密的视频日志。

林深点开。

画面晃动得厉害，显然是偷拍。视角很低，像是把摄像头藏在衣领或口袋里。画面里出现一双穿着昂贵皮鞋的脚，正在一条铺着大理石地板的走廊里行走。拍摄者——很可能是那个格子衬衫——在跟踪。

视频没有声音，但下方有自动生成的字幕，准确率不高，断断续续:

“……确认目标进入……B栋……1703……私人会所……”

“……车牌号……黑色的……没有标识……”

“……他进去了……我在外面等……三小时……出来了……带着东西……”

画面切到另一个场景。这次是夜间，在某个地下停车场。那双皮鞋的主人——现在能看到深灰色羊毛大衣的下摆——正走向一辆黑色的轿车。轿车没有品牌标志，车窗是深色防弹玻璃。

一个穿着西装、身材高大的男人从驾驶座下来，拉开后车门。在车门打开的瞬间，车内灯光照亮了一瞬间。

林深暂停视频，倒回去，逐帧播放。

第三帧。车内后座上，放着一个银白色的手提箱。箱体表面有一个徽记——两个嵌套的圆环，圆环之间是细密的电路纹路。图形下方有一行小字，像素不够，但能勉强辨认出前两个字母:In……后面是t……e……

Intertek？Intech？

林深记下这个线索，继续播放。

视频最后一段是在“集市”。画面里出现了“绅士”的侧脸——这是林深第一次看清他的长相。四十岁上下，亚裔，面容清癯，戴着一副无框眼镜，镜片后的眼睛是浅灰色，眼神平静得像实验室里的仪器。他站在东南角第三个摊位前，正在用那个银色分析仪检测碎片。

格子衬衫的镜头拉近，聚焦在“绅士”左手无名指上。

那里戴着一枚戒指。铂金素圈，款式简单，但戒面内侧似乎刻着什么。

视频结束。

自动生成的最后一行字幕:

“他叫陈序。查到了。科技伦理学家。背景很深。‘雨燕’说这东西不能碰。我要撤了。如果这个U盘被人捡到，别追查。会死。”

画面黑屏。

文件自毁程序启动，三秒倒计时，然后整个分区被格式化，U盘发出轻微的咔哒声，内部芯片过热烧毁。

林深拔出U盘。金属外壳烫得惊人，他把它扔进桌角的防火回收桶。

房间里只剩下服务器风扇的嗡鸣。

陈序。

他在搜索引擎里输入这个名字。结果立刻跳出来——维基百科词条，学术数据库页面，媒体报道。照片上的人与视频里一模一样:科技伦理学家，前政府高级顾问，“人类潜能安全理事会”名誉主席。发表过数十篇关于人工智能伦理、神经科技监管的论文，公开演讲的视频里，他的声音温和理性，谈论着“技术应为人类建立理性秩序”。

一个备受尊敬的人。一个在公众视野里代表着理性与责任的人。

而这个人，在凌晨五点的深网黑市里，用便携分析仪检测着系统性收割来的异能碎片。

林深靠在椅背上，闭上眼睛。

太阳穴的抽痛已经演变成全脑范围的闷胀，像颅骨内灌满了沉重的铅液。止痛药在起作用，但太慢了。他能感觉到血管在皮肤下搏动，每一次心跳都加重那份压迫感。

左手腕的疤痕又开始发烫。

不是错觉。皮肤温度确实在升高，疤痕组织下的神经末梢传来尖锐的刺痛，像有什么东西要从那道旧伤口里钻出来。

他睁开眼睛，看向手腕。

在显示器冷光的照射下，那道五厘米长的扭曲疤痕呈现出一种诡异的色泽——不是粉白，不是暗红，而是一种近乎半透明的、带着细微荧光的浅蓝，就像U盘上那圈标记的颜色。

他伸手触摸。

指尖传来的温度高得不正常，至少四十度。疤痕边缘的皮肤在轻微抽搐，像独立的生命体。

林深猛地缩回手，呼吸急促起来。

这不是疲劳过度。不是心理作用。

这道疤——从他记忆中最早的时刻就存在，他以为那是童年意外留下的——现在正在对“陈序”这个名字，对这个与“心智防火墙”有关的男人，产生反应。

记忆的碎片又开始翻涌。冰冷的金属台。电极的触感。低频嗡鸣。那个平静的声音:

“神经同步率达标。开始载入协议。”

协议。

什么协议？

他颤抖着手，在另一个加密数据库里输入“陈序”和“心智防火墙”。没有直接结果。但关联搜索里跳出一条七年前的旧闻:政府资助的前沿研究项目“心智防火墙”顺利结题，项目负责人陈序接受采访，称该项目“为未来神经接口安全奠定了重要基础”。

结题时间，正好在他妹妹出事前三个月。

在他自己参与那个项目——如果那些闪回是真的——之后不久。

林深盯着屏幕，血液一点点冷下去。

窗外，天完全亮了。晨光透过遮光帘的缝隙，将房间切割成明暗相间的条块。远处传来早高峰的车流声，城市开始苏醒，人们起床，洗漱，赶地铁，去上班，活在那个被精心维护的、安全的表层世界里。

而他坐在这个三十平米的囚笼里，左手腕上有一道正在发烫的、可能连接着他过去所有秘密的疤痕，口袋里装着足以还清债务但可能永远无法兑现的碎片，电脑屏幕上是一个本该代表理性与秩序的男人在黑市里的偷拍影像。

还有四十四天。

倒计时在走。

但林深突然意识到，即使四十四天后他还清了债务，保住了记忆，他也可能永远无法“消失”。

因为有些东西，一旦看见了，就再也回不去了。

有些真相，一旦开始浮出水面，就会像水下的冰山一样，拖着看到它的人一起沉没。

他抬起手，看着那道泛着诡异蓝光的疤痕，低声说:

“……巧合？”

但这次，连他自己都不信了。
