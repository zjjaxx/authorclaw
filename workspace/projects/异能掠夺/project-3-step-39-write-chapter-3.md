# Write Chapter 3

# 第3章：集市暗流

集市的味道比记忆里更糟。

林深调整着呼吸面罩的过滤阀，化学药剂和活性炭的气味刺进鼻腔，勉强盖过那层挥之不去的、金属烧灼后的腥甜。那是高浓度异能碎片聚集区特有的气息，像铁锈混着臭氧，在他喉咙深处留下一丝挥之不去的痒意。他贴着铅板墙壁移动，脚步落在粗粝水泥地上时，刻意让鞋底与地面摩擦出与周围环境一致的、拖沓的沙沙声。

灯光是这里最大的谎言。头顶那些廉价的LED灯串和霓虹灯牌，用破碎的彩色光芒把空间切割成一块块明暗不定的区域。光亮处，人脸在闪烁下显得扭曲怪异；阴影里，则藏着太多不想被看见的交易。声音是另一种伪装——通风管道的永恒低鸣盖过了大多数低语，但如果你仔细听，能分辨出压抑的咳嗽、终端按键的滴答、还有偶尔从某个摊位传来古怪的嗡鸣，像被困住的黄蜂。

东南角。第三个摊位。

林深在一条堆满废弃电缆的岔道口停下，身体隐在机柜投下的黑暗里。他微微偏头，用眼角余光扫过目标区域。

防雨布搭起的棚子下，几块暗沉如煤渣的“灰烬”散落在油腻的台面上。摊主是个裹着破旧军大衣的驼背身影，正低头摆弄着一台老式示波器，对摊位前的顾客漠不关心。

而那位顾客——

深灰色休闲西装，合身得像量体定制。头发一丝不苟，几缕银发在霓虹灯下泛着冷光。他微微俯身，左手托着一台银白色便携仪器，右手在触控屏上快速滑动。仪器侧面透镜阵列偶尔闪过微弱的蓝光，扫描着台面上的“灰烬”。姿态放松，却带着实验室里才有的精确感。

就是“窃神者”截图里那个男人。

林深调整呼吸，压下右侧太阳穴开始隐隐作痛的预感。他需要看得更清楚。

他闭上眼，再睁开时，视线略微涣散。

**碎片视觉，主动聚焦。**

世界剥开一层。空气中漂浮的异能残渣像灰色的雪，缓缓沉降。但那些“灰烬”周围，缠绕着不一样的东西——不是刚剥离碎片那种尖锐的、色彩饱和的光丝，而是几缕黯淡的、近乎透明的雾状残留。它们形态模糊，能量微弱，像是被榨干后丢弃的果壳。

但林深的注意力被另一个细节钉住了。

这些雾状残留的**边缘轮廓**。

通常，异能自然消散或粗暴剥离后，残留形态是随机的、破碎的，边缘像撕裂的棉絮。可眼前这几缕“灰烬”的残留，边缘呈现出一种诡异的、高度相似的**平滑衰减曲线**。不是完全一致，但那种衰减的斜率、能量逸散的节奏……像是用同一把刀，以同一种角度和力道，从不同的源头上切下来的。

系统性采集。标准化的剥离手法。

这不是黑市散户能干出来的事。这需要技术、设备，和一套严苛的操作流程。

那个西装男人似乎完成了扫描。他直起身，仪器屏幕朝向他自己，快速浏览着数据。林深看不清他的表情，但能看到他点了点头，动作轻微而肯定。然后，他从西装内袋掏出一个扁平的金属卡盒，从里面抽出几张不记名的深网信用芯片，递给摊主。

摊主头也不抬，伸出脏兮兮的手，抓过芯片，在手里掂了掂，塞进怀里。交易完成，没有一句废话。

西装男人将仪器收回一个特制的皮套，挂在腰侧。他没有立刻离开，而是站在摊位前，目光缓缓扫过集市昏暗的巷道，像是在观察，又像是在……等待什么。

林深肌肉绷紧，将自己更深地缩进阴影。男人目光扫过他所在的区域时，停顿了不到半秒。是巧合？还是察觉到了什么？

就在这时，集市入口方向，传来一阵极其轻微的骚动。

不是大声的喧哗，而是一种韵律的改变。原本杂乱无章的脚步声、低语声、拖动货物的摩擦声，突然出现了几个不协调的、带着明确目的性的节奏点。像几滴冰水落进滚油，瞬间被周围的噪音吞没，但林深捕捉到了。

他太熟悉这种节奏了。协调，克制，带着训练有素的效率感。

**清道夫。**

不是大规模清扫，是侦察小队。渗透进来，收集情报，定位目标。

几乎同时，那个西装男人也动了。他像是同样接收到了某种无形的信号，不再停留，转身朝着与入口相反的方向，迈步离开。步伐依然从容，但速度明显加快。

林深必须立刻做出选择：跟上那个男人，还是先避开清道夫？

头痛预警般加剧，太阳穴的血管突突跳动。跟上去，可能被卷入未知的风险；不跟，这条指向“心智防火墙”和“编号7”的线索可能就此断掉。

他看了一眼西装男人消失的巷道口，又瞥向入口方向——几个人影已经分散开来，融入集市流动的人群中，但行动间那种特有的、猎食者般的协调感掩盖不住。

走。

林深果断放弃追踪，身体贴着墙壁，向自己预留的备用出口移动。那里靠近集市的废弃通风主干道，岔路多，干扰强，是摆脱追踪的理想路线。

他混入一小股正朝那个方向移动的人流——几个戴着防毒面具、背着鼓囊囊背包的贩子。借着他们的掩护，快速穿过一片由集装箱构成的迷宫区。

距离出口还有不到三十米，巷道变窄，头顶的灯光也越发稀疏。

突然，侧面的岔道阴影里，一个身影猛地撞了出来！

林深反应极快，侧身避让，右手已摸向腰后的电击器。但对方撞来的力道控制得很巧，不是攻击，更像是……故意制造接触。

那是个戴着兜帽、身材单薄的年轻人，帽檐压得很低，看不清脸。两人身体交错的一瞬间，林深感到对方将一个冰冷坚硬的小物件，快速塞进了他外套侧面的口袋。

同时，一句压得极低、语速飞快的话钻进耳朵：

“见面礼！他们在抓‘雨燕’！快走！”

声音年轻，带着一丝压抑不住的兴奋颤抖。

说完，那人像受惊的兔子，猛地缩回岔道阴影，脚步声迅速远去，消失在管道交错的深处。

林深手指在口袋外按了按，触感是一个拇指大小的、金属质感的物体。U盘？他没有停留，甚至没有回头去看，加速汇入前方人流，几秒钟后，拐进了通往备用出口的最后一段巷道。

“雨燕”……黑市里有点名气的流动情报贩子。清道夫在抓他？为什么是现在？

疑问在脑中一闪而过，随即被更紧迫的脱身需求覆盖。出口近在眼前——一扇伪装成生锈压力阀门的金属门。他快速输入每日更换的密码组合，阀门“嗤”地一声泄压，向内滑开一条缝隙。

他闪身出去，阀门在身后闭合。

外面是废弃工业园区的露天堆场，夜色浓重，只有远处厂区几盏残存的路灯发出昏黄的光。冰冷的空气灌入肺部，冲淡了集市里那股浑浊的气味。他靠在冰冷的砖墙上，喘息了几秒，让心跳和呼吸平复。

安全了。暂时。

直到此刻，他才从口袋里掏出那个被塞进来的东西。

一个微型U盘，黑色哑光材质，没有任何标识。在昏暗光线下，像一块沉默的煤炭。

“见面礼……”林深低声重复这个词，手指摩挲着U盘冰冷的表面。那个撞来的年轻人，兜帽下隐约可见的黑框眼镜轮廓，急促语气里熟悉的中二感……

“窃神者”。陈飞。

他居然跟到了集市里。而且，似乎提前知道了清道夫的动向。

麻烦的胆子。但这次，这胆子带来了情报。

林深将U盘握紧，迅速离开堆场，钻进园区外错综复杂的老街区巷弄。他没有直接回安全屋，而是绕了三个大圈，换了两次外套，在一处二十四小时营业的嘈杂网吧厕所里呆了二十分钟，确认没有任何尾巴后，才从后门离开，折向另一个临时的落脚点——一间用假身份短租的公寓。

***

公寓里只有最基本的家具，空气中有股淡淡的霉味。林深拉上所有窗帘，打开一台从不联网的备用笔记本电脑，将U盘插入。

没有病毒，没有自启动程序。只有一个加密文件夹。

密码是头盔小人的像素画哈希值，又一次。

文件夹里是两样东西。

第一样是一个视频文件合集，文件名是“绅士行进路线（碎片）”。点开，是十几段时长很短的监控录像片段，来自不同地点：便利店门口、ATM机角落、交通信号灯、某栋写字楼大堂……视角各异，清晰度也不一样，显然是非法接入或劫持的公共及私人摄像头。

每段视频里，都捕捉到了那个西装男人的身影，或正面，或侧影，或背影。片段按照时间戳排列，拼接出一条断断续续的行进路线：从“深网集市”所在的废弃工业园区开始，穿过老城区，最终消失在一片高楼林立的滨湖高档社区附近。

路线终点那片区域，林深有印象。临湖，隐私性极好，房价是这座城市金字塔尖的水平。李泽楷的宅邸也在那个方向，但更靠外围。

第二样东西，是一个文本文件，标题是“账户片段分析报告（初步）”。里面是技术性的解析日志，记录了“窃神者”如何追踪一个深网匿名账户的资金流动痕迹，如何关联到几次对“心智防火墙”历史文献的异常查询，以及最终，如何在那团乱麻般的数据迷雾中，揪出了一条极细的、几乎被擦除的关联链。

报告最后，用加粗字体写着：

**“关联锚点（可信度78.3%）：该匿名账户部分早期活动模式（登录时间偏好、查询关键词组合、跳板节点选择习惯）与以下公开身份的数字足迹存在统计学显著重叠——”**

下面是一个名字，一张从学术会议官网上扒下来的标准照，和简短的头衔。

**陈序。**

照片上的男人五十岁上下，面容清癯，银灰色头发梳得整齐，戴着一副无框眼镜。眼神透过镜片看向镜头，平静，睿智，带着学者特有的、与人保持适当距离感的温和。他穿着深色的西装，白衬衫，没打领带，背景是某个国际科技论坛的蓝色幕布。

头衔写着：著名科技伦理学家，前政府高级科技顾问，“人类潜能安全理事会”名誉主席。

林深的目光钉在照片上，又缓缓移到旁边窗户玻璃反射出的、自己模糊的倒影。安全屋里昏暗的灯光，眼下浓重的青黑，连帽衫的深色布料。

照片里的陈序，整洁，光明，站在学术与政策的聚光灯下。

而他自己，藏在城市最肮脏的缝隙里，交易着非法的碎片，被债务和头痛追赶，手腕上带着不知来历的疤痕。

两个世界。本该毫无交集。

但“心智防火墙”。但“受试者编号7”。但那个西装男人对“灰烬”标准化的扫描，以及他离开时那从容却迅速的背影。

还有这份报告里，那些枯燥的技术分析指向的冰冷结论：这个站在光明处的学者，至少有一个匿名身份，在深网中查询着与林深过去密切相关的项目，其时间偏好和操作习惯，与那个出现在黑市、收购“灰烬”的西装男人背后账户的痕迹……重叠。

巧合？

林深关掉了报告窗口，也关掉了陈序的照片。房间里只剩下电脑风扇的微弱声响，和窗外城市永不间断的、模糊的轰鸣。

他向后靠进硬邦邦的椅子，抬起左手，拇指用力按在手腕的疤痕上。粗糙的皮肤，底下是更粗糙的增生组织。这道疤从他记事起就在，父母说是童年烫伤，但他没有任何相关记忆。只有偶尔，在头痛最剧烈时，疤痕深处会传来幻觉般的灼痛，像是有什么被封印的东西想要破开皮肤钻出来。

编号7。疤痕。被篡改的记忆。还有此刻，这个像幽灵一样从光明世界投下的阴影——陈序。

太多碎片。边缘锋利，割得人神经生疼。它们漂浮着，旋转着，似乎快要拼出某种形状，但那形状太过荒诞，太过庞大，让人本能地想要否认。

他看了一眼电脑右下角的时间。距离他离开集市，已经过去近两个小时。清道夫可能还在附近活动。“雨燕”被抓，意味着黑市的情报网络会出现震动，接下来几天，集市的风声只会更紧。

李泽楷宅邸的行动必须提前。他需要那笔钱，也需要……转移注意力。把自己从这团突然缠上来的、关于过去的迷雾中拔出来，哪怕只是暂时。

他保存好U盘里的所有数据，将其加密备份到多个离线存储设备。然后，他开始清理临时公寓里的一切痕迹，就像他每次离开一个落脚点时所做的那样。

窗外的天色依旧浓黑，离天亮还有一段时间。但林深知道，有些东西已经不一样了。

当他最后关掉电脑，房间陷入黑暗时，那句话再次浮现在脑海，低哑，紧绷，带着连他自己都未能完全察觉的寒意：

“……巧合？”

黑夜没有回答。只有远处滨湖方向，那片高档社区零星的灯火，在城市的雾霭中，勾勒出遥远而模糊的轮廓，像黑暗中一双沉默注视的眼睛。
