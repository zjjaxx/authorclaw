# Major locations

# 主要地点：《异能掠夺》

## 1. 深网集市 | The Node
**别称**：“节点”、“集市”、“碎片巴扎尔”
**物理位置**：城市边缘，一片废弃的工业园区（原电子元件厂）地下三层。入口伪装成锈蚀的货运电梯，需要特定的数字序列（每日更换）与一次性的物理密钥（某种改造过的异能碎片残片）才能激活下行。
**物理描述**：
一个由旧防空洞改造而成的巨大不规则洞穴空间。地面是粗糙的混凝土，墙壁布满早期防核爆处理的铅板涂层，如今已斑驳脱落。空间被几十个由集装箱、废弃服务器机柜和防雨布隔出的“摊位”不规则分割，形成迷宫般的巷道。头顶是裸露的、嗡鸣不止的工业级通风管道和杂乱如蛛网的线缆，上面挂满了廉价的LED灯串和闪烁的霓虹灯牌，提供着不稳定、色彩破碎的照明。少数几个摊位拥有自带的聚光灯，在昏暗中形成刺眼的光岛。
**氛围**：
一种高度紧张的、被压抑的狂热。这里没有叫卖声，只有压低的、快速的耳语和终端按键的滴答声。信任是这里的终极奢侈品，每双眼睛都在评估与戒备。空气里弥漫着一种“临时感”与“末日狂欢”混合的气息——所有人都知道这个据点随时可能被“清道夫”捣毁或被更强大的势力吞并，但此刻，这里是规则之外的法外之地。
**常客**：
- **匿名贩子（如林深的“Null”）**：包裹严实，行动迅速，交易完成即消失。
- **中间人与鉴定师**：拥有固定摊位或包厢，穿着稍显体面，表情深不可测。
- **收购代理（包括“断网人”外围人员）**：举止专业，出价果断，对特定类型碎片有偏好。
- **情报贩子与掮客（如老周）**：游走于巷道，见人说人话，见鬼说鬼话。
- **好奇的富豪、绝望的能力者、寻找刺激的极客（如早期的阿飞）**：容易辨认，通常因紧张或兴奋而举止失措。
**情节重要性**：
- **故事引擎**：林深大部分前期交易在此进行，是45天倒计时压力的直接体现场所。
- **信息枢纽**：关于“断网人”的流言、关于“清道夫”动向的警告、关于稀有碎片的情报在此交汇，是林深拼图的关键碎片来源。
- **冲突爆发点**：首次遭遇“清道夫”侦察、被“断网人”代理人盯上、与竞争对手发生摩擦的关键场景都发生于此。
- **世界观的微观展示**：直观呈现异能黑市的运作规则、代价交换的冰冷本质，以及“秩序真空”地带的丛林法则。
**感官细节**：
- **声音**：低沉的通风系统轰鸣是永恒的背景音；间歇性的、从某个摊位传来的微弱、古怪的嗡鸣或嘶嘶声（碎片能量不稳定）；鞋底摩擦粗粝地面的沙沙声；压抑的咳嗽和偶尔因价格谈崩而骤然拔高又迅速压低的咒骂；远处管道冷凝水滴落的规律声响。
- **气味**：浓重的灰尘与陈旧电子元件受热的“焦糊味”是基底；混合着劣质咖啡、速食面、金属锈蚀、以及一种难以言喻的、类似臭氧或电离空气的“金属腥甜味”——高浓度异能碎片聚集产生的特殊气息。
- **纹理**：触摸墙壁是冰冷、粗糙且略带油腻的铅板感；地面常有不知名的粘腻水渍；空气潮湿阴冷，但靠近某些发热的“碎片稳定器”或人体时，能感到一阵不自然的温热。
- **光线**：整体昏暗，依赖闪烁不定的彩色光源。阴影浓重，人脸在霓虹灯下显得光怪陆离。突然亮起的终端屏幕或鉴定用的紫外灯会制造短暂的、令人目眩的强光区域。

## 2. “清道夫”第七区收容与评估设施
**别称**：“白塔”（外部代号）、“洗涤间”（内部黑色幽默）
**物理位置**：市中心某三甲医院地下，与市政应急指挥中心共享地基，有独立加密电梯直达。
**物理描述**：
极致的功能性、洁净与秩序。整个设施以白色、浅灰和金属银为主色调。走廊宽阔、笔直，天花板极高，嵌满发出均匀冷白光的面板。墙壁是光滑的无缝复合材料，可以随时冲洗消毒。房门都是气密式，带有观察窗和电子锁。区域划分严格：收容区（类似高级单人病房，但墙壁衬有特殊涂层）、审讯室（只有一张桌两把椅，单向镜）、医疗评估室（布满非标准医疗仪器）、以及核心的数据处理中心（巨大的环形屏幕墙）。一切物品都被固定或收纳，没有任何个人装饰或冗余物品。
**氛围**：
绝对的、令人窒息的**寂静**与**压抑**。声音被吸音材料吞噬，脚步声也几不可闻。空气恒温恒湿，洁净到缺乏任何“生气”。这里的时间仿佛凝固，唯一的变化是屏幕上滚动的数据和指示灯的颜色。一种系统性、非人性的权威感无处不在，提醒着访客（或囚犯）个体在此的渺小与无力。是“秩序”最冰冷、最纯粹的物理形态。
**常客**：
- “清道夫”外勤特工（如苏芮）：来交付“目标”或汇报。
- 设施内的研究员、医师、审讯专家：穿着统一的白色或浅蓝制服，表情专业而淡漠。
- 被收容的异能者或相关嫌疑人：处于高度紧张、恐惧或药物导致的麻木状态。
- 偶尔来访的高级官员或顾问（维序者可能曾以此身份来访）。
**情节重要性**：
- **旧秩序的具象化**：代表官方对异能的态度——不是研究或理解，而是“收容、评估、控制或清除”。
- **林深的终极噩梦场景之一**：他极力避免被带入这里，因为一旦进入，意味着数字身份的彻底暴露和物理自由的终结。
- **苏芮的工作环境**：在此能看到她如何在系统要求与个人良知间挣扎（例如，她对收容者报告的细微修改，或她独自在数据中心调阅矛盾档案）。
- **信息宝库与禁区**：设施数据库可能存有关于早期异能事件、“心智防火墙”项目碎片化记录，是揭开部分真相的关键，但闯入难度极高。
**感官细节**：
- **声音**：近乎绝对的静，只有空调系统极轻微的嘶嘶声、电子设备运行时几乎听不见的高频嗡鸣、以及偶尔从扬声器传来的、语调平板的指令。
- **气味**：浓烈的消毒水（异丙醇）气味，混合着臭氧和一种用于空气净化的、淡淡的柠檬化学剂味道。没有任何“人”的味道。
- **纹理**：一切都是光滑、坚硬、冰冷的。金属桌面、复合塑料椅、玻璃观察窗。连提供的纸质文件都光滑挺括。空气干燥，皮肤容易产生静电。
- **光线**：均匀、明亮、无影的冷白色照明，模拟自然光但毫无温度。没有任何阴影可以躲藏。

## 3. “摇篮”实验室 | The Cradle
**别称**：“花园”（维序者个人用语）、“核心”
**物理位置**：远郊山区，一座废弃的私人天文台地下深处。入口与天文台穹顶的机械结构联动，只有特定星图在天窗呈现时，才能触发隐秘电梯。
**物理描述**：
一个充满矛盾美感的空间。整体是未来主义的洁净实验室风格（与“清道夫”设施相似，但更高级），但其中陈列着古老的、如同博物展柜般的透明立柱。每个立柱内，在柔和的、色彩可调的背景光下，悬浮着一枚或多枚“核心异能碎片”，缓缓自转，美得惊心动魄。实验室中央是一个庞大的环形操作台，连接着多台沉默的量子计算单元和复杂的神经信号映射设备。墙壁上是巨大的屏幕，显示着全球地图，上面有无数光点（碎片信号）和连接线，其中一条主线若隐若现地指向城市方向（林深的位置）。空间一角，甚至有一个小型生态舱，里面种植着经过碎片辐射影响的奇异植物。
**氛围**：
**冰冷的精确与扭曲的崇高**。这里没有“清道夫”设施那种对人的压抑，而是一种更宏大的、对“自然规律”进行重新编译的野心所带来的压迫感。安静，但充满了能量低频涌动的“存在感”。维序者在此不是审讯官，而是造物主般的“园丁”。氛围肃穆、专注，带有一种宗教仪式般的虔诚感，但其目的却是剥离人性的、终极的技术理性。
**常客**：
- “维序者”陈序：这里是他的圣所和指挥中心。
- 少数核心研究员：绝对忠诚且分享其理念的精英科学家，沉默寡言，眼神狂热。
- 高级执行者：前来接受指令或交付特别重要的“标本”。
**情节重要性**：
- **反派大本营与终极目标展示**：直观呈现“断网人”的技术实力、维序者的美学与野心，以及全球掠夺网络的骇人规模。
- **真相揭示的关键场景**：林深可能在最终对决前或通过某种方式（如阿飞骇入内部网络获取的实时影像）窥见此地，从而理解维序者计划的完整面貌和残酷美感。
- **林深“起源”的关联点**：实验室的技术与“心智防火墙”项目一脉相承，这里的设备可能就有当年用于改造他的原型机。
- **最终高潮的可能地点之一**：林深或许需要潜入或远程攻击此处，以破坏全球网络的“控制端”。
**感官细节**：
- **声音**：量子计算机运行时产生的、几乎超越人耳感知范围的极低频嗡鸣，带来一种发自胸腔的压迫感；生态舱内模拟的自然风声与流水声，显得异常空洞；碎片悬浮柱偶尔发出的、如风铃般清脆但冰冷的能量共鸣音。
- **气味**：洁净的空气里，有一丝微弱的、类似雨后石英和冷金属的味道，混合着生态舱传来的湿润土壤与奇异植物的清冷芬芳（有些类似薄荷与铁锈混合）。
- **纹理**：操作台是温润的黑色复合材料，触感如玉石；悬浮柱外罩光滑冰冷；地面是导热性良好的金属格栅。空气微凉且带电离子含量略高，皮肤能感到微微的刺麻感。
- **光线**：主要光源来自碎片自身的辉光和屏幕的冷光。整体幽暗，但关键区域被精确聚焦的暖白色或淡蓝色光柱照亮，明暗对比强烈，充满戏剧性和神圣感。

## 4. 林深的“蜗居”安全屋
**别称**：无（林深尽可能避免给它任何称谓，以防产生依恋）
**物理位置**：老周管理的、位于老城区的某栋筒子楼顶层尽头房间。楼下是喧闹的市集，隔壁是永远在打麻将的邻居。
**物理描述**：
一个不到三十平米的单间，拥挤、杂乱，但乱中有序。房间被他自己用书架和隔音板材粗糙地分割成“生活区”和“工作区”。生活区只有一张行军床、一个小冰箱和一个电磁炉。工作区则是核心：一张占据半面墙的长桌上，摆着三台经过深度改装的显示器（常亮）、多个路由器与信号扰断器、一台自组装的服务器塔，以及各种焊接工具、拆开的电子设备。墙上贴满了便签纸，上面是潦草的代码片段、碎片交易暗号、手绘的关系图谱和时间线。窗户被厚重的遮光帘封死，唯一的“装饰”是贴在显示器边缘的一张小小的、已磨损的林浅的照片。
**氛围**：
**偏执的安宁与孤独的战场**。这里是林深对抗外部世界的堡垒和茧房。门外的市井喧嚣被隔音材料过滤成模糊的背景音，屋内只有设备风扇的低鸣。空气凝滞，充满了独居男性的气息（咖啡、即食食品、电子元器件发热的味道）。这是一个高度功能化、为生存和赎罪而存在的空间，没有任何享受生活的痕迹，唯一柔软的部分属于已逝的过去。它既是一个精密的作战指挥所，也是一个自我囚禁的牢笼。
**常客**：
- 林深本人（绝大多数时间）。
- 阿飞（不请自来，经常带来零食和麻烦）。
- 老周（上门收租、传递消息或蹭饭）。
**情节重要性**：
- **主角内心世界的外化**：环境的封闭、杂乱、高度技术化和缺乏生活气息，直接反映林深的情感隔离、生存焦虑、对技术的依赖以及对过去的执着。
- **计划与喘息的空间**：林深在此分析情报、准备交易、与阿飞远程协作、在头痛发作后独自忍受痛苦。是他从外部高压中暂时抽离的“缓冲区”。
- **关系发展的私密场所**：阿飞的闯入和老周的到访，是外部世界“侵入”他个人空间的象征，也是他被迫进行有限社交、建立脆弱联结的场景。
- **安全感的象征与丧失**：当这个地点最终暴露，被“清道夫”或“断网人”闯入或监控时，意味着林深最后一点脆弱的安宁被剥夺，将极大提升其危机感和故事紧张度。
**感官细节**：
- **声音**：多台设备风扇持续不断的“白噪音”般嗡鸣；键盘快速敲击的清脆响声；偶尔从老旧冰箱传来的压缩机启动的沉闷震动；隔壁麻将牌的碰撞声和模糊的人声透过墙壁隐约传来。
- **气味**：浓郁的现磨咖啡豆香气（林深依赖咖啡因）、即食火锅或泡面的调味剂味道、电子元件长时间工作产生的淡淡焦糊味、以及旧书和灰尘的气息。一种“脑力劳动”与“将就生活”混合的独特气味。
- **纹理**：桌面有咖啡渍和焊接留下的灼痕；键盘按键已被磨得光滑；遮光帘厚重粗糙；行军床的帆布面料硬挺。空气因为设备发热而微暖干燥。
- **光线**：主要光源来自多块显示器的冷白光，在黑暗中映亮林深专注或疲惫的脸。其他区域隐藏在阴影中。没有自然光，时间感在此模糊。

## 5. 老周的“二手轮回”铺
**别称**：“周记电器维修”（合法招牌）、 “安全屋”（对极少数熟客）
**物理位置**：林深所住筒子楼临街的底层商铺，前后通透。前面是堆满旧电视、收音机、电风扇的维修铺面，后面是堆满更“特殊”货品的仓库兼老周的起居室，有一道隐蔽后门通往楼内。
**物理描述**：
前面铺面拥挤、杂乱但充满生活气息。玻璃柜台里摆着各种零件，墙上挂满待修电器，工作台上永远是拆到一半的机芯和松香的味道。后面仓库则别有洞天：货架上除了常规二手电器，还有各种来路不明的电子设备（监听反制器材、改装过的手机、信号增强器）、奇怪的“工艺品”（可能是低阶异能碎片做成的护身符或装饰）、以及几个上锁的保险柜。一张油腻的折叠桌是吃饭、谈生意、打牌的多功能场所。角落里一张行军床，床上被子从未叠过。整体光线昏暗，仅靠几盏瓦数不高的灯泡照明。
**氛围**：
**危险的亲切与精明的混沌**。前面是市井的、温情的、可以讨价还价的寻常世界；后面是灰色地带的、秘密的、真假难辨的交易场。老周在这里如鱼得水，能在修老大爷的收音机和跟黑市掮客谈“传感器”价格之间无缝切换。氛围松弛中带着警惕，看似杂乱无章，实则每样“特殊”物品的摆放只有老周自己清楚。这里是市井生存智慧与地下世界规则的结合部。
**常客**：
- 街坊邻居（修家电、买二手货）。
- 林深（走后门，进行情报交易或获取特殊装备）。
- 各路情报贩子、跑腿的、销赃的、打听消息的灰色人物。
- 偶尔有“清道夫”的便衣或“断网人”的眼线伪装成顾客前来摸底。
**情节重要性**：
- **信息与物资的中转枢纽**：林深许多非核心情报和小型装备由此获得，是剧情推进的实用节点。
- **喜剧效果与节奏缓冲**：老周与街坊、与林深、与各路牛鬼蛇神的互动，提供了大量市井笑料和鲜活细节，缓解主线高压。
- **连接“正常”与“异常”世界的桥梁**：通过这个铺子，读者能看到异能黑市如何像毛细血管一样渗透进最普通的社区生活。
- **危机预警与安全阀**：老周往往能最早从市井流言或“客户”的异常举止中嗅到危险（如“清道夫”的排查或新势力介入），为林深提供宝贵（虽然常被抱怨夸大其词）的预警。
- **情感纽带的具现地**：林深与老周那种“互相嫌弃又互相依赖”的关系，大部分在此铺陈和发展。老周女儿偶尔出现送饭的场景，也会为这个灰暗世界注入一丝真实温暖的微光。
**感官细节**：
- **声音**：前面铺面：收音机里咿咿呀呀的戏曲、老式电扇的嗡嗡声、焊接的滋滋声、老周与顾客的讨价还价声。后面仓库：压低的谈话声、点钞机的沙沙声、旧电器通电测试时的杂音。
- **气味**：前面：松香、焊锡、旧金属、灰尘的味道。后面：除了前面的气味，还多了泡面、隔夜饭菜、潮湿霉味，以及某些“特殊物品”散发的、难以描述的微弱异味（如处理过的生物组织或能量残留）。
- **纹理**：到处都是油腻和灰尘。柜台玻璃模糊，工具手柄被磨得光滑，旧电器的塑料外壳发黄变脆。空气闷热潮湿（尤其夏天）。
- **光线**：前面靠自然光和日光灯，明亮但杂乱。后面仓库光线昏暗，仅有的灯泡在堆积的货物上投下浓重的阴影，适合进行不想被看清面孔的交易。

**地点构建完成**。这五个地点构成了《异能掠夺》世界的主要舞台：
- **深网集市**是**冲突与交易的漩涡**。
- **“清道夫”设施**是**旧秩序冰冷的心脏**。
- **“摇篮”实验室**是**新秩序扭曲的子宫**。
- **林深的蜗居**是**主角孤独的堡垒与内心镜像**。
- **老周的铺子**是**连接一切、提供缓冲与温度的市井节点**。

它们从氛围、功能到感官细节都截然不同，但共同服务于故事的悬疑、讽刺基调，并为角色行动提供可信、富有张力的环境。
