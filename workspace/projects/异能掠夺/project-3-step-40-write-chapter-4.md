# Write Chapter 4

# 第4章：老周的“安全屋”

老周的铺子永远散发着同一种味道——焊锡的焦甜、机油的黏腻，还有旧电器塑料外壳受热后挥发出的、类似烧焦糖果的化学气息。林深推开“二手轮回”那扇吱呀作响的玻璃门时，这股味道裹着暖烘烘的空气扑了他一脸，像一只油腻腻的手。

凌晨五点十分。街上只有扫街车缓慢驶过的嗡鸣，和远处早点摊隐约的锅铲碰撞声。铺子里灯只开了后面仓库的一盏，昏黄的光晕在堆积如山的旧电视、收音机和叫不出名字的金属零件上切割出浓重的阴影。老周系着那条永远洗不干净的深蓝色围裙，正撅着屁股在一个打开的示波器壳子里捣鼓什么，后脑勺几根稀疏的头发在灯光下泛着油光。

林深没出声，反手带上门，门楣上的铜铃清脆地响了一声。

老周动作一顿，没回头，肩膀却几不可察地松弛了半分。“来啦？”他拖长声音，从工作台底下摸出一个用防静电袋裹着的扁平盒子，随手扔在油腻的台面上，“你要的‘钥匙扣’。先说好，这玩意儿理论干扰时长只有九十秒，实际使用环境复杂，打个七折，六十三秒。过时就自求多福。”

林深拿起盒子，拆开。里面是一个比信用卡略厚的黑色塑料片，边缘有微型接口，表面光滑得像块鹅卵石。他插上便携测试仪，屏幕跳出一串快速滚动的参数。有效，能量波形模拟得很干净，足以骗过大多数民用级生物识别系统。老周的手艺，在灰色地带里算是顶尖。

“钱转了。”林深收起干扰器，声音因为长时间没说话而有些沙哑。

老周这才转过身，一张圆脸上挂着眼袋，胡茬没刮干净。他没接话茬，而是拿起一旁的旧搪瓷缸子喝了口浓茶，咂咂嘴，眼神在昏暗中打量着林深。“气色比鬼还差。”他评论道，语气里听不出是关心还是纯粹陈述事实，“那宅子，我后来又托人问了点细节。”

林深看着他，没动。

老周压低声音，身体前倾，带着一股茶叶和陈年汗味的气息：“安保升级是没错，但重点不是硬件，是‘人’。李老板最近搭上了一条新线，给宅子做安全顾问的，是‘科盾’的人。”

科盾。一个名字正经、在各大企业安全招标中频繁出现的私营安保公司。表面光鲜，背地里承接的业务范围……要广得多。据说他们有一些特殊的“风险评估师”，专精于处理常规手段无法解释的“异常状况”。

“这单生意，科盾那边派了个姓赵的顾问，四十来岁，戴眼镜，看起来像个教书先生。”老周声音更低了，“但道上有人传，这姓赵的……‘眼睛’很毒。不是比喻。他经手的地方，没丢过东西，但好几个试图摸进去的‘梁上君子’，事后都‘意外’进了医院，查不出外伤，就是精神恍惚，记不清事。”

异能。或者至少，是接触过异能、并懂得利用其残留效应进行防御的人。

林深脸上没什么表情，只有左手拇指习惯性地按上了手腕的疤痕，缓慢摩挲。“知道了。”

“知道个屁。”老周啐了一口，也不知是啐茶叶沫子还是啐林深的反应，“这还没完。你那‘瞬时记忆强化’碎片的消息，不止你在盯。大概三天前，有个中间人联系我，不是熟面孔，但开价很高，高得离谱。他要的不是碎片，是碎片原宿主的**所有信息**——姓名、背景、社会关系、医疗记录，越详细越好。”

林深摩挲疤痕的动作停了一瞬。

黑市的规矩，交易碎片，不问出处。这是保命的基本法则。打听原宿主详细信息，要么是寻仇，要么是……追踪某种关联。这不像是买家，更像是猎手在确认猎物气味。

“什么来路？”林深问。

老周摇头，脸上的肉随着动作颤动：“不清楚。联络一次就切，用的都是临时加密信道，钱走的是海外多重混淆的虚拟币，根本追不到源头。但那种做派，那种……不惜代价也要挖到底的劲头，不像咱们这摊浑水里的鱼。”他顿了顿，浑浊的眼睛盯着林深，“小林，听我一句，这单‘瓷器活’，你那点‘金刚钻’可能不够看了。水太浑，底下有大东西在翻腾。”

是警告，也是老周式的自保。他提供了情报，摆明了风险，仁至义尽。接下来林深怎么选，是他的事，别连累铺子。

林深把干扰器塞进外套内袋，金属外壳贴着肋骨，传来微微的凉意。“谢了。”他说，语气依旧平淡，听不出情绪，“最近风紧，你自己也小心。‘雨燕’折了。”

老周瞳孔猛地一缩。“什么时候？在哪儿？”

“昨晚。集市。清道夫动的手。”林深简单说道，没提“窃神者”塞U盘的事。

老周的脸色在昏黄灯光下变得有些难看。他抓起搪瓷缸子又灌了一大口茶，喉结剧烈滚动。“妈的……连‘雨燕’这种滑不留手的泥鳅都逮住了……”他喃喃道，眼神飘向堆满杂物的店铺深处，仿佛那里面藏着窥探的眼睛，“这世道，真是越来越没法混了。”

就在这时，前门那扇玻璃门上的铜铃，又清脆地响了一声。

叮铃——

不是被风吹的。是有东西，或者有人，触动了门。

林深身体瞬间绷紧，像一张拉满的弓。他没回头，但全身感官已如蛛网般撒向门口方向。右手自然下垂，指尖离绑在小腿上的战术匕首柄只有一寸。

老周也吓了一跳，手里的搪瓷缸子差点掉地上，茶水泼出来一些，在他油腻的围裙上晕开更深的一块污渍。“谁啊？这么早……”他嘟囔着，伸长脖子往前店看。

店铺前半部分没开灯，只有街边路灯惨白的光，透过脏兮兮的玻璃门渗进来，勾勒出一个站在门口的人影。

那人影不高，有些单薄，背着一个鼓鼓囊囊看起来就很沉的背包。他似乎在打量店铺里昏暗的环境，然后，径直朝着后面有光的仓库区走了过来。

脚步声很轻，带着点年轻人特有的、弹性过足的跳跃感。

人影走入昏黄光晕的范围。

是个男孩。看起来顶多二十岁，头发有点乱，戴着一副有点过时的黑框眼镜，镜片后的眼睛在灯光下亮得惊人。他穿着一件印满复杂电路图和不明符号的白色T恤，外面套了件不太合身的工装马甲，上面别着好几个造型奇特的徽章和数据线接口。脸上带着一种混合着巨大兴奋和紧张的红晕，嘴角咧开，露出两颗有点尖的虎牙。

他的目光像探照灯一样，瞬间就锁定了仓库里除了老周之外的另一个人——林深。

然后，那双发亮的眼睛里，爆发出近乎狂热的、找到宝藏般的光芒。

“前——辈——！”

陈飞，或者说，“窃神者”，用他那完全不知道压低音量、充满了舞台剧般张力的声音，大喊着，朝着林深的方向猛地踏前一步，差点被地上散乱的电缆绊倒。

老周手里的搪瓷缸子，“哐当”一声，彻底掉在了地上。劣质搪瓷碎裂，深褐色的茶水和茶叶沫子溅得到处都是。他张大嘴，看着这个突如其来的、活像从某个动漫展逃出来的生物，又看看脸上瞬间结了一层寒霜的林深，脑子显然还没处理完这超载的信息。

林深没动。他甚至没有完全转身面对陈飞。只是微微侧过头，用眼角的余光，冷冷地扫了那个激动得浑身发颤的年轻人一眼。

那一眼，没有任何温度。像手术刀划过皮肤，精准地剥离了所有情绪，只剩下纯粹的、评估威胁等级的审视。

仓库里温暖的、混杂着各种气味的空气，仿佛瞬间被抽空了。取而代之的，是一种令人窒息的、金属般冰冷的寂静。只有老周粗重的喘息声，和陈飞因为兴奋而略微急促的呼吸。

陈飞似乎被林深那一眼冻了一下，但眼中的火焰丝毫没有熄灭。他深吸一口气，努力让自己的声音听起来不那么飘，但那股子中二的热血劲儿还是从每个字缝里往外溢：“我、我终于找到您的实体安全屋了！这真是历史性的时刻！请务必允许我，您最忠诚的追随者，‘窃神者’，加入您下一次伟大的‘破晓行动’！我带来了诚意和我的——”

“你怎么找到这里的。”

林深打断了他，声音不高，甚至算得上平静。但每一个字都像冰锥，砸在寂静的空气里。

陈飞噎了一下，但立刻语速飞快地回答：“交叉验证！您之前用来接收我消息的那个加密信道，虽然跳转了十七次，但在第九次跳转时，有一个极其微弱的、持续了0.05秒的本地网关响应延迟，我对比了全市所有可能产生这种延迟的片区网络负载模型，结合您之前活动时间规律和‘集市’事件后的最优撤离路径概率计算，再筛选这个片区符合‘隐蔽、老旧、有可靠中间人’特征的物理节点，最终将概率最高的三个地点进行实地——”

“说人话。”

“我黑了附近三个街区的公共监控，用行为模式识别算法筛出了最近一周所有在深夜单独进入这个片区、且行踪反侦察意识强的热源信号，最后跟着一个最像您的背影，走到这街口，看见这家店名，觉得风格很搭，就进来碰碰运气！”陈飞一口气说完，眼睛眨巴着，带着点邀功的意味，“没想到真的……呃！”

他话没说完，因为林深动了。

不是大幅度的动作。只是肩膀极其细微地沉了一下，重心前移。整个人的姿态，从静止的磐石，变成了一张即将离弦的弩。没有杀气外泄，但那瞬间凝聚的、仿佛连光线都能割裂的专注力，让仓库里本就稀薄的空气再次骤降几度。

老周腿一软，差点坐倒在身后的零件堆里。他活了四十多年，三教九流见过不少，但此刻林深身上散发出的那种气息——那不是街头斗狠的凶戾，而是一种更冰冷的、源于绝对理性评估后，准备**清除障碍**的决断——让他骨髓都发凉。

陈飞脸上的兴奋红潮也瞬间褪去，变得有些苍白。他不是傻子，他能感觉到那锁定了自己的、无形的压力。那不是游戏里的BOSS战前奏，这是真实的、生命受到威胁的寒意。他喉结滚动了一下，镜片后的眼睛里闪过一丝慌乱，但更多的是一种倔强的、不肯退缩的光。

就在林深右手手指即将触碰到匕首柄的前一刹那。

陈飞猛地举起双手，做出一个夸张的、投降般的姿势，但声音却压得极低，快得像是在倒豆子：“前辈！我没有恶意！账户尾号3872、5501、还有昨天刚走完流程的‘星海’项目洗钱通道第三中转户！我可以帮您优化路径，节省至少百分之五点三的损耗！我能找到‘科盾’那个姓赵的顾问的公开行程和非公开心理健康评估报告！我能实时监控‘集市’周边三个街区的所有官方和非官方通讯频段！我对您有价值！非常大的价值！”

他一口气报出林深最近使用的、最隐秘的几个资金渠道的尾号，甚至包括一个昨晚才完成第一次跳转、理论上不可能被追踪的新路径。

林深的手指，在距离匕首柄不到半厘米的地方，停住了。

他冰冷的目光落在陈飞因紧张而微微冒汗的额头上，又缓缓移向他那双举在空中、有些发抖却努力张开表示无害的手。年轻人T恤上那些复杂的电路图，在昏黄灯光下像某种神秘的符文。

时间在粘稠的寂静中，被拉长、挤压。

老周屏住呼吸，眼睛瞪得溜圆，看着林深，又看看那个不知死活的愣头青，觉得自己心脏快要从嗓子眼里蹦出来了。他手里下意识地摸到了工作台上的一把重型扳手，冰凉的金属触感让他稍微定了定神，虽然他知道，如果林深真要动手，这玩意屁用没有。

足足过了五秒钟——在老周感觉里像五个小时——林深那绷紧如弓弦的肩膀，极其缓慢地，松弛了微不可察的一丝。

他没有收回目光，依旧盯着陈飞，但开口时，那冰锥般的语气稍微缓和了那么一点点，变成了北极冻原上刮过的风：“二十四小时。”

陈飞愣了一下：“……啊？”

“李泽楷宅邸，最新安装的‘萤火虫IV型’动态感应系统。”林深一字一句，清晰冰冷，“我要它的核心算法特征码，至少三个不同环境变量下的实时响应数据模型，以及，它自学习模块在过去七十二小时内的增量更新日志。”

他顿了顿，补充道：“无声获取。不能触发任何防御机制或警报记录。任何形式的追踪反噬，你自己处理。”

这是测试。一个几乎不可能的测试。也是画下的一条线：证明你的价值，同时，离我远点。做得到，或许有资格被“利用”；做不到，或者惹出麻烦，那就后果自负。

陈飞的眼睛，在听到“萤火虫IV型”和那些具体技术要求的瞬间，就像被点燃的镁条一样，“唰”地亮了起来。之前的慌乱和苍白一扫而空，取而代之的是一种近乎朝圣般的专注和兴奋。他放下举着的手，扶了扶眼镜，胸膛因为激动而微微起伏。

“核心算法特征码……环境变量响应模型……自学习增量日志……”他喃喃重复着，手指无意识地在空中虚点，像是在敲击无形的键盘，“‘萤火虫IV型’，基于多传感器数据融合和混沌边缘判定……需要绕过它的动态基准线校准协议……有意思……太有意思了！”

他猛地抬头，看向林深，脸上绽放出一个巨大无比、几乎能照亮这昏暗仓库的笑容，用力一点头：

“明白！‘窃神者’接受使命！二十四小时！不，二十小时之内，我将为您献上打开那扇‘叹息之门’的钥匙！”

说完，他竟不再多看林深和老周一眼，猛地转身，背着那个鼓鼓囊囊的大背包，像一阵风一样冲出了仓库，穿过前半间昏暗的店铺。玻璃门上的铜铃再次急促地响了一声，叮铃当啷，他的人影已经消失在门外熹微的晨光里。

仓库里，又只剩下林深和老周两个人。

还有一地的碎瓷片、茶水渍，和空气中尚未完全消散的、属于那个中二少年的、炽热又混乱的能量场。

老周长长地、颤巍巍地吐出一口气，松开手里握得死紧的扳手，金属砸在木台面上，发出沉闷的一声。他腿一软，靠着工作台滑坐到一个小板凳上，抹了把额头，发现全是冷汗。

“我……我滴个乖乖……”他声音发飘，像是刚从水里捞出来，“这小子……到底是从哪个石头缝里蹦出来的孙猴子？他刚才说的那些……都是真的？”

林深没有回答。他走到仓库角落一个老旧的洗手池边，拧开生锈的水龙头，用冰冷的自来水冲了冲脸。水珠顺着他瘦削的下颌线滴落，打湿了连帽衫的领口。他看着镜子里自己那张疲惫、苍白、眼窝深陷的脸，和镜中身后老周惊魂未定的模样。

手腕上的疤痕，在冷水刺激下，传来清晰的、细密的刺痛。

麻烦。一个巨大的、不可预测的、活蹦乱跳的麻烦。

但他报出了那些账户尾号。他对“科盾”和“赵顾问”有反应。他眼里那种看到高难度技术挑战时迸发的、纯粹的光芒，不像伪装。

一个有着致命缺陷（中二、不可控）的……顶级工具。

林深关掉水龙头，扯过一旁搭着的、也不知道干不干净的旧毛巾，胡乱擦了把脸。他走回工作台边，从老周的工具箱里拿出一把螺丝刀，开始沉默地拆卸那台坏掉的示波器外壳。动作稳定，精准，仿佛刚才那剑拔弩张的十几分钟从未发生过。

老周看着他这副样子，张了张嘴，想说什么，最终只是叹了口气，弯腰去收拾地上的碎瓷片。瓷器刮擦水泥地面的声音，在寂静中显得格外刺耳。

过了好一会儿，林深才开口，声音已经恢复了平时的平淡沙哑，听不出情绪：“铺子前后门的监控，加密等级提到最高。最近少接生客。”

老周动作一顿，闷闷地“嗯”了一声。

又过了几分钟，林深放在外套内袋里的、经过多重加密的备用手机，轻微震动了一下。

他拿出来，点亮屏幕。是一条匿名信道发来的信息，没有任何文字，只有一个加密附件。他点开附件，解码后，是一张拍摄角度隐蔽的照片。

照片上，李泽楷那标志性的微秃头顶和定制西装清晰可辨。他正站在一艘豪华游艇的甲板上，对着镜头方向（偷拍者）举杯微笑。背景是深蓝色的海面和更远处的城市天际线。照片的元数据被打上了时间戳：**拍摄于今日凌晨四时二十分**。

信息附带了游艇的名字、停泊码头，以及一行小字标注：

**“慈善派对，为期三晚。泊位已确认。宅邸主要人员随行。”**

窗口。确定了。

林深删除了信息和附件，收起手机。他继续着手头拆卸示波器的动作，螺丝刀旋转，金属部件分离，发出规律而轻微的声响。

窗外，天色正在一点一点变亮。城市的轮廓从深蓝的夜幕中挣扎出来，染上灰白的光边。早班公交车的引擎声由远及近，又渐渐远去。

仓库昏黄的灯光下，老周终于收拾完了地上的狼藉，坐回小板凳上，点起一支廉价的香烟，闷头抽着。烟雾缭绕，混入空气里原有的各种气味。

林深将拆下的电路板放在台面上，目光落在上面密密麻麻的元件和焊点上。他的思绪，却仿佛穿透了这层物理的阻隔，落在了别处。

落在那个像风一样冲进来的中二少年，和他背上的那个鼓鼓囊囊的背包上。

落在陈飞最后离开时，那双镜片后燃烧着熊熊火焰的眼睛上。

落在……自己刚刚提出的，那个几乎不可能在二十四小时内完成的任务上。

他需要那枚“瞬时记忆强化”碎片。需要那笔钱。需要按计划推进，从这团越来越浓的迷雾里，撕开一个逃出生天的口子。

但现在，计划里，被强行塞入了一个新的、活生生的、会说话会激动会喊“前辈”的变量。

这个变量，此刻或许正坐在某个堆满零食和屏幕的房间里，对着“萤火虫IV型”的系统架构图，两眼放光，手指在键盘上敲出残影，试图在二十小时内，创造一个小小的奇迹。

或者，一个巨大的灾难。

林深放下螺丝刀，拿起旁边一块擦拭用的麂皮，慢慢擦拭着指尖并不存在的油污。他的脸上依旧没有任何表情，只有眼底深处，掠过一丝极其细微的、连他自己都未必察觉的波澜。

像平静的深潭，被一颗意外投入的石子，搅动了最底层一丝沉淀的泥沙。

窗外，天光大亮。崭新的一天，带着它所有的未知和风险，无可阻挡地降临了。

而二十四小时的倒计时，已经开始。
