# Write Chapter 2

# 第二章：不请自来的信徒

入侵警报在凌晨四点十七分触发。

不是外围的试探——林深布设的数字防线有七层，从伪装成普通端口的蜜罐到基于行为模式的动态规则。触发的是第三层，一个基于异常流量熵值计算的隐形传感器。这意味着入侵者绕过了前两层粗筛，技术不错，但又在第三层暴露了踪迹。

林深从浅眠中惊醒。

他没有睁眼，保持呼吸平稳，但大脑已经清醒得像被冰水浇过。右手滑到枕头下，握住那把改装过的电击器。左手在黑暗中摸到床头柜上的手表，指尖轻触表盘侧面。

表盘亮起微光，投射出一个半透明的全息界面，悬浮在他眼前二十厘米处。线条和数据流快速滚动。

入侵路径被标成红色，在虚拟的网络拓扑图上蜿蜒。方式很……花哨。对方没有用常规的漏洞扫描或暴力破解，而是在林深自己设置的几个伪装服务之间跳转，像是在玩某种解谜游戏。每次跳转都留下一点冗余代码，代码风格华丽，带着不必要的注释和格式。

“窃神者向阴影中的传奇致敬！请求觐见，共商大计！”——这是其中一段注释。

林深眼神沉下去。

这不是“清道夫”的风格。那些穿制服的猎手行事直接、高效，像手术刀。这更像个……玩家。或者说，疯子。

他坐起身，行军床的帆布发出轻微的摩擦声。房间依然黑暗，只有全息界面幽蓝的光映亮他半张脸，眼下顽固的青黑在光影下更深了。头痛的余韵还在颅骨内侧隐隐搏动，像远去的雷声。

没有开灯。他赤脚走到工作区，三台显示器中的一台自动亮起，显示入侵的实时分析。

路径很混乱，但有效。对方利用了林深自己搭建的几个中继节点之间的信任关系，像是提前研究过他的架构习惯。核心跳板的IP地址在快速变换，但最终落脚点——在经过三次反向追踪和解密后——指向本地科技大学的主服务器。

一个学生？或者藏在校园网里的自由黑客？

林深的手指在键盘上快速敲击。他需要确认威胁等级。如果只是好奇心过剩的极客，他有七种方法让对方无声无息地消失——至少从数字世界。如果是陷阱，是“清道夫”或“穿黑袍的”设下的诱饵，那就要更谨慎。

他调出那个落脚点的访问日志。入侵者在过去四小时内，从那个节点发起了十七次试探，每次试探都附带一段不同的……留言。

“前辈的防火墙架构真美！像黑夜里的星图！”
“第三跳的加密协议用了改良的XXTEA？酷！”
“我通过了您的第七道谜题！可以给个见面机会吗？”
“我的代号是‘窃神者’！目标是成为深网的传说！”
“附件是我破解您第二层动态规则的心得，请指教！”

附件是真的。里面详细分析了林深自己设计的一个自适应规则引擎，指出了三个理论上的弱点——虽然其中两个林深早就设置了反制陷阱，但第三个确实是他疏忽的边界情况。

技术天赋极高。缺乏纪律。表现欲过剩。

林深靠进椅背，右手拇指习惯性地摩挲左手腕的疤痕。疤痕在黑暗里微微发烫，不是疼痛，更像某种生理性的警示。

他需要决定如何处理这个变量。

直接封杀最简单。他可以编写一个定向的恶意代码包，通过对方留下的路径反向注入，烧毁其硬件或抹除数据。但这样会暴露他的一部分技术特征，而且可能打草惊蛇——如果这真是某个组织的诱饵。

暂时观察？风险在于这个“窃神者”可能继续深挖，甚至无意中触及林深真正的核心：那些洗钱路径、碎片交易的暗网联络点、以及关于“心智防火墙”和自身记忆的加密档案。

或者……接触。

林深盯着屏幕上那句“请求觐见，共商大计”，眼神冰冷。他不需要共犯，不需要信徒。他需要的是在四十五天内凑够钱，还清债务，然后消失。任何额外的人际连结都是弱点，都是可能被利用的杠杆。

妹妹空洞的眼睛在记忆里一闪而过。

他闭上眼，深吸一口气。空气里有隔夜咖啡的酸涩和电子元件发热的微焦气味。

决定做出来了。

他新建了一个完全隔离的虚拟环境，在里面编写了一段代码。不是攻击性的，更像是一个测试——一个基于图灵变体的逻辑谜题，嵌套了四层加密和一次性的动态密钥。题目本身没有实际意义，纯粹考察解题者的逻辑能力、密码学知识和……耐心。

他将这段代码封装，附上一句话：“解出来，再说话。”

然后通过对方留下的一个中继节点，匿名发送回去。

做完这些，他切断了那个节点与自己真实网络的所有关联，清除了临时环境。就像从没发生过。

窗外天色开始泛灰。凌晨五点了。

林深揉了揉太阳穴，那里又开始隐隐作痛。他起身烧水，从冰箱里拿出昨晚剩下的半罐冷咖啡，直接倒进嘴里。苦涩的液体滑过喉咙，带来短暂的清醒。

他需要专注在真正重要的事上：云栖苑7号，那枚“瞬时记忆强化”碎片。

老周发来的加密包已经解码。图纸确实粗糙，但关键信息都在：建筑结构、监控摄像头大致位置、供电线路入口。巡逻时间表更详细——两个固定岗每四小时换班，流动岗的路线有细微规律，在凌晨三点到四点之间，后花园区域的监控会因为系统自检有十七秒的盲区。

十七秒。够他从围墙翻进去，避开地面传感器，抵达书房正下方的工具间。

但真正的难点在书房内部。生物识别锁、动态感应阵列、还有那个伪装成艺术品的保险箱。老周的朋友没画出保险箱的具体型号，只说“连着主警报系统”。

林深调出王启明——那位矿产富豪——的公开信息。六十二岁，热衷慈善和艺术品收藏，最近三年开始投资“前沿心理学研究”。有两次离婚记录，三个成年子女，都不在身边。典型的独居富豪，怕死，多疑，钱多到可以买任何他认为能带来安全感的东西。

这类人通常有个共同点：他们相信技术，但不完全理解技术。他们会买最贵的系统，但不会亲自设置。他们会依赖“专家”，但永远留一手。

林深开始编写潜入脚本。

首先需要骗过动态感应阵列。那东西的原理是分析房间内的红外热图变化模式，识别出“人类形状”的移动。阿飞——那个“窃神者”——如果能提供这种新型阵列的核心算法特征，他就可以编写一个干扰程序，让传感器“看到”的是一片稳定的、无人移动的热图背景。

但阿飞能否在二十四小时内做到，是个未知数。林深不能把赌注全押在一个疯癫的黑客身上。

他设计了一个备用方案：利用老周提供的供电线路信息，在潜入前十七分钟，对宅邸的独立供电系统进行一次微弱的电压波动干扰。这种波动会触发安保系统的自检程序，届时动态感应阵列会短暂切换到低灵敏度模式，持续大约九十秒。

九十秒，从工具间到书房，打开保险箱，取出碎片，撤离。

风险在于电压波动可能被记录，引起后续调查。而且，如果王启明雇佣的“前安保公司顾问”足够专业，他们可能设置了针对此类干扰的次级警报。

林深需要更多信息。关于那个保险箱。

他再次调出深网的几个隐秘论坛，输入几个关键词：“艺术品伪装保险箱”、“生物识别+物理锁”、“高端私人安保定制”。信息很少，大多是吹嘘和广告。但在一个需要邀请码才能访问的、讨论“非标准收藏品保管”的小板块里，他找到一条三年前的旧帖。

发帖人自称参与过某个中东富豪的安全屋设计，提到一种德国制造的“幻影”系列保险箱。外壳可以定制成任何艺术品形态，内置双重验证：指纹或虹膜生物识别+一组六位数的机械密码转盘。最阴险的是，如果验证失败超过两次，或者箱体受到异常震动，它会自动向预设的五个紧急联系人发送加密坐标，并释放一种高浓度催眠气体。

帖子里没有说如何破解，只留下一句：“对付‘幻影’，你需要的是时间，不是技术。或者，你需要知道主人设置密码时的习惯。”

林深截下这条信息。

习惯。王启明六十二岁，做矿产起家，白手起家。这类人往往怀旧，喜欢用有纪念意义的数字：公司成立日期，第一次收购成功的日期，子女生日，结婚纪念日——虽然他离婚两次。

公开信息显示，王启明的矿业公司“启明资源”成立于三十八年前的十月十二日。第一次重大收购是在二十四年前的六月七日。长子出生于四十一年前的三月十八日。两次结婚分别在三十五年前和二十二年前。

六个数字的组合。可能性太多。

林深需要一个能短暂干扰生物识别系统的装置。老周答应今天交货，但那种市面买不到的定制玩意，老周从哪里搞来？又是哪个“朋友”？

他想起老周警告的“穿黑袍的”。那些气质冰冷、出价诡异、打听原宿主详细信息的买家。

左手腕的疤痕又开始发烫。他停下敲击键盘的手指，用力按压疤痕，直到疼痛盖过那种古怪的灼热感。

屏幕右下角，一个加密通讯窗口突然弹出。

是“窃神者”。

消息很短，附带一个文件：“前辈，第一个挑战完成！这是我的解题过程和思路导图！另外，您对‘集市’东南角第三个摊位今天新到的那批‘灰烬’不好奇吗？我有内部消息哦。”

附件之后，是一张图片。

林深点开。

那是一张监控截图，角度刁钻，像是从某个通风口或者隐藏摄像头拍摄的。画面里是“深网集市”那个熟悉的、堆满废弃服务器的角落。第三个摊位前，站着一个穿着深灰色羊毛大衣的男人，背影挺拔。他手里拿着一个巴掌大的银色仪器，正在检测摊位上几块色泽黯淡的碎片——正是林深昨天看到的那种“灰烬”。

截图只有侧后方角度，看不清男人的脸。但林深注意到几个细节：大衣剪裁合身，面料昂贵；皮鞋一尘不染，与集市污浊的地面格格不入；检测仪器的造型极其简洁，没有任何品牌标识，表面有细微的散热孔——那是高性能便携分析仪的特征。

最重要的是，在截图边缘，男人脚边的地面上，放着一个黑色的皮质公文包。公文包的搭扣上，有一个徽记的模糊反光。

林深放大那个区域。

图像像素有限，但能勉强辨认：那是一个几何图形，像是两个嵌套的圆环，圆环之间填充着细密的电路纹路。图形下方似乎有一行小字，但完全模糊了。

他盯着那个徽记，呼吸不自觉地变缓。

然后，他看向“窃神者”消息的最后一句：

“PS：截图里的‘绅士’，半小时前用同一个匿名节点，查询过‘心智防火墙’项目的早期学术论文哦。关键词包括：‘神经接口适配性’、‘代价转移实验’、‘受试者长期跟踪’。”

房间里的空气仿佛突然凝固了。

服务器风扇的嗡鸣变得异常清晰。窗外，隔壁的麻将声不知何时停了，只有远处早班公交车的引擎声隐隐传来。

林深的手指悬在键盘上方，没有动。

他的目光从截图上的徽记，移到那句“心智防火墙”，再移到自己左手腕的疤痕。疤痕在显示器冷光下呈现出一种暗淡的、扭曲的粉白色，像一道永远无法愈合的裂口。

头痛毫无征兆地袭来。

这次不是右侧太阳穴的钝痛，而是整个前额的紧绷感，仿佛有冰冷的金属箍在慢慢收紧。视野边缘开始出现细微的闪烁光点，像坏掉的显示屏。

他闭上眼，深呼吸。数到七，再缓缓吐出。

“心智防火墙”。

那个名字像一把钥匙，插进他记忆里某扇锈死的门。门后不是具体的画面，而是一种感觉——冰冷的金属台，皮肤上黏贴电极的触感，某种低频嗡鸣穿透颅骨，还有一个平静的、没有感情的声音在说话：

“神经同步率达标。开始载入协议。”

协议？什么协议？

他猛地睁开眼，强制切断那段闪回。冷汗从额角滑下来，滴在键盘的空格键上。

屏幕还亮着。“窃神者”的窗口悬在那里，像一只等待回应的眼睛。

林深移动鼠标，点开那个解题思路的附件。文件里是详细的步骤、代码片段、甚至还有手绘的流程图，字迹张扬，充满各种夸张的箭头和爆炸形状的批注。技术逻辑严密，但表达方式……像个兴奋过度的中学生。

天赋是真的。疯癫也是真的。

他关掉附件，回到聊天窗口。光标在输入框闪烁。

他需要决定。是继续无视这个“麻烦”，还是利用这个“麻烦”？

那个“绅士”在查询“心智防火墙”。老周警告的“穿黑袍的”在打听原宿主信息。集市里出现系统性采集的“灰烬”碎片。还有他手腕上这道永远在提醒他代价的疤痕。

所有这些碎片之间，似乎有丝线连接。而他，正站在丝线交织的中心。

他打字，回复“窃神者”：

“你是谁？目的？”

发送。

几乎立刻，回复就来了：

“我是陈飞！但请叫我‘窃神者’！我是您未来的共犯！目的？当然是见证传奇啊！前辈，我能感觉到，您在做一件改变世界的大事！请让我帮忙！我可以做任何事！破解、追踪、情报分析、甚至跑腿买咖啡！(๑•̀ㅂ•́)و✧”

最后还附了一个自制的小动画：一个像素小人戴着黑客面具，对着星空张开双臂，身后爆炸出绚烂的烟花。

林深看着那个动画，沉默了三秒。

然后他关掉了窗口，清除了所有聊天记录。

但他没有封杀“窃神者”的访问路径。

而是留了一道很小的、几乎看不见的缝隙——一个监控端口。如果对方再次尝试接触，他会知道。

他靠在椅背上，看向窗外。天色已经亮了很多，灰白的光线透过遮光帘的缝隙，在地板上切出一道锐利的线。

新的一天。倒计时第四十四天。

左手腕的疤痕还在隐隐发烫。仿佛在提醒他，有些代价，不是还清债务就能逃脱的。

而有些麻烦，一旦沾上，就再也甩不掉了。
