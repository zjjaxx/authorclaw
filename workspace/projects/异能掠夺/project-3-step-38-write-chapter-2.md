# Write Chapter 2

# 第2章：不请自来的信徒

警报触发时，林深正在逆向解析李泽楷宅邸通风系统的老式控制协议。

手腕上的疤痕毫无征兆地刺痛了一下——不是幻觉，是皮肤下微型生物传感器传来的预警，比屏幕角落跳动的红色三角图标快了零点三秒。他左手拇指已经压了上去，缓慢摩挲着那道粗糙的凸起，右手则在键盘上敲出一串指令。

**入侵路径：非常规。** 不是“清道夫”那种教科书式的渗透，也不是黑市竞争者粗暴的撞库。对方的轨迹像喝醉的萤火虫——忽左忽右，在防火墙的逻辑缝隙间跳跃，毫无规律可言，却又总能精准地避开最致命的诱饵陷阱。技术花哨，效率低下，但透着一股令人不安的……直觉。

林深调出实时追踪视图。入侵者像一条滑腻的鱼，在他构建的数字深海里左冲右突。IP地址疯狂跳转：新加坡的代理节点、冰岛的服务器、巴西某大学公共机房……但每一次落脚，停留时间都不超过两秒。太干净了，几乎没有系统调用痕迹，像是脚不沾地的幽灵。

直到第十七跳。

追踪线猛地收束，指向一个坐标——本市，东区，理工大学主服务器。停留时间：0.8秒。足够了。

林深的手指在键盘上停顿。大学服务器？学生？还是伪装？

就在他准备深入挖掘那个服务器日志时，入侵行为突然停止了。不是撤退，而是……转化。对方放弃了所有渗透尝试，转而在林深防火墙最外层一个无害的隔离沙箱里，留下了一个数据包。

一个用七层不同算法嵌套加密，却把解密密钥像生日礼物一样挂在最外面的数据包。

以及一行闪烁的、自带渐变色动画的留言：

> **“向阴影中的传奇致敬！窃取神谕之人——‘窃神者’，请求觐见！愿与您共商颠覆世界真实面纱之大计！(✧ω✧)”**

结尾附赠一个像素动画：一个戴着头盔、披风飞扬的小人，对着星空单膝跪地，鞠躬。

林深盯着屏幕，脸上没有任何表情。只有左手拇指压在疤痕上的力道，又重了半分。

他沉默地解开一层层加密——密钥确实是那个幼稚的动画表情的哈希值——最后展现在眼前的，不是什么恶意代码，而是一份极其详尽的……个人简历。

简历。

姓名：陈飞（但强烈建议称呼代号“窃神者”）
年龄：19
技能树：量子计算理论（自学）、神经网路逆向工程（略有心得）、深网协议漏洞挖掘（天赋所在）、现实增强界面设计（个人兴趣）……
近期成就：独立破译“第三新东京市”地下交易市场（深网某个中二论坛）的通信协议；成功预测三次“清道夫”外围巡逻路线（准确率87.3%）；发现“心智防火墙”项目公开论文与其实验数据之间的十三处逻辑断层……
人生目标：成为数据洪流中的引航灯塔，揭开世界表里之境的帷幕，以及，找到“Null”并成为其共犯。

简历最后，是一张照片。大概是偷拍的：一个戴着黑框眼镜、头发乱翘的年轻人，穿着印有复杂分形图案的T恤，坐在满是零食包装和电路板的房间里，对着镜头比出夸张的“V”字手势，笑容灿烂得几乎溢出屏幕。

背景里，书架上塞满了《脑机接口：从理论到实践》、《混沌理论与复杂系统》、《攻壳机动队》蓝光盒，以及一排排动漫手办。

林深关闭了简历窗口。

他向后靠进椅子，椅背发出呻吟。显示器冷光下，他眼下的青黑像两团化不开的墨迹。头痛的后遗症还在颅骨深处隐隐搏动，配合着此刻的情绪——一种混合着荒谬、警惕和极度不耐烦的疲惫。

孩子。一个天赋或许不错，但明显活在某种自我编织的宏大叙事里的……孩子。

他调出刚才入侵的完整日志，重新分析。那些毫无章法却又总能避开陷阱的路径选择，现在有了新的解释：那不是经过训练的专业规避，而是一种近乎本能的、天马行空的“碰巧”。对方似乎压根没按常理出牌，所以常理的陷阱对他无效。

危险吗？目前看，不像。但麻烦，巨大的麻烦。这种活在自己世界里的天才，最容易因为一时兴起，把所有人都拖进不可预测的漩涡。

林深的手指在键盘上悬停片刻。他在评估：立刻抹除所有痕迹，加固防线，彻底隔绝这个“窃神者”？还是……留一道缝，观察？

风险在于，观察本身就可能暴露更多。但对方已经展现了某种程度的追踪能力（能找到他这个级别的中继节点），彻底消失需要时间，而他现在最缺的就是时间。四十四天。李泽楷的宅邸。

另外……那份简历里提到的“逻辑断层”。这个陈飞，也注意到了“心智防火墙”。

林深最终没有采取任何极端措施。他只是悄无声息地，在那个被入侵过的沙箱最深处，埋下了一个新的、更隐蔽的追踪信标。然后，他切断了与那个节点的所有明面连接，将防线整体后撤了一层。

让子弹飞一会儿。也让自己，有多一点时间处理眼前更实际的威胁。

***

老周的情报在第二天傍晚准时送达。

加密链传输，文件包解压后是一堆杂乱的信息：几张模糊的保安巡逻时间表、一份过期的建筑平面图（和他已有的那份差别不大）、一段从远处用长焦镜头拍摄的宅邸外墙视频（晃动得让人头晕），以及一份手写的、字迹潦草的清单，列出了安保升级可能涉及的承包商名字——其中三个被红笔圈出，旁边标注：“疑似有异能背景咨询”。

价值有限，但符合老周一贯的风格：真假参半，关键处留一手，等着加钱。

林深没有追加费用。他把所有信息导入自己搭建的分析模型，结合卫星图、公开的市政管线数据和能从深网爬取到的该区域无线信号图谱，开始重建宅邸的立体模型。

工作台上的三块屏幕同时亮起。左边是不断刷新的数据流，中间是逐渐成型的3D建筑结构，右边是代码编辑器，他正在编写针对特定动态感应算法的欺骗脚本。

阿飞——或者说，“窃神者”——的警告被他暂时搁置在脑海角落。现在，全部注意力必须集中在李泽楷的宅邸。

根据老周的情报和交叉验证，宅邸最新的安保核心，是一套“萤火虫IV型”自适应动态感应系统。它不再依赖简单的移动侦测，而是通过布设在房间各处的微型传感器阵列，持续扫描环境中的质量分布、热源轮廓甚至空气流动的细微变化，构建实时动态模型。任何与模型不符的扰动——哪怕是一只猫跳上沙发——都会触发警报。

传统的屏蔽或干扰手段几乎无效。你需要骗过它的“眼睛”，让它相信你本来就是环境的一部分。

林深敲击键盘，屏幕上的代码瀑布般滚落。他正在模拟“萤火虫IV型”的数据处理逻辑，寻找其算法在极端情况下的认知边界。空气湿度突然变化时，对热源轮廓的权重分配是否会偏移？多个传感器数据在微秒级延迟下，融合算法是否会产生可预测的误差窗口？

头痛的后遗症像背景噪音，持续低鸣。他偶尔停顿，用指关节按压右侧太阳穴，或者更用力地摩挲手腕的疤痕。目光有时会不经意地扫过工作台边缘那张照片，又迅速移开，像是被无形的线烫到。

咖啡壶里的液体早已见底，但他没有起身去续。时间在以分钟为单位流逝，倒计时在后台安静地跳动。他需要那个“瞬时记忆强化”碎片，需要那笔钱。这是他计划中不可缺失的一块拼图。

窗外的天色由昏转暗，城市的灯光次第亮起，又被厚重的遮光帘挡在外面。安全屋里只有键盘敲击声和机器风扇的低鸣。林深像一尊沉入数据深海的石像，只有屏幕上流淌的代码和眼中偶尔掠过的锐光，证明他还在与某个无形的系统搏斗。

就在他即将完成欺骗脚本的核心模块时——

主显示器右下角，一个极其隐蔽的提示图标，轻轻闪烁了一下。

不是警报，是他之前埋下的、针对“窃神者”的追踪信标被触发了。有人，在尝试反向追踪那个信标。

林深动作顿住，眼神瞬间冷了下来。他没有立刻动作，而是让代码继续运行，同时分出一部分注意力，监控那个信标的反馈。

信号很微弱，试探性的。对方似乎在小心翼翼地绕着他留下的诱饵走，手法比昨天的入侵要谨慎得多，甚至带着点……犹豫？

几秒钟后，试探停止了。信标恢复平静。

紧接着，林深的加密通讯频道（一个他只与极少数情报贩子使用的死信渠道）收到了一条新消息。发送者ID是一串乱码，但签名处，画着一个歪歪扭扭的头盔小人。

消息内容只有一行字：

**“前辈，您对‘深网集市’东南角第三个摊位今天新到的那批‘灰烬’不好奇吗？我有内部消息哦 (•̀ω•́)✧”**

下面附了一张图片附件。

林深盯着那条消息，指尖在疤痕上停住。内部消息？这个“窃神者”，不仅在技术层面追踪他，还涉足黑市情报？

他点开了图片。

那是一张监控截图，角度刁钻，显然来自某个非法接入的集市内部摄像头。画面模糊，噪点很多，但能看清场景：正是“深网集市”那迷宫般的巷道，东南角区域。第三个摊位——一个用防雨布和废旧服务器机柜搭起来的简陋棚子——前，站着一个人。

一个与周围环境格格不入的人。

男人看起来四十多岁，穿着剪裁合体的深灰色休闲西装，没打领带，头发梳得一丝不苟。他正微微俯身，手里拿着一台巴掌大小的、泛着金属冷光的便携式仪器，对准摊位上几块暗沉无光的碎片残骸（也就是黑市俚语中的“灰烬”）进行扫描。姿态专注，动作娴熟，带着一种实验室研究员般的精确感。

周围是穿着连帽衫、裹得严严实实的匿名贩子，油腻的防雨布，闪烁的廉价霓虹灯，空气中仿佛能闻到臭氧和金属锈蚀的味道。而这个男人，干净、得体、专业，像一滴油落进了污水里，刺眼得让人不安。

老周提到的“穿黑袍的”？未必是字面意义上的黑袍，但这种格格不入的气质，吻合。

林深将图片放大，仔细观察男人手中的仪器。型号无法完全辨认，但一些细节特征——多重透镜阵列、侧面特殊的散热孔设计——让他想起在极少数高端学术期刊上见过的，用于检测高能粒子残留的实验室设备变种。

这不是黑市该出现的东西。

他回复消息，字符敲得很慢：“你是谁？目的？”

几乎秒回。

**窃神者：“我是您未来的共犯！目的？当然是见证传奇啊！PS：截图里的‘绅士’，半小时前用深网匿名节点，高频查询过‘心智防火墙’项目2009年至2012年的所有非公开会议摘要和早期技术草案哦。查询关键词包括：‘神经适配性阈值’、‘长期记忆锚定副作用’、‘受试者编号7’。”**

林深的呼吸，在看见最后五个字时，微不可察地滞了一下。

受试者编号7。

他左手腕的疤痕，在指腹下传来一阵尖锐的、幻觉般的灼痛。工作台边缘，那张磨损照片里妹妹的笑容，在眼角余光中突然变得无比清晰。

屏幕冷光映着他骤然绷紧的侧脸。集市截图里那个西装男人的形象，和老周含糊的警告、自己昨天头痛时闪过的诡异网络图残影、还有金属盒文件照片上那行“二期受试者跟踪评估”的红线……所有这些散落的点，被“心智防火墙”和“编号7”这两条线，粗暴地串联了起来。

巧合的概率，正在向零跌落。

他盯着通讯窗口里那个闪烁的头盔小人图标，仿佛能透过数据流，看到屏幕另一端那个戴着黑框眼镜、满脸兴奋的年轻人。麻烦，巨大的麻烦。但这个麻烦，似乎正捧着钥匙，站在他试图撬开的门上。

窗外，夜色已浓。城市在远处轰鸣，而在这间闭塞的安全屋里，寂静突然有了重量。

林深缓缓松开摩挲疤痕的手指，在键盘上敲下新的指令，继续完成那未写完的欺骗脚本。屏幕上的代码继续流淌，3D宅邸模型缓缓旋转。一切如常。

只有他自己知道，计划清单上，优先级已经悄无声息地改变了。

李泽楷的宅邸依然要闯。

但在那之前，他需要再去一次“深网集市”。需要亲眼看看，那些“灰烬”，和那个查询“受试者编号7”的“绅士”。

倒计时在背景中跳动：43天18小时07分。

时间不多了。而水面下的影子，正变得越来越清晰。
