# 《异能掠夺》第八部分：白噪点与城市伤痕（第106-120章）章纲

**卷标：** 第八篇：城市游魂
**主题句：** 当文明的外壳仍在，其内核已被新的规则悄然蛀蚀。在名为“秩序”的废墟上，一群拒绝被定义的人，试图用共鸣的噪音，谱写不被契约束缚的生存乐章。

### **第106章：旧城伤痕**
*   **POV:** 林深
*   **主要地点:** 城市边缘通往旧城区的过渡地带
*   **关键节拍:**
    1.  **谨慎渗透：** 小队离开湿地公园，依据埃琳娜信号中模糊的坐标，开始向旧城数据交换中心方向移动。他们选择废弃的地面轻轨线路和建筑夹缝前进，避开主干道。眼前的城市不再是他们熟悉的模样：街道布满裂缝，从中长出微光菌斑；废弃车辆被藤蔓和发光苔藓覆盖；空气中“情感回响”如同背景辐射，时而传来无源的哭声、笑声或争吵的碎片。
    2.  **分层的“秩序”：** 他们观察到城市已被无形分割。某些街区异常“洁净”，几乎没有菌斑和强烈回响，但有一种被“梳理”过的压抑感，偶有巡逻的、形态更稳定的契约实体（“巡债者”）掠过——这是“债主”的“高效管理区”。另一些区域则“回响”沸腾，菌斑疯长，甚至有短暂的情感幻象闪现，是“共鸣混沌区”。少数区域则有“清道夫”的临时岗哨和巡逻队，试图维持旧日秩序。
    3.  **第一次遭遇：** 在穿越一条“混沌区”的小巷时，他们遭遇了并非契约实体也不是人类的“东西”——几个身体部分菌斑化、行为狂乱、似乎被自身强烈情感回响所困的“共鸣失控者”。其中一个年轻女人不断重复尖叫着“还给我！”，双手挥出微弱的能量涟漪。林深被迫使用能力，快速读取其回响核心（一段被至亲背叛夺取财产的强烈执念），并尝试用平静的情感频率进行短暂“对冲”，使其暂时平静下来，趁机通过。
    4.  **林深的反思：** 这次遭遇让林深意识到，“共鸣时代”对普通人的伤害是直接的。无法处理自身剧烈情绪或过往创伤的人，极易被环境回响放大，陷入失控。埃琳娜的“白噪点”，或许不只是避风港，更可能是一个治疗和稳定这类人的“急救站”。
*   **紧张程度:** 7/10 （危险环境与遭遇）
*   **章节结尾钩子:** 就在他们即将离开这片“混沌区”时，阿飞突然低呼：“信号增强了！就在前面那个街区…但是，林深，苏芮姐，你们看天上！” 只见旧城数据交换中心方向的上空，隐隐盘旋着数架“清道夫”的无人侦察机，而更远处的云层中，似乎有一片不自然的、缓慢旋转的暗影，散发着熟悉的契约冰冷感——“债主”的某种高空监视节点，也锁定了那个区域。

### **第107章：数据坟场入口**
*   **POV:** 阿飞
*   **主要地点:** 旧城数据交换中心外围（废弃建筑群）
*   **关键节拍:**
    1.  **目标的表象：** 数据交换中心是一座庞大的、上世纪风格的灰色建筑，如今窗户破碎，外墙爬满菌斑和正常藤蔓。周围是配套的办公楼和宿舍区，同样荒废。从外部看，这里死寂一片，与城市其他区域的“活跃”形成对比，但缺乏“被管理区”的那种刻意整洁。
    2.  **信号的诡谲：** 埃琳娜的信号从这里的地下发出，但时断时续，且混杂着一种有规律的“屏蔽杂波”。阿飞分析后认为，地下有某种主动的、基于情感频率的隐形场，并非单纯隐藏，更像是在发出“此地无价值”的错误信息，欺骗“债主”的感知和“清道夫”的扫描。
    3.  **寻找入口：** 根据信号特征和阿飞的设备探测，他们锁定了一个通往地下车库的坍塌坡道。坡道被瓦砾半掩，但仔细看，瓦砾的摆放有人工痕迹，留有狭窄通道。通道内壁有新鲜的、非自然形成的菌斑刮擦痕，似乎有大型物体经常进出。
    4.  **入口的“守卫”：** 就在他们准备进入时，阴影中悄无声息地出现了两个“人”。他们穿着用废旧布料和电子零件混搭的衣物，脸上涂抹着发光的菌斑涂料作为伪装，手持改装过的、带有强烈情感频率发射器的棍棒。他们没有立刻攻击，而是用审视、警惕的目光打量着小队，尤其多看了几眼苏芮肩膀上未完全消退的契约符文和虚弱的林深。
*   **紧张程度:** 7/10 （对峙与未知）
*   **章节结尾钩子:** 其中一个守卫向前一步，声音沙哑但清晰：“地表来的？身上带着‘契约的臭味儿’和‘清道夫的铁锈味’。报上名，还有，你们怎么找到这里的？说错一个字，或者频率不对，”他晃了晃手中的棍棒，顶端发出低沉的嗡鸣，“就把你们留给外面的‘清理者’。”

### **第108章：频率为证**
*   **POV:** 苏芮
*   **主要地点:** 数据交换中心地下入口处
*   **关键节拍:**
    1.  **紧张的沟通：** 苏芮强撑精神，上前交涉。她坦言自己曾是“清道夫”，但已脱离，并展示了伤口和符文的挣扎痕迹作为证明。林深则直言受埃琳娜的广播信号指引而来，并说出了埃琳娜研究代号的完整名称和部分理论关键词。阿飞适时播放了设备中记录的、埃琳娜广播的原始情感频率片段。
    2.  **守卫的验证：** 守卫仔细检查了频率片段，并用一个简陋的、类似音叉的装置在自身耳边激发共鸣。片刻后，他点了点头，但警惕未消：“频率对上了埃琳娜博士的‘友方识别码’。但你们身上的‘债’和伤，是麻烦。我们需要通报。” 他示意同伴回去报信。
    3.  **等待与观察：** 在等待期间，苏芮凭借职业观察力，注意到这些守卫虽然装备简陋，但行动间有章法，眼神锐利且清醒，与外面失控的“共鸣者”或被契约控制者截然不同。他们利用菌斑涂料不仅伪装，似乎还能微弱地调节自身情感频率，融入环境。这里是经过组织的。
    4.  **进入许可：** 报信的守卫返回，带来一个穿着旧实验室白大褂、神色疲惫但眼睛很亮的中年女性。她正是**埃琳娜**。她看到林深等人，先是松了口气，随即目光落在苏芮的伤口和林深苍白脸上，眉头紧锁：“比预期来得晚，状态也更差。进来吧，但需要先去隔离观察室。你们身上的‘外源信号’太强了。”
*   **紧张程度:** 6/10 （交涉与验证）
*   **章节结尾钩子:** 跟随埃琳娜进入地下通道。通道并非想象中阴暗，墙壁上每隔一段就镶嵌着发出柔和白光的、培养在透明罐子里的特殊菌株（与外面发冷光的菌斑不同）。但就在经过一个岔路口时，林深猛地捂住头，看向另一条黑暗的通道深处：“那里…有很强的…**痛苦和抗拒的回响**，还有…金属和药水的味道。” 埃琳娜脚步一顿，叹了口气：“那是‘治疗区’。你们待会会看到的。‘白噪点’不全是希望，也有我们不得不面对的…代价。”

### **第109章：白噪点之下**
*   **POV:** 林深
*   **主要地点:** 旧城数据交换中心地下核心区——“白噪点”基地
*   **关键节拍:**
    1.  **基地概貌：** 地下空间被改造成一个功能复合体。核心是原本的数据中心大厅，如今服务器机柜大多被改造为居住单元、工作台和储存区。柔和的人造白光（来自特殊培养的“白噪点”菌株）照亮空间。约有三四十人在这里活动，有技术人员、前医护人员、普通幸存者，甚至有两个看起来曾是“清道夫”的人。所有人都佩戴着简易的情感频率调节器（项链或腕带）。
    2.  **埃琳娜的简报：** 埃琳娜解释，“白噪点”是她发现的一种特殊菌株，它能发出一种稳定、平和的“白噪音”情感频率，有效中和外界混乱回响的干扰，并微弱抵制契约频率的渗透。这里是依靠这种菌株建立的“情感静默区”，也是研究“共鸣时代”和收治受影响者的前哨站。
    3.  **“治疗区”的真相：** 埃琳娜带他们参观了林深之前感知到的区域。那里更像是病房，躺着几个情况各异的人：有的全身菌斑化严重但被“白噪点”光线抑制着；有的沉浸在自身回响的幻象中喃喃自语；还有一个，身体部分出现了缓慢的、不可逆的物质转化迹象（皮肤呈现金属或晶体光泽）。埃琳娜沉重地说：“‘共鸣’不只是精神影响，高浓度下会引发物理层面的‘现实扭曲’。我们尽力稳定他们，但很多损伤…可能是永久的。这就是新世界的‘代价’。”
    4.  **苏芮的初步治疗：** 埃琳娜用“白噪点”培养液和专用频率发生器对苏芮的伤口进行处理。伤口处的契约符文在“白噪音”冲刷下进一步淡化，苏芮感到侵入骨髓的冰冷感消退了许多，但埃琳娜警告：“契约污染深入神经，就像烙印。‘白噪点’能抑制和清洁表层，但根源的‘契约联系’可能无法彻底斩断，除非…找到‘债主’的核心规则并破坏它。”
*   **紧张程度:** 6/10 （信息接收与内部观察）
*   **章节结尾钩子:** 治疗间隙，阿飞和基地的技术人员迅速打成一片，帮忙调试设备。他兴奋地跑回来告诉林深：“这里有完整的旧数据中心备份电力系统和一部分还能用的硬件！我能尝试搭建一个更强的信号中继和防御网络！” 然而，他话音刚落，整个基地的灯光突然轻微闪烁了一下，墙壁上的“白噪点”菌株光芒也出现瞬间的波动。广播里传来警戒层守卫急促的声音：“埃琳娜博士！检测到外围‘情感静默场’出现高频冲击！有东西在尝试突破！能量特征…是**强契约反应**，而且不止一个方向！”

### **第110章：围猎静默**
*   **POV:** 埃琳娜 & 守卫队长
*   **主要地点:** “白噪点”基地外围防御节点及监控中心
*   **关键节拍:**
    1.  **袭击者：** 监控显示，基地三个主要隐蔽入口附近，同时出现了多个“巡债者”实体，以及几个形态更接近人、但全身覆盖流动契约符文、手持结构复杂光刃的“契约执行者”。它们不像之前遇到的那样漫无目的，而是有组织地探测、攻击“情感静默场”的薄弱点。
    2.  **防御机制：** 埃琳娜启动防御。基地外围的“白噪点”菌株被激活到高亮，发出更强、更集中的“白噪音”频率，形成干扰屏障。守卫们利用地形和改装的情感冲击武器（类似阿飞之前用的，但更稳定）进行阻击。战斗不依赖物理火力，而是情感频率的对抗与干扰，无声但凶险。
    3.  **林深的协助：** 林深主动要求前往压力最大的东侧入口。他利用自己增强的感知，精准定位“契约执行者”发出的核心契约频率，并引导守卫集中“白噪音”冲击，成功扰乱了一个执行者的行动，使其被守卫合力“击散”（化为无序的光点和消散的符文）。这是他第一次有组织地运用能力参与防御。
    4.  **袭击的突然撤退：** 就在防御看似稳住阵脚时，所有契约实体突然同步停止攻击，如同接收到统一指令，迅速后撤，消失在废墟中。来得突然，去得也干脆。
*   **紧张程度:** 8/10 （频率对抗战斗）
*   **章节结尾钩子:** 袭击结束，但无人感到轻松。监控拍到，在契约实体撤退前，一个格外高大的“契约执行者”朝着基地主入口的方向，用光刃在地面上刻下了一个清晰的、旋转的**莫比乌斯环图案**，环内还有一个不断跳动的、类似林深之前看到的“估值数字”的虚影。埃琳娜脸色难看：“这不是袭击失败…这是**标记和警告**。它们找到了我们，这次是试探，下次…可能就是真正的‘债务追讨’了。”

### **第111章：分歧与提案**
*   **POV:** 林深
*   **主要地点:** “白噪点”基地核心会议室（原数据中心会议室）
*   **关键节拍:**
    1.  **基地的内部会议：** 埃琳娜召集核心成员（包括守卫队长、医疗负责人、技术人员代表）以及林深小队，商讨对策。基地内部出现分歧：一部分人主张立刻加强隐蔽，转移部分人员和关键物资，甚至考虑放弃这个据点；另一部分人（主要是战斗人员和部分技术人员）认为无处可逃，应该加固防御，利用“白噪点”和现有技术开发更主动的反制手段。
    2.  **林深的分析：** 林深分享了自己与“债主”在“公平秤”和湿地公园的两次接触经验。他指出，“债主”的行为遵循一套严密的、基于“契约”和“价值评估”的规则逻辑。它似乎将“白噪点”这种独立于其管理体系的“静默区”视为“不良资产”或“系统漏洞”。单纯的隐藏和防御，在对方拥有某种全局感知（可能通过高空节点或契约污染网络）的情况下，是消极且被动的。
    3.  **林深的激进提案：** 林深提出：“我们不能只等着被‘清理’。我们需要**主动收集关于‘债主’的信息，寻找其规则的漏洞，甚至尝试‘污染’或干扰其更核心的节点。**” 他建议组建一个小型侦察队，利用阿飞的技术和自己的能力，在“债主”势力范围内进行有限度的、有针对性的渗透和情报获取，目标是找到其“评估系统”或“契约网络”的关键弱点。
    4.  **激烈的争论：** 提案引发激烈争论。反对者认为这无异于自杀，会暴露更多信息，引来更猛烈的打击。支持者则认为被动防御终将失守，必须争取主动权。埃琳娜陷入沉思。
*   **紧张程度:** 7/10 （内部战略争论）
*   **章节结尾钩子:** 会议没有达成一致，暂时休会。林深独自来到基地的“治疗区”外围，看着里面受苦的人们。苏芮走到他身边，低声说：“你的提案风险很高。但你说得对，我在‘清道夫’学到一点：对付一个系统性的敌人，不能只想着躲藏。你需要一个具体的、第一步可行的计划。” 林深看着手中微微发热的契约碎片，又看向远处黑暗中隐约可见的、契约实体留下的莫比乌斯环标记，缓缓道：“第一步…或许我们可以从‘回收’或‘干扰’它们留下的这些‘标记’开始。这既是情报，也可能是一个陷阱。”

### **第112章：逆向标记**
*   **POV:** 阿飞
*   **主要地点:** “白噪点”基地技术工作间及外围标记点
*   **关键节拍:**
    1.  **技术准备：** 阿飞和基地的技术人员夜以继日，以那枚黑色契约碎片和之前采集的契约实体残骸为样本，结合埃琳娜的理论，试图制造一种能够“读取”或“反向干扰”契约标记的装置。装置核心是一个微型化的“白噪点”频率发生器和一套复杂的谐波分析模块。
    2.  **首次实地测试：** 林深、阿飞、苏芮和两名经验丰富的守卫组成侦察队，携带原型机，悄悄接近东侧入口外那个被刻下的莫比乌斯环标记。他们需要在极短时间内完成读取并尝试抹除或覆盖它。
    3.  **读取与发现：** 阿飞启动装置，对准标记。装置屏幕滚过大量混乱数据，但逐渐解析出一些信息：标记不仅仅是一个图案，它是一个**微型信标**，持续发送着关于此地“静默场”强度、情感频谱特征以及（最关键的）**检测到的“高价值目标”生物特征残留**（包括林深、苏芮和埃琳娜的频率特征）的数据包。
