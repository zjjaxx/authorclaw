# 第7章：鉴定师

俱乐部的门是青铜色的，厚重，哑光，没有任何标识，嵌在老法租界一栋保护建筑不起眼的侧面墙上。林深在街对面阴影里站了十分钟，看着那扇门。

雨水刚停不久，路面湿漉漉地反射着街灯昏黄的光。空气里有潮湿的梧桐叶和远处咖啡馆飘来的、过萃咖啡豆的焦苦味。时间接近午夜，但这一片街区依旧有零星的豪车滑过，引擎声被潮湿的空气吸收，只剩下轮胎压过水洼的细微嘶响。

那扇门始终关着。没有人进出。

但他知道，里面有人。不止一个。他的改装手表在靠近这里三个街区时，就探测到了复杂的、多层交叠的信号屏蔽场。不是普通的商业防窃听，是军用级，混杂着某种……非标准的能量波动，像是用异能碎片技术强化过的。

阿飞的声音从骨传导耳机里传来，比平时严肃得多：“前辈，我仍然建议取消。对方提供的坐标内部结构无法远程扫描，屏蔽太彻底了。而且预付定金的那笔资金流，经过十七次跳转后，最终汇入的池子……和之前调查‘灰烬’时那个匿名账户有间接关联。概率87%以上是同一伙人。”

林深没回答。他看着那扇门。

左手腕内侧的疤痕在隐隐作痛，和右侧太阳穴那种熟悉的、闷烧般的头痛预兆形成夹击。自从昨晚近距离接触了那枚“懊悔”碎片，这种双重的、不对称的痛感就再没完全消失过。像有两根生锈的钉子，分别楔进了他身体的两端，时不时被人用锤子轻轻敲打一下。

老周傍晚时也打过电话，声音压得极低，背景音是他铺子里永远修不好的那台旧收音机的杂音：“小林，我托道上几个老关系问了，你接的那个‘私活’……没人听说过。不是常规路子。你小心点，这种‘独家鉴定’，要么是坑，要么是……饵。”

饵。

林深闭上眼睛，深吸了一口潮湿冰冷的空气。肺叶扩张，牵动着肋骨，每一次呼吸都能感觉到紧身衣下，那枚藏在特制屏蔽袋里的“懊悔”碎片的冰冷存在。以及手机里，那条匿名信息后附上的、足以买断他未来所有麻烦的天文数字定金。

饵很诱人。钓竿的那一头，可能是深渊，也可能是答案。

关于“07号”，关于“事故”，关于陈序，关于那枚完美得不自然的“亚伯拉罕之契”。

他睁开眼，迈步穿过湿漉漉的街道。

走到青铜门前，没有门铃，没有摄像头。他抬起右手，将改装手表的表盘贴向门上一块颜色稍深的、不易察觉的凹陷区域。

表盘微震，幽蓝光纹流过。十六位动态密钥，加上他预设的、一次性的生物电场模拟信号，无声发送。

三秒钟死寂。

然后，门向内滑开一条缝，没有发出任何声音。门后不是走廊，而是一个极小、极简的玄关，只容一人站立。灯光是柔和的暖白色，墙壁覆盖着某种吸音绒布，空气里有极淡的、类似檀香和新雪的味道。

门在他身后合拢，严丝合缝。

正对面的另一扇门打开。一个穿着黑色旗袍、身姿笔挺的中年女人站在门后，脸上带着职业化的、弧度精确的微笑。“Null先生。请随我来。”

她的声音平和，没有情绪起伏，每个字都像用尺子量过。林深的目光快速扫过她——旗袍是上好的丝绸，剪裁合身，没有任何配饰。双手自然交叠在身前，手指修长，指甲修剪整齐，没有佩戴任何首饰。她侧身让开通道，动作流畅，没有多余的部分。

林深走进去。里面是一条不长的走廊，同样铺着吸音材料，两侧墙壁是深灰色的金属质感。走廊尽头是另一扇门。女人无声地走在他侧前方半步，高跟鞋踩在地毯上，没有声音。

“请将您的个人通讯设备和电子设备，暂时存放在这里。”女人在一扇看起来像是电梯门的银色面板前停下，旁边墙壁滑开一个抽屉，里面是排列整齐的、带有编号的黑色小盒。“鉴定结束后会完整归还。请放心，盒子具有法拉第笼屏蔽功能，且本次会面全程处于我们独立的、物理隔绝的网络环境中。”

林深看着她。女人回视，眼神礼貌而坚定。

他摘下耳机，连同手机、改装手表、以及藏在腰带夹层里的两个备用信号发射器，一起放进一个盒子里。盒子合上时，发出轻微的抽气声，内部指示灯亮起红色。

女人再次微笑，按动墙上的按钮。银色面板滑开，是一部小型电梯，轿厢内部同样是深灰色，没有楼层按钮。

电梯下行。失重感持续了大约十秒。林深在心中默数。按这个速度和体感，目的地至少在地下三层以下。

门开了。

外面是一个宽敞的包厢。风格极其简约，近乎禅意。浅灰色的石材地面，一面墙是整块的落地玻璃，外面是……人工营造的水下景观。幽蓝的光线从水底透上来，缓慢游弋的锦鲤和几尾银白色的、叫不出名字的鱼，在漂浮的水草间穿行。水声被完全隔绝，只有绝对的静。

房间中央，是一张宽大的黑色石质长桌。桌旁已经坐了一个人。

正是林深之前在“深网集市”监控截图里看到的那个“得体男人”。此刻他换了一身深灰色的便装，依旧一丝不苟，戴着副无框眼镜，正低头看着手里的一台平板电脑。听到声音，他抬起头，目光落在林深身上。

那目光很平静，带着一种研究者观察样本般的审视，没有好奇，没有惊讶，只有纯粹的评估。

“请坐，Null先生。”男人开口，声音和那女人一样，平稳得不带波澜。“我是这次的委托人，你可以叫我‘代理人’。感谢你愿意承接这次鉴定。”

林深走到桌前，在男人对面的椅子上坐下。椅子是硬质的，符合人体工学，但并不舒适，旨在让人保持清醒和端正的坐姿。

“碎片。”林深说。没有寒暄，没有试探。他的头痛在进入这个绝对安静、能量场被严密控制的空间后，似乎被压制了一些，但代价是感官变得更加敏锐——他能感觉到空气中残留的、极其微弱的、多种异能碎片被频繁取放后留下的“环境噪音”，以及一种更底层的、大型设备运转时带来的、几乎无法察觉的次声震动。

男人——代理人——点了点头，将平板电脑放到一边。他拍了拍手。

包厢一侧的墙壁无声滑开，一个穿着白色防护服、戴着头罩和手套的技术人员推着一台设备进来。设备像一个小型的手术推车，顶部是一个透明的圆柱形容器，被多层不同颜色的光膜包裹着，内部悬浮着那枚“亚伯拉罕之契”。

即使隔着容器和光膜，即使没有主动使用能力，林深的心脏还是骤然紧缩了一下。

在图片上看，它已经足够奇异。但亲眼所见，那种非自然的“完美”带来的冲击力，是二维影像无法比拟的。它静静地悬浮在容器中央，缓慢地自转。乳白色的光晕并非均匀散发，而是从其复杂几何结构的每一个切面内部透出，层层叠叠，让整个碎片看起来像是由内而外被点亮的、无比精密的微缩建筑。光线柔和，却带着一种不容置疑的、冰冷的**存在感**。没有脉动，没有闪烁，稳定得像一颗被摘下来的、缩小了亿万倍的恒星核心。

没有情感回响泄露出来。一丝一毫都没有。它安静得可怕。

技术人员将推车停在桌子中间，对着代理人微微躬身，然后无声退了出去。墙壁合拢。

“如你所见，”代理人开口，“‘亚伯拉罕之契’。我们获得它已经有一段时间，但它的能量结构和内部规则，超出了我们现有分析框架的边界。它稳定，极度稳定，稳定到不像是自然造物。我们需要你那双特别的眼睛，告诉我们它到底是什么，它的‘代价’可能映射为何种形式，以及……它是否安全，或者说，在什么条件下是安全的。”

他顿了顿，目光透过镜片，锁定林深。“酬金你已经看到。预付部分只是诚意。完成鉴定，尾款即时支付。我们只要求真相，无论那是什么。”

林深看着容器里的碎片。他的喉咙发干。右手手指无意识地蜷缩了一下。

“我需要隔离环境。”他说，声音比他预想的要稳。“绝对的物理和能量隔离。鉴定过程中，任何外部干扰都可能导致我的‘视觉’反馈失真，或者……引发不可控的后果。”

“已为你准备好了。”代理人指向房间另一个角落，那里有一扇之前与墙壁融为一体的门滑开，露出后面一个更小的房间。里面只有一张椅子，一个固定在椅子前方的、可调节的观测支架，以及四壁和天花板覆盖的、闪烁着微弱银光的特殊材料——那是高纯度铅和异能中和合金的复合层。“那里是静滞舱。可以屏蔽99.97%的外部能量干扰和物理信号。碎片会被移入舱内的固定观测位。你将有最多三十分钟时间。超过这个时间，出于安全考虑，我们会强行中断。”

林深站起身。走向那个小房间的每一步，都感觉腿像灌了铅。头痛的预兆在加剧，仿佛知道他即将面对什么，正在颅骨内蠢蠢欲动。

他进入静滞舱。门在身后合拢，发出一声沉闷的、气密锁定的声响。

世界瞬间被抽空了。真正的、绝对的寂静。连自己的心跳声和血液流动声，都被放大了无数倍，在耳膜内轰轰作响。空气静止，温度恒定，只有眼前观测支架上，那个刚刚被机械臂移入的、承载着“亚伯拉罕之契”的透明容器，散发着恒定不变的乳白色光芒。

林深在椅子上坐下。调整观测支架，让碎片处于他双眼正前方三十厘米处，一个最舒适、也最危险的观察距离。

他深吸一口气，再缓缓吐出。试图将脑子里所有杂念——债务、林浅、07号、陈序、老周的警告、阿飞的数据——全部清空。

然后，他放松了对“碎片视觉”的本能压制。

嗡——

不是声音，是感觉。像是一层一直蒙在感官上的薄膜被猛地撕开，世界以一种截然不同的方式涌入他的大脑。静滞舱银色的墙壁上，浮现出无数细微的、游动的能量残留痕迹，像是星尘，又像是细菌，那是这个空间过去可能存放过其他物品留下的“污渍”。

而他的目光焦点，无可避免地，落在了“亚伯拉罕之契”上。

主动聚焦的刹那——

世界消失了。

没有渐入，没有过渡。他像是被直接从椅子上抛了出去，坠入一片纯粹由结构和逻辑构成的**白**。不是光，不是颜色，是一种感知上的“空”与“满”的悖论结合体。

他“看”到了碎片的内部。

那已经不能用“结构”来形容。那是无数层叠的、旋转的、嵌套的数学模型在同时演绎。分形几何无限延伸，拓扑结构扭曲变换，每一寸空间都被精密的算法填满，没有浪费，没有冗余，没有自然造物常见的随机美或缺陷。它是一篇写满了宇宙底层代码的论文，冰冷，严谨，辉煌，毫无人性。

没有情感回响。是的，一点都没有。就像代理人说的，它稳定得可怕。但这种稳定本身，就是一种巨大的**异常**。异能碎片是代价的结晶，是情感与规则的扭曲产物，它的核心必然伴随着混乱的“回响”。但这枚碎片……它的核心是一片绝对的“寂静”。不是空无一物，而是所有可能的情感频谱，都被某种力量强行压制、调和、归零了。

林深感到一阵眩晕。不是生理上的，而是认知上的。他的大脑试图处理这海量的、有序到恐怖的结构信息，神经突触在超负荷运转。右侧太阳穴的血管开始疯狂搏动，疼痛从预警升级为实质性的钻凿。

他咬牙，试图将“视觉”更深入一些，去触碰那片核心的“寂静”，去理解压制情感的“力量”究竟是什么。

就在他的意识触角，小心翼翼地探入那片绝对秩序领域边缘的瞬间——

**轰！！！**

剧痛。无法形容的剧痛。不是从太阳穴，而是从大脑深处，从他被改造过的、那片作为“活体密钥”的脑区，猛然爆发！像是有无数根烧红的针，从颅骨内侧同时刺出！

“呃啊——！”他听到自己发出一声压抑的、从喉咙深处挤出的痛吼。

眼前的幻象变了。白色的数学世界崩塌，取而代之的是一条……无限延伸的、纯白色的走廊。走廊两侧，是无数扇紧闭的门，门上没有任何标识，只有光滑的、反光的白色表面。

他站在走廊中央，无法动弹。剧烈的疼痛撕扯着他的意识。

一个声音响起。不是从耳朵听到，是直接在他意识里轰鸣，平静，非人，带着金属般的共振：

**“检测到关键节点：未稳定型。”**

**“协议：同步进程强制启动。”**

**“校准坐标：锁定中。”**

**“错误：节点存在原始记忆链接……污染度评估……”**

随着这冰冷的声音，走廊两侧那些白色的门，其中一扇，突然亮起了微弱的红光。门牌上，浮现出一个数字：

**7**

数字7。猩红，刺眼。

林深想要尖叫，想要逃离，但他的意识被钉在原地，被迫“看着”那扇门。门后传来了声音，不是那非人的提示音，而是……他自己的声音，年轻一些，充满恐惧和痛苦：

*“……不……不是我……小浅……对不起……”*

*“……为什么忘不掉……关掉……关掉它！”*

*“……编号07……请求终止……代价……代价太大了……”*

无数混乱的、碎片化的声音，从7号门后涌出，冲击着他。与此同时，那非人的声音再次响起，似乎对这股“噪音”产生了反应：

**“检测到高强度噪声源……与节点稳定性冲突。”**

**“启动净化协议……”**

**“同步进程修正……引入次级过滤层……”**

更剧烈的疼痛袭来！林深感觉自己的记忆、意识、甚至人格，都像要被那冰冷的“净化协议”强行撕开、过滤、重组！他看到了更多的幻象碎片：冰冷的实验室仪器，穿着白大褂的模糊人影，贴在皮肤上的电极，以及一片无尽的、令人绝望的黑暗……

“不——！”

他用尽全部意志力，猛地切断了“碎片视觉”！

连接中断的瞬间，他像是从万丈高空坠落，重重摔回现实。

他瘫在椅子上，整个人被冷汗浸透，如同刚从水里捞出来。身体不受控制地剧烈颤抖，牙齿咯咯作响。眼前发黑，耳朵里是尖锐的、高亢的耳鸣，盖过了一切。喉咙里涌上腥甜的味道，他侧头，“哇”地一声吐了出来——是胃液，夹杂着血丝。

头痛已经不再是“痛”，是一种整个颅腔都要炸开的、持续的、毁灭性的压力。他的右眼视野完全被扭曲的光斑和黑雾占据，左眼也只能勉强看到模糊的轮廓。

静滞舱的门滑开了。急促的脚步声。

代理人走了进来，脸上那副平静的面具第一次出现了裂痕——他的眉头紧皱，看着林深，又看向观测支架上那枚依旧静静悬浮、光芒没有丝毫变化的“亚伯拉罕之契”。

“Null先生？”代理人的声音传来，隔着耳鸣，显得遥远而模糊。“你看到了什么？”

林深张了张嘴，发不出声音。他只能抬起颤抖的手，指了指自己的头，然后，极其艰难地，比划了一个“停”的手势。

代理人眼神闪烁了一下，对跟进来的技术人员快速吩咐：“医疗扫描。快。”

一个手持式的扫描仪被凑到林深头部。屏幕上的数据疯狂跳动。

“神经电活动异常剧烈！部分区域过载！生物电场紊乱！”技术人员的声音带着惊愕。

代理人深吸一口气，看向林深：“能说话吗？结论是什么？”

林深闭上眼睛，抵抗着又一波恶心和眩晕。他聚集起残存的力气，从咬破的嘴唇间，挤出破碎的、沙哑的词语：

“非……自然……产物……”

“高度……结构化……人工干预……”

“核心……寂静……情感压制……”

“危险……等级……未知……”

他每说一个词，都仿佛用尽全身力气。“……绝对……不要……尝试……激活……”

说完最后一个字，他再也支撑不住，身体向前软倒。

代理人迅速扶住了他，将他放平在静滞舱冰冷的地面上。技术人员开始注射某种镇静剂和神经稳定剂。

冰凉的液体涌入血管，狂暴的痛楚和混乱开始被强制镇压，拖入黑暗的深渊。在意识彻底沉没之前，林深透过模糊的视线，看到代理人正对着通讯器快速而低声地说着什么，目光时不时落在他身上，眼神复杂难明。

然后，他听到代理人最后一句清晰的话，是对他说的，声音恢复了那种平稳，却多了一丝……难以形容的意味：

“Null先生，你的‘眼睛’，确实非常特别。今天的合作很……有启发性。尾款已经支付到你指定的账户。希望未来，我们还有机会，进行更深入的……合作。”

合作？

林深想冷笑，但连牵动嘴角的力气都没有。黑暗彻底吞没了他。

意识漂浮。

不知过了多久，他感觉到自己被移动，被放入一辆车，平稳行驶。然后，他被放在某个地方——不是他的安全屋，也不是阿飞的据点。是一个陌生的、但同样安静的房间。

等他再次积聚起一丝清醒的意识，挣扎着睁开沉重的眼皮时，首先看到的，是自己被放在床头柜上的个人物品——手机、手表、耳机。屏幕是暗的。

窗外，天色是黎明前最深的靛蓝。

他躺在陌生的床上，浑身像散了架，头痛变成了沉闷的、持续不断的钝痛。嘴里全是血和胆汁的苦涩味道。

他颤抖着伸出手，摸到手机，按亮。

屏幕亮起，显示时间，以及一连串未读消息提示。最上面一条，来自加密通讯应用，是阿飞，发送时间是……二十分钟前。

消息只有一行字，但每个字都像冰锥，刺进林深尚未完全清醒的意识：

“前辈！追踪到付你定金的部分资金，最终流向的其中一个中间节点，和之前调查‘灰烬’时那个匿名账户——以及陈序基金会控股的一家离岸空壳公司——在三个月前有过一笔隐蔽的技术服务费往来！他们是一伙的！那个代理人，是‘断网人’！”

林深盯着屏幕，手机冰冷的光芒映亮他惨白、汗湿的脸。

**他们是一伙的。**

鉴定。合作。深入合作。

他猛地想起代理人最后那个意味深长的眼神，想起那枚完美冰冷的“亚伯拉罕之契”，想起幻象中那非人的声音和猩红的“7”号门。

这不是结束。

这只是一个开始。一个他主动踏入的、更庞大、更精密的狩猎场的开始。而他，既是猎人眼中有价值的“眼睛”，也是那个被锁定的、不稳定的“关键节点”。

窗外的靛蓝色天空边缘，泛起一丝苍白。

新的一天开始了。带着血腥味，和无处不在的、冰冷的凝视。
