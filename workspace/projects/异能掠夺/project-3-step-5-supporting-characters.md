# Supporting characters

# 配角档案：《异能掠夺》

## 1. 阿飞 (重度中二担当 | 技术外挂)

*   **姓名**：陈飞 (但坚持让人叫其代号“窃神者”)
*   **年龄**：19岁
*   **角色**：天才黑客、林深在深网的技术支援与“麻烦精”。
*   **与主角关系**：单向崇拜者与事实上的技术搭档。阿飞是在一次深网攻防战中，意外追踪到林深（“Null”）近乎幽灵级的反追踪手法后，惊为天人，开始死缠烂打式“拜师”。林深起初嫌他烦且危险，但发现阿飞的技术天赋（尤其是突破常规数字逻辑的能力）在应对异能黑市的加密系统时堪称“外挂”，遂发展出一种无奈又依赖的利用关系。阿飞视林深为“隐匿于现世的传奇”，单方面将两人捆绑为“破晓双星”或“深渊行者”这类中二组合。
*   **动机**：
    *   **表层**：追求极致的“酷”与“传奇性”，渴望成为网络传说的一部分，证明自己不只是个躲在屏幕后的“脚本小子”。
    *   **深层**：一个成长于标准中产家庭、生活平淡却内心充满瑰丽幻想的天才少年，对现实世界的庸碌规则感到窒息。异能黑市和碎片的存在，对他而言是一个远比任何游戏都真实的“异世界”，他渴求的不是力量本身，而是**成为宏大叙事的一部分**。他需要林深这个“引路人”带他进入那个世界，同时也需要用他的方式（中二行动）来“拯救”或“点亮”林深这种在他看来“过于黯淡的英雄”。
*   **背景故事**：父母是高级工程师，家庭和睦但缺乏他渴望的“戏剧性”。14岁就黑入过学校系统给自己改成绩（不是为了高分，而是为了留下一个无人能解的网络谜题）。16岁开始混迹深网边缘论坛，痴迷于各种都市传说和未解之谜，并自发调查，逐渐接触到异能存在的蛛丝马迹。他的黑客技术一半来自正规学习，另一半则源于他那种“不按协议出牌”的、近乎直觉的想象力。他曾在网上公开悬赏“超自然现象”线索，因此被林深注意到并反向追踪，从而开启了这段孽缘。
*   **性格特质**：
    - **重度中二病**：将一切行动赋予史诗般的命名和意义。黑入监控叫“展开寂静之幕”，数据解密叫“吟唱破译真言”，逃跑叫“执行相位转移协议”。他真心相信并活在自己的叙事里。
    - **无畏的乐观与忠诚**：对危险的认知严重不足，但因此也具备了林深所缺乏的、横冲直撞的勇气。一旦认准林深（他的“共犯”/“导师”），就会展现出近乎鲁莽的忠诚。
    - **天才的直觉与不可预测性**：他的代码常常优美但难以理解，解决问题的思路天马行空，经常能打开林深因过度谨慎而忽略的“后门”。他是林深计划中最大的**X变量**。
*   **说话方式**：
    - 混合技术术语、动漫/游戏台词和自创的“法则”或“真名”。例如：“前辈，敌方防火墙的‘叹息之壁’已确认，但我感知到其底层协议存在‘悖论裂隙’！请求发动‘因果逆流突袭’！”
    - 对林深永远使用敬称（“前辈”、“导师”），语气充满夸张的热情。
    - 在极度紧张或专注时，中二病会暂时让位于极其精简的技术术语，形成一种有趣的反差。
*   **对主角弧线的贡献**：
    1.  **打破林深的封闭**：阿飞死缠烂打、不求回报（甚至倒贴）的“追随”，是林深“交易至上”逻辑的第一个、持续的例外。他迫使林深不得不应对一种非功利性的、麻烦的情感联结。
    2.  **提供“非常规解法”**：在多次危机中，阿飞的中二脑洞会意外地提供关键破局思路（例如，用游戏MOD的逻辑去理解碎片重组规则），挑战林深过于依赖理性与经验的思维定式。
    3.  **承担“希望的具象化”**：在故事最黑暗的时刻（如“夜莺”背叛后），阿飞那种不合时宜的、坚信“我们是主角队所以一定能翻盘”的信念，会成为林深不至于彻底沉沦的微弱锚点。他的存在本身，就代表了林深试图逃离的“可能性”与“热血”，尽管形式很滑稽。
    4.  **中二病的“实用化”反转**：在最终高潮，阿飞可能会将某个中二设定（如他自创的“灵魂共鸣协议”）以极其硬核的技术手段实现，成为林深执行“共鸣”计划的关键技术支点，完成从“噪音”到“神之一手”的升华。

## 2. 老周 (搞笑担当 | 现实锚点)

*   **姓名**：周大宝 (自称“道上周老板”，实则人人叫他老周)
*   **年龄**：45岁左右
*   **角色**：林深的房东、二手电器铺老板、兼深网黑市底层情报贩子与杂物供应商。
*   **与主角关系**：互相嫌弃又互相依赖的“利益共同体”。老周是林深与现实世界为数不多的、滑稽而脆弱的连接点。他提供廉价的出租屋（隔音差但位置隐蔽）、各种来路不明的电子设备，以及真假参半的市井流言。林深是他最麻烦也最稳定的金主，而他则是林深获取“地面信息”和应急物资的窗口。他们的关系建立在精打细算的利用和一点心照不宣的、绝不宣之于口的“战友情”之上。
*   **动机**：
    *   **表层**：赚钱，赚容易钱，规避一切大风险。他的座右铭是“风浪越大，鱼越贵，但前提是老子的船别翻”。
    *   **深层**：一个被生活磨平了棱角、见识过太多灰暗的小人物，内心深处仍保留着一丝不合时宜的“江湖义气”和对“奇人异士”的迷信。他贪财怕死，但也明白在深水区混，对林深这样有真本事又“讲点规矩”的狠人保持一条线，关键时刻可能救自己一命。他需要林深带来的“大生意”和“保护伞”（虽然林深不承认），也在观察林深身上那份他早已丢失的“执着”。
*   **背景故事**：早年混过社会，倒腾过各种灰色产业，见过些世面也吃过不少亏。一次差点卷入真正的异能冲突（目睹了碎片效应），侥幸活命后，他意识到这个行当水太深，于是退居二线，利用自己的人脉和商铺做起了情报和物资的中转站。他自诩“安全屋”，实则最擅长在各方势力间摇摆、传话、抽成，并确保自己永远不在第一线。他有个正在读大学的女儿，这是他所有胆怯和贪婪背后，最坚实的软肋和底线。
*   **性格特质**：
    - **市侩的精明与夸张的表演性**：总是哭穷、夸大风险、讨价还价，演技浮夸但核心诉求明确。擅长从任何对话中嗅出商机和危险。
    - **贪生怕死但关键时刻有微弱闪光**：平常怂得毫无悬念，但在真正触及他底线（如威胁到他女儿，或林深真的陷入绝境且他判断“不帮可能死更惨”）时，会一边骂娘一边做出超出自身利益计算的、有限的勇敢举动。
    - **信息的活体数据库**：记性好，尤其对江湖传闻、人物关系和各类“古怪小事”过目不忘，是林深拼凑真相碎片的重要民间信息来源。
*   **说话方式**：
    - 地道的市井腔调，夹杂着过时的黑话和自创的比喻。例如：“小林啊，不是我说你，你这单‘瓷器活’风险太高，我这点‘金刚钻’怕是要赔本啊！最近风声紧，‘穿制服的’和‘穿黑袍的’（指清道夫和断网人）都在溜达！”
    - 口头禅是“亏了亏了”、“要死了要死了”、“最后一次，真是最后一次帮你”。
    - 传递关键坏消息时，会罕见地收敛起滑稽，用简短的、干巴巴的句子，这往往意味着真出大事了。
*   **对主角弧线的贡献**：
    1.  **提供“庸常现实”的对照**：老周代表了林深试图逃离的那个世界——琐碎、功利、充满小奸小恶但也孕育着真实生命力的市井生活。他是林深“断网”梦想的一个具体、滑稽的参照物。
    2.  **喜剧缓冲与节奏调节**：他的戏份是高压剧情中有效的减压阀，他的倒霉和抱怨能带来真实的笑料，但笑声背后又能感受到底层生存的艰辛。
    3.  **人性化情报来源**：通过老周接触到的“客户”和“麻烦”，往往更贴近异能世界的草根面，让林深（和读者）看到系统性掠夺对普通人生活造成的具体、微小的伤害，使宏观冲突有了血肉。
    4.  **考验并重塑林深的信任能力**：老周的一次次“掉链子”和偶尔的“靠谱”，在反复拉扯中，缓慢地、不情愿地教会林深：信任不是全或无的，而是在有限条件下的、基于对人性复杂度的认知之上的风险评估。老周最终某次豁出去的帮忙，会成为林深重建人际信任的重要一步。

## 3. 苏芮 (灰色地带者 | 秩序内外的镜子)

*   **姓名**：苏芮
*   **年龄**：29岁
*   **角色**：“清道夫”组织三级外勤特工，代号“白鸦”，负责追踪并“处理”异能相关异常事件及潜在危险个体。
*   **与主角关系**：追捕者与潜在的理解者。她是“清道夫”中较年轻的一员，专业、冷静，但尚未被系统完全同化，仍保留着对“真相”和“正义”本身的追问。在追捕林深的过程中，她逐渐发现官方叙事与现场证据的裂缝，开始对“断网人”的存在产生怀疑，并对林深这个“高价值目标”的行为模式（并非无差别作恶，且似乎在被更强大的势力驱赶）感到困惑。她可能从纯粹的猎手，转变为在规则边缘徘徊的观察者，甚至成为林深在危急时刻非常规的、充满张力的“临时信息源”或“避险通道”。
*   **动机**：
    *   **表层**：履行职责，维护社会稳定，清除“不稳定因素”。她相信秩序的必要性。
    *   **深层**：一个相信制度但更相信证据的理想主义者（残留）。她加入“清道夫”是希望用专业能力保护无辜者免受异能相关的伤害。但随着层级升高，接触到的内部掩盖和模糊指令越多，她的信念开始动摇。她追捕林深，一部分是任务，另一部分是想**通过这个顶尖的“病毒”，反推出系统本身可能存在的“病灶”**。
*   **背景故事**：警校优秀毕业生，因在一次涉及疑似异能者的离奇案件中表现出色（冷静、观察力强、报告严谨），被“清道夫”秘密招募。接受过严格的格斗、侦查、情报分析及“认知强化训练”（一种弱化的精神抗性提升）。她处理过数十起事件，见过异能导致的悲惨后果，也执行过冷酷的“净化”命令。最近她经手的几起碎片相关案件，现场痕迹与她被告知的“野生能力者内讧”结论存在微妙矛盾，让她埋下了怀疑的种子。
*   **性格特质**：
    - **专业的冰冷与内心的审视**：工作中绝对理性，行动干净利落，报告毫无感情色彩。但独处时，她会反复审视案件细节和自己的判断。
    - **细节偏执狂**：相信现场不会说谎。对不合逻辑的细节有着猎犬般的执着。
    - **孤独的守序者**：在“清道夫”内部朋友不多，因她“想太多”而被部分同僚视为异类。她的正义感与系统的要求之间，存在着持续的、无声的摩擦。
*   **说话方式**：
    - 公事公办，简短精确。多用陈述句和术语。例如：“目标‘Null’，于昨日23:47在暗网节点‘集市’出现，交易行为模式与档案吻合。建议启动B-7追踪预案。”
    - 在内部提出质疑时，会用“根据现场痕迹A，能否与结论B完全兼容？”这类客观句式，避免直接挑战权威。
    - 极少表露个人情绪，唯一的例外可能是在极度疲惫或面对明显不公的牺牲者时，会有一丝几乎无法察觉的停顿或气息变化。
*   **对主角弧线的贡献**：
    1.  **代表“旧秩序”的复杂面孔**：她不是脸谱化的冷酷特工，而是让林深（和读者）看到，即使在高压管控的系统内部，也存在着困惑、良知与对真相的追求。她使“清道夫”这一势力立体化。
    2.  **提供体制内视角的信息**：她可能在不违反核心纪律的前提下，通过某种方式（如匿名警告、留下可追踪的线索）让林深意识到“断网人”的威胁远超个人想象，或者官方也并非铁板一块，从而影响林深的战略判断。
    3.  **作为林深的“影子”与对照**：她和林深都是系统的“产物”（一个被改造，一个被招募），都在用自己的方式应对世界的混乱。她的挣扎（在秩序内寻求正义）与林深的挣扎（在秩序外寻求救赎）形成镜像，让林深反思自己与“体制”的关系是否只有对抗一途。
    4.  **为后期可能的“非正式合作”或剧情反转埋线**：在故事后期，当“断网人”的威胁公开化，或“清道夫”内部出现分裂时，她可能成为一个关键的、游走于灰色地带的变量，甚至被迫与林深形成短暂、脆弱且充满张力的同盟，共同面对更大的威胁。这能深化“秩序可腐化但不可真空”的主题。

**档案已整合至 Book Bible**。这些配角分别从 **技术/幻想层面（阿飞）、现实/市井层面（老周）、制度/秩序层面（苏芮）** 切入故事，与林深的个人救赎弧线深度交织。阿飞注入“非常规可能性”与情感热度，老周提供现实重力与喜剧缓冲，苏芮则带来体制内的张力和道德模糊性，共同迫使林深走出封闭的自我，面对一个复杂、混沌但真实的人际与世界网络。
